Configure Kdenlive Proxy Files on NVMe Scratch Disk

Using proxy clips in Kdenlive allows for smooth timeline playback and responsive editing when working with demanding high-resolution media. Storing these temporary proxy files and project caches on a dedicated high-speed NVMe scratch disk eliminates I/O bottlenecks and maximizes system performance. This guide covers how to set up and redirect Kdenlive's global and project-specific proxy and cache storage paths directly to an NVMe drive.

1. Prepare the NVMe Scratch Directory

Before updating the settings in Kdenlive, ensure your dedicated NVMe drive is properly mounted and create a dedicated folder for Kdenlive temporary assets (for example, /mnt/nvme_scratch/kdenlive_cache on Linux or D:\Kdenlive_Scratch on Windows).

2. Set the Global Cache and Proxy Directory

To ensure all newly created proxies and cached data are routed to your NVMe scratch disk by default:

  1. Open Kdenlive and go to the top menu bar.
  2. Select Settings > Configure Kdenlive...
  3. In the left-hand navigation pane, select Environment.
  4. Click on the Default Folders tab.
  5. Locate the Proxy clips entry (or Cache data depending on your Kdenlive version).
  6. Click the folder icon next to the path, browse to your dedicated NVMe directory, and select it.
  7. Click Apply to save your global preferences.

3. Configure Proxy Encoding Profiles

Optimizing the proxy file format ensures the NVMe drive’s high read/write speeds are utilized effectively:

  1. In the Configure Kdenlive window, select Proxy Clips from the left-hand sidebar.
  2. Check the box labeled Enable Proxy Clips.
  3. Under the Encoding profile dropdown, choose a lightweight editing codec such as MJPEG, ProRes, or DNxHR if editing high-frame-rate footage. These intra-frame codecs generate larger files that decode rapidly without taxing the CPU, making them ideal for fast NVMe storage.
  4. Set the Generate for videos larger than threshold (e.g., 1000 pixels or 1920 pixels) to automate proxy creation upon importing media.
  5. Click OK to close the preferences window.

4. Adjust Project-Specific Settings

If you want individual projects to override global defaults and explicitly write to the NVMe scratch disk:

  1. Open your project and select Project > Project Settings from the top menu.
  2. Navigate to the Project Files or General tab.
  3. Check Custom project folder and point the path to a designated project directory on your NVMe drive.
  4. Go to the Proxy tab within Project Settings, ensure Enable proxy clips is checked, and verify the settings align with your scratch drive workflow.
  5. Click OK.

5. Managing NVMe Scratch Disk Space

Because intra-frame proxies and waveform caches can consume significant disk space over time, regularly manage the scratch disk:

  1. Go to Settings > Configure Kdenlive... > Cache Data.
  2. Review the cached data size for proxy clips, timeline previews, and audio thumbnails.
  3. Use the Clean Up or Delete Cached Data options to purge older project caches and free up high-speed NVMe storage.
