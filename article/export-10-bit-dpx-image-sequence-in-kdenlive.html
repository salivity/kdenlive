Export 10-bit DPX Image Sequence in Kdenlive

Exporting an uncompressed 10-bit DPX (Digital Picture Exchange) image sequence from Kdenlive is essential for professional color grading, archival, and visual effects workflows. Because Kdenlive leverages the FFmpeg multimedia framework under the hood, you can achieve this by configuring a custom render profile with specific pixel formats and codec arguments. This guide outlines the exact, step-by-step procedure required to set up and render a timeline sequence as uncompressed 10-bit DPX frames.

Step 1: Open the Render Dialog

  1. Open your completed project in Kdenlive.
  2. In the top menu, navigate to Project and select Render, or press the shortcut Ctrl + Enter (Cmd + Enter on macOS).

Step 2: Create a Custom Render Profile

Kdenlive does not include an explicit 10-bit DPX preset by default, so you must create a dedicated profile:

  1. In the Render window, look at the Presets panel and click the Create New Profile button (plus icon) located near the preset category dropdown.
  2. Enter a name for the profile, such as 10-bit DPX Sequence.
  3. Set the Extension field to dpx.

Step 3: Enter the FFmpeg Render Arguments

In the Parameters box of your new profile, insert the following configuration to ensure true 10-bit uncompressed RGB frame rendering:

f=image2 vcodec=dpx pix_fmt=gbrp10le

Note on Pixel Formats:

  • gbrp10le: Exports planar 10-bit little-endian RGB.
  • gbrp10be: Exports planar 10-bit big-endian RGB (standard for some legacy hardware systems).

Click Save to store the preset for future use.

Step 4: Configure File Naming and Destination

  1. In the Output file field, click the folder icon to choose an empty target folder on a high-speed storage drive (DPX files require substantial disk space).
  2. Append a sequential naming pattern using standard printf format notation to define frame numbering. For example: /path/to/render_folder/shot_%05d.dpx (The %05d ensures frame numbers are padded with five digits, such as shot_00001.dpx.)

Step 5: Render the Timeline

  1. Under Render options, ensure Full Project or Selected Zone is set according to your export needs.
  2. Ensure More Options settings match your project's native frame rate and resolution.
  3. Click the Render to File button. Kdenlive will process the timeline and export each frame sequentially as an uncompressed 10-bit DPX file.
