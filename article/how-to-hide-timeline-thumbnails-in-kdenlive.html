How to Hide Timeline Thumbnails in Kdenlive

Rendering video thumbnails directly onto timeline clips in Kdenlive requires significant RAM and CPU processing, which can slow down editing performance on complex projects. This guide explains how to configure Kdenlive's timeline settings to hide video thumbnails, helping optimize project performance, eliminate timeline lag, and lower system memory consumption.

Method 1: Change Global Timeline Preferences

To hide thumbnails across all present and future timeline tracks automatically, adjust the global preferences:

  1. Open Kdenlive.
  2. In the top menu, go to Settings > Configure Kdenlive (on macOS, go to Kdenlive > Preferences).
  3. Select the Timeline tab from the left sidebar.
  4. Locate the Thumbnails section.
  5. In the dropdown menu for video thumbnails, select No thumbnails (or choose In/Out frames only if you still require basic visual markers with minimal memory impact).
  6. Click Apply, then click OK to save the changes.

Method 2: Adjust Thumbnails for Individual Tracks

If you prefer to keep thumbnails on certain tracks while disabling them on others, you can configure tracks individually:

  1. Locate the header area of the target video track on the left side of the timeline.
  2. Right-click the track header.
  3. Hover over the Thumbnails option in the context menu.
  4. Select Hide or No thumbnails.
  5. Repeat this process for any other tracks where you want to minimize resource usage.

Additional Tips to Lower Timeline Memory Overhead

  • Audio Waveforms: In the same Timeline settings menu, you can disable or set audio waveforms to only show when necessary, saving additional rendering resources.
  • Proxy Clips: If timeline scrubbing remains slow, enable proxy editing under Project > Project Settings > Proxy to generate lightweight preview versions of high-resolution footage.
