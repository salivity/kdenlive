Create Multilingual Subtitles in Kdenlive

Creating multilingual subtitles in Kdenlive allows you to reach a global audience by managing and translating multiple language tracks within a single video project. This guide outlines the step-by-step workflow for enabling subtitle tracks, creating a base transcription, duplicating timings for translations, and exporting the final subtitle files for platforms like YouTube or media players.

Step 1: Enable the Subtitle Track

To begin working with subtitles, you must first enable the subtitle track in your timeline.

  • Go to the main menu and select Timeline > Subtitles > Add Subtitle Track, or simply click the Subtitle icon in the timeline toolbar.
  • A dedicated subtitle track will appear at the very top of your timeline, directly above the video tracks.

Step 2: Create the Base Subtitle Track

Before translating, you need a master track in the video's original language. You can create this base track using one of three methods:

  • Manual Entry: Double-click on the subtitle track at the desired timestamp to create a blank subtitle block, then type your text in the Subtitle Edit panel.
  • Importing an Existing File: If you already have a transcript, go to Timeline > Subtitles > Import Subtitle File to load an SRT or VTT file.
  • Speech-to-Text: Use Kdenlive’s built-in speech recognition tool by selecting Timeline > Subtitles > Speech Recognition to automatically generate subtitles from your audio track.

Step 3: Add Additional Subtitle Tracks

Once your master subtitle track is complete, you can add separate tracks for each target translation language.

  • Right-click on the subtitle track header on the left side of the timeline.
  • Select Add Subtitle Track.
  • Double-click the track header to rename it according to the target language (e.g., "Spanish," "French," "German") to keep your project organized.

Step 4: Copy and Translate Subtitle Blocks

To maintain identical timing across all languages, you should duplicate the timing blocks of your base track.

  • Select the subtitle blocks on your primary track.
  • Copy them (Ctrl + C) and paste them (Ctrl + V) directly into your new language track.
  • Select a block in the new language track, navigate to the Subtitle Edit tab in the project bin area, and replace the original text with your translated text. Repeat this process for all blocks.

Step 5: Export the Multilingual Subtitles

To distribute your video with toggleable multi-language captions, you must export each subtitle track as an independent file.

  • Go to Timeline > Subtitles > Export Subtitle File.
  • In the export dialog, select the specific subtitle track you want to save.
  • Choose your preferred format (usually SubRip .srt or WebVTT .vtt).
  • Save the file, then repeat this process for each language track in your project. These external files can now be uploaded alongside your video to platforms like YouTube, Vimeo, or bundled into MKV containers.
