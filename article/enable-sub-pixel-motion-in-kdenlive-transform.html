Enable Sub-Pixel Motion in Kdenlive Transform

This guide explains how to configure the Transform effect in Kdenlive to achieve smooth, sub-pixel motion interpolation for animations, pans, and zooms. By adjusting keyframe interpolation types, image filtering algorithms, and export settings, you can eliminate pixel stepping and visual stuttering caused by integer-pixel rounding during slow or precise camera movements.

1. Apply the Transform Effect

  1. Open your project and place your video or image clip onto the timeline.
  2. Open the Effects panel (usually located in the bottom-left or available via Menu > Settings > Layouts > Default).
  3. Search for Transform under the Transform, Distort and Perspective category.
  4. Drag and drop the Transform effect onto your clip in the timeline.

2. Configure Keyframe Motion Curves

Sub-pixel motion depends heavily on how positions are calculated between keyframes. Standard linear keyframes can cause sudden starts and stops that accentuate pixel grid alignment artifacts.

  1. Select the clip on the timeline and go to the Effect/Composition Stack panel.
  2. Create your start and end keyframes using the + (Add Keyframe) button.
  3. Define the movement (X, Y position or Size) at each keyframe.
  4. Right-click the keyframe points on the effect timeline and change the interpolation type:
    • Smooth or Bicubic / Catmull-Rom: Generates continuous curves between points, computing fractional coordinate values (sub-pixel positions) instead of fixed pixel steps.
    • Avoid Discrete or standard stepped keyframes, which snap directly between coordinates.

3. Set High-Quality Resampling for Fractional Alignment

When an image rests between integer pixel coordinates, the edges must be anti-aliased to prevent jitter. Kdenlive uses MLT scaling filters to calculate sub-pixel color blending.

  1. In the Transform effect panel, locate the scaling and filtering parameters (if exposed depending on the Kdenlive version) or use the project-wide scaling controls.
  2. In the project monitor preview settings, ensure Preview Scaling is set to 1:1 or disabled during fine-tuning so you can accurately observe sub-pixel movement.
  3. If using composition tracks (such as Composite and Transform), ensure the composition algorithm is set to Bicubic or Hyper/Lanczos rather than Nearest Neighbor or Bilinear.

4. Optimize Render Profile Settings for Final Output

Real-time playback in Kdenlive may drop sub-pixel accuracy to improve editing performance. The final sub-pixel rendering is calculated during the rendering phase.

  1. Click the Render button in the main toolbar (or press Ctrl + Enter).
  2. Select your target format (e.g., MP4/H.264).
  3. Expand the More Options tab.
  4. Set the Rescale Filter or Interpolation Filter to Bicubic or Lanczos. These filters perform the high-order spatial convolution required to render fractional pixel shifts smoothly.
  5. Click Render to File to produce the final jitter-free video.
