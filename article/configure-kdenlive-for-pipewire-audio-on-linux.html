Configure Kdenlive for PipeWire Audio on Linux

This guide explains how to properly configure Kdenlive to use the PipeWire audio server on modern Linux distributions. By setting the appropriate MLT framework playback driver and routing Kdenlive through PipeWire's PulseAudio emulation layer, you can eliminate audio crackling, reduce timeline playback latency, and ensure seamless audio device switching while video editing.

Step 1: Ensure PipeWire-Pulse is Active

Kdenlive relies on the MLT multimedia framework for playback. Because MLT does not yet have a dedicated native PipeWire backend, it connects to PipeWire through the pipewire-pulse compatibility layer.

Verify that the PipeWire PulseAudio service is running on your system by opening a terminal and running:

pactl info

Look for the Server Name line in the output. It should specify PulseAudio (on PipeWire...). If it does, your system is ready to route PulseAudio-targeted streams directly into the PipeWire graph.

Step 2: Set the Audio Backend in Kdenlive

  1. Launch Kdenlive.
  2. Open the application settings by clicking Settings in the top menu bar and selecting Configure Kdenlive... (or press Ctrl + Shift + ,).
  3. In the left-hand navigation pane, select the Playback tab.
  4. Locate the Audio Backend (or Audio Driver) dropdown menu.
  5. Change the selection to PulseAudio (or SDL if PulseAudio is not visible).
  6. Set the Audio Device to Default to let PipeWire handle automatic routing, or explicitly select your desired output device.
  7. Click Apply, then click OK.

Restart Kdenlive to apply the changes to the playback engine.

Step 3: Manage Routing with PipeWire Patchbays

Once configured, Kdenlive’s playback audio will appear dynamically in PipeWire. You can manage and redirect Kdenlive’s audio stream using standard PipeWire control tools:

  • pavucontrol: Open the Volume Control utility while playing the Kdenlive timeline. Under the Playback tab, locate Kdenlive to adjust application-specific volume or redirect output to a specific DAC, interface, or headphones.
  • qpwgraph / Helvum: Use visual patchbay tools like qpwgraph or Helvum to see the MLT audio nodes in real time and manually link them to PipeWire sinks or DSP plugin chains.

Flatpak and AppImage Considerations

If you run Kdenlive as a Flatpak, ensure the package has permission to access the sound system:

flatpak override --user --socket=pulseaudio org.kde.kdenlive

If you use the AppImage version, ensure your host system has the standard SDL and PulseAudio 32-bit/64-bit client libraries installed so the bundled MLT framework can bridge to PipeWire.
