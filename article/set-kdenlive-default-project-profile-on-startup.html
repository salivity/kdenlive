Set Kdenlive Default Project Profile on Startup

When launching Kdenlive, the software automatically initializes a new project using a standard pre-configured video profile, such as 1080p at 25 frames per second. If your video production workflow regularly requires a different resolution, frame rate, or aspect ratio, manually adjusting these settings for every new project can become tedious. This article provides a straightforward, step-by-step guide on how to configure Kdenlive to automatically load your preferred custom project profile every time the application starts up.

Step 1: Open Kdenlive Configuration

To change the default behavior of the software, you must access the global settings menu.

  1. Launch Kdenlive.
  2. In the top menu bar, click on Settings.
  3. Select Configure Kdenlive... from the drop-down menu. (On macOS, navigate to Kdenlive > Preferences).

Step 2: Navigate to Project Defaults

Once the configuration window is open, you need to locate the project management settings.

  1. In the left-hand sidebar of the configuration window, click on Project Defaults.
  2. Look for the Default Profile section at the top of this menu.

Step 3: Select or Create Your Custom Profile

You can now select an existing profile to be your default, or create a unique custom profile if your required specifications are not listed.

Choosing an Existing Profile

  1. Click the drop-down menu next to Default profile.
  2. Browse the categorized list (e.g., HD, Ultra HD, Custom) and select the profile that matches your target output (e.g., 1080p 60fps).

Creating a New Custom Profile

If the resolution or frame rate you need is not available in the default list, you can create it:

  1. Click the Manage Project Profiles button (the small list icon next to the profile drop-down menu).
  2. Click the Create New Profile button (indicated by a green plus sign or document icon).
  3. Enter your custom values for Description, Frame size (width and height), Frame rate, and Aspect ratio.
  4. Click Save to store the profile.
  5. Close the profile manager, return to the Project Defaults tab, and select your newly created profile from the Default profile drop-down menu.

Step 4: Apply and Save Changes

To ensure Kdenlive remembers these settings for future sessions, you must apply the changes.

  1. Click the Apply button in the bottom right corner of the configuration window.
  2. Click OK to close the window.

The next time you open Kdenlive, or whenever you select File > New, your custom profile will be pre-selected automatically, streamlining your video editing workflow.
