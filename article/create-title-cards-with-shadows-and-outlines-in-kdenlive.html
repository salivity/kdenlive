Create Title Cards with Shadows and Outlines in Kdenlive

This guide provides a straightforward method for designing custom title cards in Kdenlive using the built-in Titler tool. You will learn how to generate a title clip, format text, add high-contrast outlines (strokes), apply soft drop shadows for depth, and place your finished title directly onto the video timeline.

Step 1: Open the Titler Tool

  1. In the Project Bin, right-click an empty area.
  2. Select Add Title Clip (or go to the top menu and select Project > Add Title Clip).
  3. The Titler window will appear over your preview canvas.

Step 2: Add and Format Your Text

  1. Click the Text (T) tool icon in the top-left toolbar of the Titler window.
  2. Click anywhere on the central canvas and type your title text.
  3. Highlight the text to adjust font properties in the top toolbar:
    • Choose your Font Family and Font Size.
    • Select the main text color using the Font Color picker.
    • Use the alignment tools (left, center, right) to position the text.

Step 3: Add an Outline (Stroke)

Adding an outline helps text stand out against busy video backgrounds.

  1. Select the text object on the canvas.
  2. In the top toolbar, locate the Outline controls.
  3. Check the box to enable the outline.
  4. Set the Outline Width (typically between 2px and 6px for clean readability).
  5. Click the Outline Color box to select a contrasting color (such as black for white text).

Step 4: Configure the Drop Shadow

A drop shadow adds depth and separation between the text and background elements.

  1. With the text still selected, locate the Shadow settings in the properties panel.
  2. Enable the Shadow option.
  3. Adjust the Color (usually dark gray or black) and Opacity.
  4. Set the X Offset (horizontal) and Y Offset (vertical) to shift the shadow relative to the text (e.g., 3 to 5 pixels).
  5. Increase the Blur slider to soften the shadow edges for a more natural look, or keep it low for a crisp retro effect.

Step 5: Add a Background Card (Optional)

To turn the text into a full title card:

  1. Click the Rectangle tool in the Titler toolbar.
  2. Drag a rectangle shape across the canvas to cover the area behind the text.
  3. Set the background rectangle's color and adjust its opacity if transparency is desired.
  4. With the rectangle selected, click Lower to Bottom (Z-index controls) in the toolbar to place it behind the text.

Step 6: Save and Place on the Timeline

  1. Click the Create Title (or OK) button in the bottom right corner of the Titler window.
  2. The newly created clip will appear in your Project Bin.
  3. Drag the title clip onto a video track positioned above your background video track in the timeline.
