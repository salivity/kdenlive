Motion Graphics Overlays in Kdenlive Using Glaxnimate

Glaxnimate is an open-source vector animation tool integrated directly into Kdenlive, enabling video editors to design, animate, and render custom vector motion graphics overlays without leaving their video editing workflow. This guide outlines the complete method for setting up Glaxnimate within Kdenlive, creating vector animation assets, configuring keyframes for motion, and seamlessly compositing dynamic transparent graphics over video footage.

1. Verify Glaxnimate Integration

Ensure both Kdenlive and Glaxnimate are installed on your system. In most modern distributions and standalone packages (such as AppImage or Flatpak), Kdenlive comes bundled with Glaxnimate integration.

  1. Open Kdenlive.
  2. Navigate to Settings > Configure Kdenlive > Environment > Default Apps.
  3. Verify that the path for Glaxnimate points to the correct executable binary on your system.

2. Create a New Animation Clip

Instead of importing pre-rendered video files, generate a dedicated animation clip directly in the project bin:

  1. Right-click an empty area in the Project Bin.
  2. Select Create Animation.
  3. Choose a destination folder and file name for the animation file (saved with the .rawr extension, Glaxnimate's native format).
  4. Specify the resolution, frame rate, and duration to match your Kdenlive project profile.
  5. Click OK. Kdenlive will generate the file and automatically open Glaxnimate.

3. Design and Animate the Vector Graphic

With Glaxnimate open, build your custom motion graphic using its vector drawing and animation toolset:

  1. Set Up the Canvas: Ensure the canvas background is set to transparent so it acts as an overlay in Kdenlive.
  2. Draw Vector Shapes: Use the shape tools (Rectangle, Ellipse, Path/Pen tool) to design elements such as lower thirds, callout boxes, shapes, or text.
  3. Group Elements: Group related paths together in the Layers panel to manage transform properties collectively.
  4. Enable Keyframing:
    • Move the playhead on the Glaxnimate timeline to the desired start point.
    • Click the Record icon (or use the stopwatch icons next to properties) to enable automatic keyframing.
  5. Animate Properties: Adjust transform attributes—such as Position, Scale, Rotation, and Opacity—at different points on the timeline to create smooth movement.
  6. Fine-Tune Timing: Use the Graph Editor or adjust keyframe handles to apply easing (ease-in/ease-out) curves for more fluid motion.

4. Save and Composite in Kdenlive

Once the animation is finished:

  1. Press Ctrl + S (or File > Save) in Glaxnimate, then close the application.
  2. Return to Kdenlive. The .rawr animation file in your Project Bin will update automatically.
  3. Drag the animation clip from the Project Bin onto a video track positioned above your background video footage on the timeline.
  4. The graphic will render with full alpha transparency, playing back as a synchronized vector overlay.

5. Modify and Update Overlays

To adjust an existing overlay without starting over:

  1. Right-click the animation clip in Kdenlive’s Project Bin or on the Timeline.
  2. Select Edit Clip.
  3. Glaxnimate will launch with the existing vector assets and keyframes.
  4. Apply the required changes, save the file, and return to Kdenlive to see the updates reflected immediately.
