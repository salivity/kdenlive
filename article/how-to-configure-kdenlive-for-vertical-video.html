How to Configure Kdenlive for Vertical Video

Creating content for mobile platforms like TikTok, Instagram Reels, and YouTube Shorts requires a vertical 9:16 aspect ratio. This guide provides a straightforward walkthrough on configuring Kdenlive for vertical video editing, covering custom project profile creation, canvas adjustments, media scaling, and final render settings optimized for smartphone screens.

Step 1: Create a Vertical Project Profile

By default, Kdenlive defaults to horizontal 16:9 widescreen profiles. You must create or select a 9:16 profile before editing.

  1. Open Kdenlive and navigate to Settings > Configure Kdenlive (or Project > Project Settings for an existing project).
  2. Go to the Profiles tab.
  3. Click the Manage Project Profiles button (the icon next to the profile dropdown).
  4. Click the Add new profile (plus icon) button to create a custom profile.
  5. Enter the following parameters:
    • Profile Name: Vertical HD (or any name you prefer)
    • Frame Size: 1080 x 1920
    • Display Aspect Ratio: 9:16
    • Pixel Aspect Ratio: 1:1
    • Frame Rate: 30 fps or 60 fps (match your source footage)
    • Scanning: Progressive
  6. Click Save, select your new profile, and click Apply / OK.

Step 2: Set Up the Project Monitor

Once your vertical profile is loaded, the Project Monitor automatically displays a portrait-oriented canvas.

  1. Ensure the Project Monitor zoom level is set to Fit so you can view the entire vertical frame without clipping.
  2. If your footage has a different aspect ratio, enable safe zone guides via Project Monitor Settings (the wrench icon) > Show Guidelines to ensure text and critical elements stay within standard mobile safe areas.

Step 3: Fit and Scale Media on the Timeline

When importing horizontal (16:9) clips into a vertical project, black bars will appear at the top and bottom. Use effects to adjust them:

  • To fill the screen by cropping: Add the Transform effect to the clip, increase the Scale until the frame is filled, and adjust the X/Y position to re-center the subject.
  • To create a blurred background: Duplicate the clip across two video tracks. On the bottom track, apply the Transform effect (scale up to fill the frame) and the Gaussian Blur effect. Keep the top track at its original scale.

Step 4: Export the Vertical Video

  1. Click the Render button in the top toolbar (or press Ctrl + Return).
  2. Choose MP4 (H.264 / AAC) from the Generic presets list for maximum mobile compatibility.
  3. Under the Quality settings, adjust the slider to a high setting (CRF 18–22 is recommended).
  4. Verify that the output resolution listed at the bottom matches 1080 x 1920.
  5. Choose your output file destination and click Render to File.
