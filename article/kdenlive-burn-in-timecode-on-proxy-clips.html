Kdenlive: Burn-In Timecode on Proxy Clips

Configuring proxy clips with automatic visual timecode burn-in in Kdenlive streamlines collaboration and multi-camera editing by displaying precise frame references on lightweight preview files without affecting your final export. This is achieved by creating a custom FFmpeg proxy transcoding profile within Kdenlive's settings that utilizes the drawtext video filter during proxy generation.

Step 1: Open Proxy Clip Settings

  1. Launch Kdenlive.
  2. Navigate to Settings > Configure Kdenlive (on macOS: Kdenlive > Preferences).
  3. In the sidebar, select Proxy Clips.

Step 2: Create a Custom Encoding Profile

  1. In the Proxy and Transcode Profiles section, locate the Encoding Profile dropdown.
  2. Click the Manage Proxy Profiles button (the wrench or add/edit icon next to the dropdown).
  3. Click the + (Add) icon to create a new profile.
  4. Set a descriptive name, such as x264 Timecode Burn-In.
  5. Set the Extension to mp4 or mkv.

Step 3: Insert the FFmpeg Timecode Parameters

In the Parameters box, enter an FFmpeg command that scales the video for performance and adds the drawtext filter for the timecode overlay:

-s 960x540 -c:v libx264 -crf 23 -preset ultrafast -vf "drawtext=fontsize=32:fontcolor=white:box=1:boxcolor=black@0.6:x=(w-tw)/2:y=h-th-20:timecode='00\:00\:00\:00':rate=30" -c:a aac -b:a 128k

Parameter Breakdown:

  • -s 960x540: Scales the proxy down for smooth playback.
  • -vf "drawtext=...": Draws the timecode on the video.
    • fontsize=32: Sets text size.
    • fontcolor=white / boxcolor=black@0.6: Ensures readability against any background.
    • x=(w-tw)/2:y=h-th-20: Centers the timecode horizontally near the bottom of the frame.
    • timecode='00\:00\:00\:00':rate=30: Generates a running timecode. Adjust the rate parameter (e.g., 24, 29.97, 30, 60) to match your project framerate.

To draw source-embedded timestamps instead of a generic clock, use the timecode_source filter parameter if your source files contain embedded timecode tracks:

-s 960x540 -c:v libx264 -crf 23 -preset ultrafast -vf "drawtext=fontsize=32:fontcolor=white:box=1:boxcolor=black@0.6:x=(w-tw)/2:y=h-th-20:text='%{pts\:hms}'" -c:a aac -b:a 128k

Step 4: Apply the New Profile

  1. Click OK to save the custom profile.
  2. Under Configure Kdenlive > Proxy Clips, ensure Enable Proxy Clips is checked.
  3. Select your newly created profile from the Encoding profile dropdown.
  4. Check Auto generate for videos larger than [X] pixels if you want Kdenlive to create these proxies automatically upon importing media.
  5. Click Apply and OK.

Step 5: Generate and Verify

  1. Drag and drop a video file into your Project Bin.
  2. Right-click the clip and select Proxy Clip (if not generated automatically).
  3. Once processing finishes, a visual P icon appears on the clip thumbnail, and the timecode overlay will display in the Clip and Project Monitors during playback.
