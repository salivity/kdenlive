How to Map Project Bin Hotkeys in Kdenlive

Customizing your workspace shortcuts in Kdenlive allows you to streamline your video editing workflow and free up screen space instantly. This guide provides step-by-step instructions on mapping custom hotkeys to toggle, minimize, and expand the Project Bin dock in Kdenlive.

Step 1: Open the Shortcut Configuration Menu

  1. Launch Kdenlive.
  2. In the top menu bar, click on Settings.
  3. Select Configure Keyboard Shortcuts... from the dropdown menu (or use the default shortcut Ctrl + Alt + ,).

Step 2: Locate the Project Bin Command

  1. In the search box at the top of the Configure Shortcuts window, type Project Bin (or Show Project Bin depending on your Kdenlive version).
  2. Look for the command under the View category that controls the panel's visibility, typically labeled Project Bin or Project Tree.

Step 3: Assign Your Custom Hotkey

  1. Click on the action row to highlight it.
  2. Select the Custom radio button located below the shortcut list.
  3. Click on the input button next to "Custom" (it will display None or the previously assigned key).
  4. Press the key combination on your keyboard that you want to use (for example, Alt + 1 or F9).
  5. If the shortcut is already in use by another action, Kdenlive will prompt a conflict warning. Choose a different combination or reassign the existing one.

Step 4: Apply and Save Changes

  1. Click OK at the bottom right of the window to apply your changes.

Step 5: Test the Shortcut

Press your assigned key combination in the main workspace.

  • Pressing the hotkey when the Project Bin is visible will close/minimize it, allowing other panels like the Timeline and Clip Monitor to expand.
  • Pressing the hotkey again will restore the Project Bin to its docked position.

(Tip: To maximize any panel under your cursor to full-screen mode, Kdenlive also supports the default shortcut Shift + F10 or F11, which can be customized in the same shortcut menu under the name Toggle Full Screen Area).
