Export Kdenlive XML for Color Grading Workflows

This guide explains how to export an XML project file from Kdenlive to execute a professional round-trip color grading workflow with external software such as DaVinci Resolve. By translating the timeline into an exchange format (Final Cut Pro XML or OpenTimelineIO), you can grade original source media in a dedicated color suite and seamlessly bring the finished clips back into Kdenlive for final delivery.

Step 1: Prepare the Kdenlive Timeline

Before exporting, prepare your edit to ensure optimal compatibility with external software:

  1. Flatten Video Tracks: Reduce complex multi-track layering where possible, keeping primary footage on the lowest video tracks.
  2. Disable Native Effects: Turn off Kdenlive-specific effects, titles, and transitions, as external applications cannot read proprietary MLT filters.
  3. Check File Formats: Ensure all source clips have standard, readable codecs and uninterrupted timecode.

Step 2: Export the XML from Kdenlive

  1. Navigate to the top menu and select Project > Export.
  2. Choose Final Cut Pro 7 XML (or OpenTimelineIO if your external application supports OTIO).
  3. In the export dialog box, choose a destination folder and file name for the .xml file.
  4. Click Save to generate the XML file.

Step 3: Import the XML into Your Color Software

  1. Open your external color grading software (such as DaVinci Resolve).
  2. Go to File > Import > Timeline (or Import AAF/EDL/XML).
  3. Select the XML file generated by Kdenlive.
  4. In the import settings dialog:
    • Match the project timeline frame rate and resolution to your Kdenlive project settings.
    • Enable the option to automatically import and link to source clips. If the media does not link automatically, point the file browser to the directory containing your raw footage.

Step 4: Grade and Render the Clips

  1. Apply your color corrections and adjustments to the timeline.
  2. Navigate to the delivery/export tab of your color software.
  3. Configure the output render settings:
    • Set the render mode to Individual Clips.
    • Choose an intermediate master format (such as ProRes, DNxHR, or uncompressed 10-bit/12-bit formats).
    • Select Use Source Filename to retain original clip names, or append a suffix (e.g., _graded).
    • Include handles (frame padding) if you plan to adjust edits or crossfades later.
  4. Export the graded video files into a dedicated render folder.

Step 5: Complete the Round-Trip in Kdenlive

  1. Return to your Kdenlive project.
  2. Replace original media with the graded files using one of two methods:
    • Clip Proxy/Replacement: Right-click the clips in the Project Bin and select Replace Clip, then point to the corresponding graded file.
    • Folder Relinking: Save a copy of your project file, place the graded media in a matching folder structure, and update the project clip paths to reference the new color-corrected media.
  3. Re-enable any overlays, titles, and transitions to prepare the project for final rendering.
