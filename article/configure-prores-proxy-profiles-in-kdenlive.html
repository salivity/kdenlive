Configure ProRes Proxy Profiles in Kdenlive

This guide provides a straightforward walkthrough for configuring custom external proxy transcoding profiles in Kdenlive using the Apple ProRes Proxy codec. By leveraging FFmpeg’s ProRes encoder directly within Kdenlive's proxy settings, you can significantly reduce timeline lag, speed up scrubbing, and ensure seamless playback when working with high-resolution or heavily compressed source footage.

Why Use ProRes Proxy in Kdenlive?

While H.264/H.265 proxies create small file sizes, they are inter-frame codecs that place a heavy decompression load on your CPU during timeline navigation. Apple ProRes Proxy is an intra-frame format (every frame is compressed independently), making decoding effortless for your system and providing an exceptionally responsive editing experience.

Steps to Configure the ProRes Proxy Profile

Step 1: Open the Proxy Profile Manager

  1. Launch Kdenlive.
  2. Navigate to the top menu and select Settings > Configure Kdenlive... (on macOS, Kdenlive > Preferences...).
  3. In the left-hand sidebar, click on Proxy Clips.
  4. In the Encoding profile section, click the Manage Proxy Profiles button (the wrench or edit icon next to the profile dropdown).

Step 2: Create a New Profile

  1. In the profile management window, click the Add new profile icon (the plus sign +).
  2. Set the Profile Name to: Apple ProRes Proxy.
  3. Set the File Extension to: mov.

Step 3: Insert the FFmpeg Transcoding Parameters

In the Parameters text field, enter the FFmpeg command string for ProRes Proxy encoding.

For full-resolution ProRes Proxy:

-vcodec prores_ks -profile:v 0 -acodec pcm_s16le

For half-resolution ProRes Proxy (recommended for 4K/8K media to maximize playback speed):

-vf scale=iw/2:ih/2 -vcodec prores_ks -profile:v 0 -acodec pcm_s16le

Parameter Breakdown:

  • -vcodec prores_ks: Selects the standard FFmpeg ProRes encoder.
  • -profile:v 0: Sets the ProRes profile to Proxy (0 = Proxy, 1 = LT, 2 = Standard, 3 = HQ).
  • -acodec pcm_s16le: Encodes uncompressed 16-bit PCM audio to minimize audio processing overhead.
  • -vf scale=iw/2:ih/2: Scales the video width and height to 50% of the original source resolution.

Step 4: Save and Set as Default

  1. Click Save (or OK) to store the profile.
  2. Back in the Proxy Clips settings window, set Encoding profile to your newly created Apple ProRes Proxy.
  3. Check the box labeled Enable proxy clips to ensure newly imported clips automatically generate proxies if they exceed your designated resolution threshold (e.g., 1000px or 2000px).
  4. Click Apply, then OK.

Applying the Profile to an Existing Project

If you are already inside an active project:

  1. Go to Project > Project Settings...
  2. Select the Proxy tab.
  3. Check Enable Proxy Clips.
  4. Set the Encoding profile dropdown to Apple ProRes Proxy.
  5. Click OK.

Kdenlive will automatically begin rendering the ProRes proxy files in your project's background job queue.
