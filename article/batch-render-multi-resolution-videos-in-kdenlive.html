Batch Render Multi-Resolution Videos in Kdenlive

Exporting multiple versions of a single video project for platforms like YouTube, Instagram, and TikTok can be time-consuming if done individually. Kdenlive simplifies this workflow through its Render Queue system, allowing editors to stage horizontal (16:9), vertical (9:16), and square (1:1) exports in a single queue. This guide explains the exact steps to configure, queue, and batch export multi-resolution social media cuts directly from Kdenlive.

1. Finalize the Master Sequence

Before preparing multi-resolution variations, complete all primary editing, color correction, and audio mastering on your primary sequence. This ensures all variations stem from the same approved timeline.

2. Create Resolution-Specific Sequences or Project Copies

To reformat your video for different social media platforms without distorting the footage:

  • Option A (Sequences Workflow): Create new sequences within the same project. Go to Project > Add Sequence, name it according to the target platform (e.g., Vertical_9x16), and adjust the sequence profile to your target dimensions (e.g., 1080x1920 for Reels/Shorts or 1080x1080 for square posts). Copy the timeline assets from the master sequence and use the Transform or Position and Zoom effect to reframe the content.
  • Option B (Save As Workflow): If not using nested sequences, save separate project files (Project_16x9.kdenlive, Project_9x16.kdenlive, Project_1x1.kdenlive) and adjust the Project Settings (Project > Project Settings) to match each platform's aspect ratio.

3. Configure Render Settings for the First Resolution

  1. Open the render dialog by pressing Ctrl + Enter or clicking Project > Render.
  2. Select your desired export preset (e.g., MP4-H264/AAC for standard social media uploads).
  3. Set your output file destination and assign a clear name indicating the aspect ratio (e.g., video_vertical.mp4).
  4. If you need to scale the output resolution directly, check More Options, select Rescale, and enter the target pixel dimensions.

4. Add the Job to the Render Queue

Instead of clicking Render to File, use the queue options:

  • Click the dropdown arrow next to Render to File and select Generate Script or Add to Queue.
  • Enter a script name if prompted. This saves the render instructions without tying up system resources immediately.

5. Queue Additional Resolutions

  1. Switch to your next sequence or open the next aspect-ratio project file.
  2. Open the Render window (Ctrl + Enter).
  3. Update the output filename (e.g., video_square.mp4).
  4. Adjust the target profile, rescale dimensions, or sequence source as needed.
  5. Click Generate Script or Add to Queue to append this job to the existing list.

6. Process the Batch Render Queue

  1. Switch to the Scripts or Queue tab inside the Kdenlive Render window (or open the standalone Kdenlive Render Queue tool).
  2. Review the list of pending render jobs to ensure all file paths and settings are correct.
  3. Click Start Job to process the queue sequentially.

Kdenlive will render each resolution cut in the background, allowing you to export full multi-platform deliverables in a single automated session.
