Custom Dual Ultrawide Resolutions in Kdenlive

This guide outlines the step-by-step process for configuring custom project profiles in Kdenlive to edit content for dual-screen ultrawide video walls. You will learn how to calculate the combined pixel dimensions, create and save a custom project profile, adjust composition settings, and export your video at the exact resolution needed for multi-monitor playback.

1. Calculate the Total Canvas Dimensions

Before opening Kdenlive, determine the combined resolution of your two ultrawide displays.

  • Side-by-Side (Horizontal Array): Double the width of one display while keeping the vertical height the same.
    • Example (Dual 3440 x 1440 displays): \(3440 \times 2 = 6880\). Target resolution: 6880 x 1440.
    • Example (Dual 2560 x 1080 displays): \(2560 \times 2 = 5120\). Target resolution: 5120 x 1080.
  • Stacked (Vertical Array): Double the height while keeping the horizontal width identical.
    • Example (Dual 3440 x 1440 stacked): Target resolution: 3440 x 2880.

2. Create a Custom Project Profile in Kdenlive

Kdenlive does not include dual ultrawide presets by default, so you must define a custom profile.

  1. Open Kdenlive and go to Settings > Configure Kdenlive (or Kdenlive > Preferences on macOS).
  2. Select the Profiles tab from the left sidebar.
  3. Click the Add new profile icon (the green plus sign) located above the profile list.
  4. Configure the following profile settings:
    • Profile Name: Enter a descriptive name (e.g., Dual Ultrawide 6880x1440 60fps).
    • Frame Size: Input your calculated total dimensions (e.g., 6880 in Width and 1440 in Height).
    • Pixel Aspect Ratio: Set to 1:1 (square pixels).
    • Display Aspect Ratio: Kdenlive calculates this automatically based on your dimensions (e.g., 43:9 for dual 21:9).
    • Frame Rate: Set the numerator and denominator to match your playback hardware (e.g., 60/1 for 60 fps or 30/1 for 30 fps).
    • Scanning: Select Progressive.
    • Color Space: Set to ITU-R BT.709 (standard for digital displays).
  5. Click Save and then click OK to close the configuration menu.

3. Apply the Profile to a New Project

  1. Go to File > New.
  2. Under the Project Profile section, scroll through the list or search for your newly created custom profile.
  3. Select the custom profile and choose your preferred audio and track settings.
  4. Click OK.

Note: If you receive a prompt indicating that imported clips do not match the project profile, select Keep to prevent Kdenlive from automatically switching back to a standard resolution.

4. Arrange Content on the Canvas

  1. Drag your media onto the timeline.
  2. Apply the Transform effect to position, scale, or split assets across the combined displays.
  3. To align content strictly to the left or right monitor, use the coordinate offsets in the Transform effect (e.g., positioning an element at \(X = 0\) for the left screen or \(X = 3440\) for the right screen on a 6880x1440 canvas).

5. Export the Final Video Wall File

  1. Click Project > Render (or press Ctrl + Return).
  2. Select your preferred output format (such as Generic (MP4 - H.264/AAC) or ProRes for higher bitrate playback).
  3. Ensure that the Rescale option is unchecked so the project exports at its full native resolution.
  4. Confirm that the export parameters display your custom width and height.
  5. Click Render to File.
