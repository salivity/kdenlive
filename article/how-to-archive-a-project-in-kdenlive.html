How to Archive a Project in Kdenlive

Archiving a project in Kdenlive gathers your project file and all associated media assets—such as video footage, audio tracks, and images—into a single, organized folder or compressed archive. This process ensures your project remains fully intact and editable when transferring it to another computer, backing it up, or sharing it with collaborators without risking missing-file errors.

Step 1: Open the Project

Launch Kdenlive and open the project you wish to consolidate. Ensure that your timeline is arranged properly and that no files are currently marked as missing in your Project Bin.

Step 2: Access the Archive Tool

Navigate to the top menu bar, click on Project, and select Archive Project... from the dropdown menu. This will open the Project Archive configuration window.

Step 3: Select the Destination Folder

In the Archive Project window, click the folder icon next to the Destination field. Choose the directory on your local drive or external storage where you want the consolidated files to be saved.

Step 4: Configure Archiving Options

Customize how Kdenlive handles your project media by selecting your preferred settings:

  • Timeline clips only vs. All clips: Check the option to archive only the clips used in the timeline if you want to save storage space, or leave it unchecked to include every asset imported into your Project Bin.
  • Proxy clips: Choose whether to include proxy clips. Leaving this unchecked will copy only the full-resolution original media.
  • Compression: Check the option to compress the archive (such as into a .tar.gz or .zip file) if you want a single downloadable file, or leave it unchecked to create a standard folder structure containing your media and project file.

Step 5: Start the Archiving Process

Click the Start button at the bottom of the window. Kdenlive will begin copying the assets and adjusting file paths inside the project file to point to the newly consolidated location.

Step 6: Verify the Archive

Once the process is complete, navigate to your selected destination folder. Open the generated folder or extract the compressed file, then launch the new .kdenlive file to confirm that all media loads correctly from the consolidated location.
