Enable Intel QuickSync in Kdenlive on Linux

Hardware-accelerated video encoding significantly reduces export times and offloads intensive processing tasks from your CPU to the graphics processor. This guide explains how to configure Intel QuickSync Video (QSV) hardware acceleration for rendering projects in Kdenlive on a Linux distribution. Following the steps below, you will prepare the necessary system drivers, configure FFmpeg support, select the correct render profiles in Kdenlive, and monitor GPU utilization during export.

1. Install Required Intel Drivers and Utilities

Intel hardware acceleration on Linux relies on VA-API (Video Acceleration API) and Intel media driver backends to interface with FFmpeg and Kdenlive.

  1. Install the appropriate driver package for your distribution:
    • Ubuntu/Debian: 
      sudo apt install intel-media-va-driver-non-free libva-utils intel-gpu-tools
    • Fedora: 
      sudo dnf install intel-media-driver libva-utils intel-gpu-tools
    • Arch Linux: 
      sudo pacman -S intel-media-driver libva-utils intel-gpu-tools
  2. Verify that your user belongs to the video and render groups to ensure access to hardware nodes: 
    sudo usermod -aG video,render $USER
    (Log out and log back in for group changes to take effect.)
  3. Test your driver installation using vainfo: 
    vainfo
    Ensure the output lists supported profiles (such as VAProfileH264... and VAProfileHEVC...) alongside VAEntrypointEncSlice.

2. Verify FFmpeg Hardware Support

Kdenlive uses FFmpeg as its encoding backend. Ensure your installed version of FFmpeg supports Intel encoding encoders:

ffmpeg -encoders | grep -E "vaapi|qsv"

You should see encoders such as h264_vaapi, hevc_vaapi, h264_qsv, or hevc_qsv in the terminal output.

3. Enable Hardware Acceleration in Kdenlive

  1. Open Kdenlive.
  2. Go to Settings > Configure Kdenlive....
  3. Select the Hardware Acceleration or Environment tab (depending on your Kdenlive version).
  4. Check the box for Enable Hardware Accelerated Processing if available, and ensure Kdenlive detects your system's VA-API/QuickSync capabilities.
  5. Click Apply and OK.

4. Configure the Render Profile

  1. Open the rendering dialog by clicking Render on the main toolbar or pressing Ctrl + Return.
  2. Expand the Hardware Accelerated category in the preset list.
  3. Choose VAAPI Intel/AMD - H264 or VAAPI Intel/AMD - HEVC.

Custom QSV/VA-API Profile Creation (Optional)

If the default presets are missing or you need specific QuickSync arguments:

  1. In the Render window, click the Create New Profile (plus) icon.
  2. Set Profile Name to Intel QSV H264.
  3. Set the Extension to mp4.
  4. In the Parameters box, add the following FFmpeg command arguments: 
    f=mp4 vcodec=h264_vaapi vaapi_device=/dev/dri/renderD128 vf='format=nv12,hwupload' acodec=aac ab=192k crf=23
    (For systems specifically compiled with oneVPL/QSV wrappers, vcodec=h264_qsv can be used alternatively.)
  5. Click Save.

5. Render and Verify GPU Usage

  1. Select your configured hardware profile in the Render menu.
  2. Specify the destination path and click Render to File.
  3. Open a separate terminal window and run: 
    sudo intel_gpu_top
  4. Check the Video or VideoEnhance engine activity metrics. High utilization confirms that your Intel QuickSync hardware is actively rendering the video.
