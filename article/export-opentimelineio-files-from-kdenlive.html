Export OpenTimelineIO Files from Kdenlive

This article provides a comprehensive guide on exporting an OpenTimelineIO (.otio) sequence file from Kdenlive to streamline collaboration across various non-linear editing (NLE) applications. OpenTimelineIO serves as an open-source standard for editorial interchange, allowing editors to transfer cuts, markers, and sequence structures between Kdenlive and other software such as DaVinci Resolve, Adobe Premiere Pro, or Final Cut Pro. Follow the direct steps below to prepare, export, and share your Kdenlive timeline.

1. Finalize the Timeline in Kdenlive

Before exporting, organize your project timeline to ensure a smooth transition:

  • Remove any unused tracks or disabled clips that are not needed in the final edit.
  • Check that all cuts, clips, and basic audio/video tracks are properly aligned.
  • Note that while basic cuts, track positions, and clip retiming generally transfer well, software-specific effects and complex titles may not translate directly through the interchange format.

2. Open the Export Menu

With your project open in Kdenlive:

  1. Navigate to the top menu bar.
  2. Click on Project.
  3. Hover over the Export submenu.
  4. Select Export to OpenTimelineIO (or OpenTimelineIO... depending on your Kdenlive version).

3. Configure the Output Location

A file browser dialogue box will appear:

  1. Choose the destination directory where you want to save the interchange file.
  2. Enter a clear and descriptive filename for your sequence.
  3. Ensure the file extension is set to .otio.
  4. Click Save to generate the file. Kdenlive will compile your timeline structure into the OpenTimelineIO schema.

4. Prepare Media for Collaboration

An .otio file contains metadata referencing the location and timing of your media files, but it does not embed the actual video or audio files. To collaborate successfully:

  • Collect all source media files used in the project into a single, organized folder structure.
  • Keep the relative file paths consistent so the receiving editing software can automatically link to the media clips upon importing the .otio sequence.

5. Import into the Destination Software

Provide your collaborator with both the .otio file and the corresponding media folder. They can then use their NLE's native OpenTimelineIO import function or an OTIO adapter plugin to reconstruct the timeline and reconnect the source media files.
