How to Export OpenTimelineIO in Kdenlive

Exporting an OpenTimelineIO (.otio) file from Kdenlive allows video editors to interchange cuts, track layouts, and timing data with other non-linear editors such as DaVinci Resolve, Final Cut Pro, and Adobe Premiere Pro. This guide covers the exact steps to prepare your project, export the OTIO file from Kdenlive, and ensure seamless cross-platform collaboration across team members using different operating systems and editing software.

Step 1: Prepare the Timeline for Export

Before initiating the export, clean up the Kdenlive project timeline to minimize translation errors between different editing applications:

  • Flatten Unnecessary Tracks: Merge secondary b-roll and audio tracks where practical.
  • Remove Software-Specific Effects: Complex Kdenlive-specific effects, title generators, and custom transitions may not translate via OTIO. Bake these assets into rendered clips if they must be preserved.
  • Standardize Clip Naming: Ensure all video and audio assets have clear, unique file names without special characters.

Step 2: Use Relative Media Paths

Cross-platform workflows often break when file paths are hardcoded to specific operating system structures (e.g., Windows drive letters versus macOS/Linux root paths).

  1. Open Project > Project Settings.
  2. Verify that your project folder structure keeps source media and project files in relative directories.
  3. Keep all linked assets inside a shared project directory to allow other team members' software to automatically relink media upon import.

Step 3: Export the OpenTimelineIO File

Once the timeline is prepared, export the interchange schema:

  1. Navigate to the top menu and select Project.
  2. Hover over Export Timeline (or select File > Export depending on your Kdenlive version).
  3. Choose OpenTimelineIO (.otio) from the list of available export formats.
  4. In the file dialog, choose your destination directory—ideally within the root folder of the shared project assets.
  5. Enter a file name and click Save.

Step 4: Verify the Exported File

To ensure the exported OTIO file contains all necessary cut data before sending it to collaborators:

  • Use the command-line utility otioview (included with OpenTimelineIO tools) to inspect tracks, markers, and clip boundaries visually.
  • Alternatively, test-import the .otio file into a secondary editor or a fresh Kdenlive session to confirm that cuts and in/out points match the original edit.

Step 5: Package and Distribute to the Team

Distribute the generated .otio file along with the corresponding media directory using a shared network drive, cloud storage, or version control system. When team members import the file into their respective NLEs, they only need to point their software to the shared media folder to relink the timeline.
