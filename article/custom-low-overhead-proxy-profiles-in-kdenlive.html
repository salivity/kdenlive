Custom Low-Overhead Proxy Profiles in Kdenlive

Using custom proxy profiles with low-overhead codecs in Kdenlive can significantly boost timeline playback performance and reduce CPU strain during video editing. This guide explains how to configure Kdenlive’s proxy settings and create custom FFmpeg transcode profiles using lightweight, editing-friendly codecs such as DNxHR LB, ProRes Proxy, or fast MJPEG.

Step 1: Open the Proxy Settings

  1. Launch Kdenlive.
  2. Go to the top menu and select Settings > Configure Kdenlive (on macOS: Kdenlive > Preferences).
  3. In the left-hand sidebar, select Proxy Clips.

Step 2: Access Custom Proxy Profiles

  1. Ensure the Enable proxy clips checkbox is selected.
  2. Locate the Encoding profile dropdown menu.
  3. Click the Manage proxy profiles (wrench/edit) icon next to the dropdown to open the profile configuration manager.

Step 3: Create a New Profile

  1. Click the Add New Profile button (plus icon).
  2. Enter a descriptive name for your profile, such as DNxHR LB Low-Res or ProRes Proxy 720p.
  3. Set the target file extension (e.g., mov, mkv, or mp4 depending on your chosen codec).

Step 4: Configure FFmpeg Encoding Parameters

In the parameters field, specify the FFmpeg arguments to use a low-overhead, intra-frame codec. Intra-frame codecs require less processing power to decode during timeline scrubbing compared to inter-frame codecs (like standard H.264/H.265).

Choose one of the following recommended parameter presets:

  • DNxHR Low Bandwidth (Fastest decoding on modern hardware): -vf scale=-1:720 -c:v dnxhd -profile:v dnxhr_lb -pix_fmt yuv422p -c:a pcm_s16le (Extension: mov)

  • Apple ProRes Proxy (Low CPU overhead across all platforms): -vf scale=-1:720 -c:v prores -profile:v 0 -c:a pcm_s16le (Extension: mov)

  • MJPEG (Extremely low CPU usage for older machines): -vf scale=-1:720 -c:v mjpeg -q:v 5 -c:a pcm_s16le (Extension: mov or avi)

Note: The -vf scale=-1:720 parameter scales the proxy down to 720p while maintaining the original aspect ratio to further reduce memory and processing loads.

Step 5: Save and Set as Default

  1. Click Apply or Save to store your new proxy profile.
  2. Set your new profile as the default option in the Encoding profile dropdown.
  3. (Optional) Set the Generate for videos larger than threshold to automatically generate proxies for 1080p or 4K footage.
  4. Click OK to close the configuration menu.

Step 6: Generate and Verify Proxies

  1. Import your media clips into the Project Bin.
  2. If automatic generation is enabled, Kdenlive will begin transcoding in the background.
  3. To manually generate a proxy for an existing clip, right-click the clip in the Project Bin and select Proxy Clip.
  4. Once processing is complete, a small P icon will appear on the clip thumbnail, indicating the active use of your custom low-overhead proxy.
