Fix Kdenlive Scaling Bugs with Qt Settings

Kdenlive can sometimes suffer from user interface scaling bugs on modern high-resolution (HiDPI) monitors, leading to blurry text, oversized buttons, or extremely tiny UI elements. Because Kdenlive is built on the Qt framework, these display issues can be resolved by configuring Qt's built-in scaling environment variables. This guide details the essential Qt scaling variables and explains how to apply them on both Linux and Windows operating systems.

Key Qt Scaling Variables

Qt provides several environment variables to control how applications render across different display resolutions:

  • QT_AUTO_SCREEN_SCALE_FACTOR: Automatically scales the UI based on the screen's pixel density. Setting this to 0 disables automatic detection, which often fixes miscalculated sizing. Setting it to 1 forces automatic scaling.
  • QT_SCALE_FACTOR: Sets a global scaling factor for the entire application (e.g., 1 for 100%, 1.25 for 125%, 1.5 for 150%, or 2 for 200%).
  • QT_SCREEN_SCALE_FACTORS: Allows independent scaling factors for multi-monitor setups with different resolutions (e.g., "1;1.5" for dual displays).
  • QT_ENABLE_HIGHDPI_SCALING: Enables or disables fractional HiDPI scaling (Qt 5.14+). Setting this to 0 disables high-DPI scaling entirely, while 1 enables it.

Configuring Qt Settings on Linux

Testing via the Terminal

Before making permanent changes, test variable combinations in your terminal to find the ideal scale:

QT_AUTO_SCREEN_SCALE_FACTOR=0 QT_SCALE_FACTOR=1.25 kdenlive

If you are using the Flatpak version, launch it using:

flatpak run --env=QT_AUTO_SCREEN_SCALE_FACTOR=0 --env=QT_SCALE_FACTOR=1.25 org.kde.kdenlive

For the AppImage version:

QT_AUTO_SCREEN_SCALE_FACTOR=0 QT_SCALE_FACTOR=1.25 ./kdenlive-*.AppImage

Making the Fix Permanent

  1. Modify the Desktop Entry:

    • Copy the system shortcut to your local directory: 
      cp /usr/share/applications/org.kde.kdenlive.desktop ~/.local/share/applications/
    • Open ~/.local/share/applications/org.kde.kdenlive.desktop in a text editor.
    • Find the Exec= line and update it: 
      Exec=env QT_AUTO_SCREEN_SCALE_FACTOR=0 QT_SCALE_FACTOR=1.25 kdenlive %F

  2. Set Session-Wide Variables:

    • Add the desired variable exports to your ~/.profile, ~/.bashrc, or ~/.pam_environment file: 
      export QT_AUTO_SCREEN_SCALE_FACTOR=0
export QT_SCALE_FACTOR=1.25

Configuring Qt Settings on Windows

Method 1: Modify System Environment Variables

  1. Press Win + R, type sysdm.cpl, and press Enter.
  2. Navigate to the Advanced tab and click Environment Variables.
  3. Under User variables (or System variables), click New.
  4. Set the Variable name to QT_AUTO_SCREEN_SCALE_FACTOR and the Variable value to 0.
  5. Click New again, set the Variable name to QT_SCALE_FACTOR, and enter your preferred multiplier (such as 1.25 or 1.5).
  6. Click OK to apply the changes and restart Kdenlive.

Method 2: Launch via a Batch Script

If you only want these settings to apply to Kdenlive and not other Qt-based applications on Windows, create a .bat launcher file:

  1. Open Notepad and enter the following: 
    @echo off
set QT_AUTO_SCREEN_SCALE_FACTOR=0
set QT_SCALE_FACTOR=1.25
start "" "C:\Program Files\kdenlive\bin\kdenlive.exe"
  2. Adjust the file path to match your Kdenlive installation location.
  3. Save the file as kdenlive_scaled.bat and use it to launch the application.
