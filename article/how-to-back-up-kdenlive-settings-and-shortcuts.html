How to Back Up Kdenlive Settings and Shortcuts

Backing up your custom configuration profiles and keyboard shortcuts in Kdenlive ensures you can easily restore your optimized workspace, custom render presets, and editing workflow after a fresh installation or when migrating to a new machine. This guide outlines the steps to export keyboard shortcuts directly through the user interface and locate the specific configuration files across Linux, Windows, and macOS systems.

Method 1: Backing Up Keyboard Shortcuts via the Interface

Kdenlive allows you to manage and export your custom keyboard layouts directly within the application settings:

  1. Open Kdenlive.
  2. Navigate to Settings > Manage Keyboard Shortcuts (or Configure Shortcuts depending on your version).
  3. Click the Manage Schemes button (or the gear icon).
  4. Select Export Scheme... or Save Scheme....
  5. Choose a destination folder (such as an external drive or cloud storage) and save the shortcut file (.kshortcut or .shortcuts).

To restore shortcuts on a new system, return to the same menu and select Import Scheme....

Method 2: Manually Backing Up User Configuration Files

Kdenlive stores project presets, custom layout configurations, render presets, and application preferences in dedicated system directories. Copying these folders creates a complete backup of your setup.

Step 1: Close Kdenlive

Ensure Kdenlive is completely closed before copying files to prevent configuration overwrite errors.

Step 2: Locate and Copy the Files

On Linux:

  • Main Configuration: ~/.config/kdenliverc
  • Custom Profiles and Presets: ~/.local/share/kdenlive/
  • Custom Titles and Luts: ~/.local/share/kdenlive/titles/ and ~/.local/share/kdenlive/luts/

On Windows:

  • Main Configuration: %APPDATA%\kdenlive\kdenliverc (or %LOCALAPPDATA%\kdenliverc)
  • Custom Profiles and Presets: %APPDATA%\kdenlive\ or %LOCALAPPDATA%\kdenlive\

On macOS:

  • Main Configuration: ~/Library/Preferences/kdenliverc
  • Custom Profiles and Presets: ~/Library/Application Support/kdenlive/

Step 3: Archive the Files

Copy the kdenliverc file and the entire kdenlive data folder to a secure backup directory or external storage device.

Restoring Your Configurations

To restore your setup on a new system:

  1. Install Kdenlive on the target machine and launch it once to generate default directory paths, then close the application.
  2. Copy the backed-up kdenliverc file into the corresponding configuration directory for your operating system.
  3. Copy the contents of your backed-up kdenlive folder into the target application data folder.
  4. Launch Kdenlive to verify that all custom project settings, layouts, and shortcuts have loaded.
