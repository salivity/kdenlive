Integrate Kdenlive with Glaxnimate for Vector Animation

Integrating Kdenlive with Glaxnimate allows video editors to create, edit, and render high-quality 2D vector animations directly within their video editing timeline. This guide provides a straightforward walkthrough on how to configure the connection between both open-source programs, create new animation clips, and seamlessly edit your vector graphics with real-time updates.

Prerequisites and Installation

To get started, you must have both Kdenlive and Glaxnimate installed on your system.

  1. Download and install the latest version of Kdenlive.
  2. Download and install Glaxnimate.
  3. For the best compatibility, ensure both applications are updated to their latest stable versions.

Step 1: Configure Kdenlive to Find Glaxnimate

Before you can create animations, Kdenlive needs to know where the Glaxnimate executable is located on your computer.

  1. Open Kdenlive.
  2. Go to the top menu and select Settings > Configure Kdenlive (on macOS, select Kdenlive > Preferences).
  3. In the configuration window, click on the Environment tab on the left sidebar.
  4. Select the Default Applications (or Paths) tab.
  5. Look for the Glaxnimate path field. Click the folder icon next to it, navigate to where Glaxnimate is installed on your system, and select the executable file (glaxnimate.exe on Windows, or the Glaxnimate binary/AppImage on Linux/macOS).
  6. Click Apply and then OK to save the changes.

Step 2: Create a New Animation Clip in Kdenlive

With the path configured, you can now generate animation files directly from your project bin.

  1. Right-click on an empty space in the Project Bin in Kdenlive.
  2. Select Create Animation (or go to Project > Create Animation in the top menu).
  3. A dialog box will appear. Choose a file name and save location for your new animation (usually in .rawr or .lottie format).
  4. Set the desired duration and frame rate for the animation clip.
  5. Click OK. The new animation clip will appear in your Project Bin.

Step 3: Edit the Animation in Glaxnimate

Kdenlive makes it easy to jump back and forth between editing your video and refining your vector graphics.

  1. Drag the newly created animation clip from the Project Bin onto your timeline.
  2. Right-click the clip in the timeline or the Project Bin and select Edit Clip.
  3. Glaxnimate will automatically launch and open the specific animation file.
  4. Use Glaxnimate’s vector tools to design your shapes, paths, text, and keyframe animations.

Step 4: Save and Sync Changes

The integration features a live sync workflow that updates your video preview automatically.

  1. Once you are finished editing in Glaxnimate, save your work by pressing Ctrl + S (or Cmd + S on macOS) or selecting File > Save.
  2. Switch back to Kdenlive.
  3. The timeline preview in Kdenlive will automatically refresh to reflect the changes you made in Glaxnimate. You do not need to manually re-import the file.
