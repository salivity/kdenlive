How to Change Project Frame Rate in Kdenlive

Adjusting the master project frame rate in Kdenlive after clips have already been placed on the timeline can be done directly through the project settings, by migrating the timeline to a new project profile, or by modifying the project XML file. This guide outlines the most effective methods to change your project's frame rate without losing your current edit or clip placements.

Method 1: Change Frame Rate via Project Settings

In modern versions of Kdenlive, you can adjust the project profile directly from the menu bar:

  1. Click on Project in the top menu and select Project Settings.
  2. Go to the Settings tab.
  3. Under the Profiles list, browse and select the preset that matches your desired resolution and frame rate (FPS).
  4. Click OK.
  5. Kdenlive will prompt a confirmation asking to adjust the project. Confirm the change.

Note: Changing the frame rate on an active timeline may cause slight shifts in cut points or transitions due to how frames are recalculated. Always save a backup copy of your project before applying this change.

Method 2: Copy the Timeline to a New Project Profile

If changing the profile within the current project causes timing errors or if the project settings option is restricted:

  1. Select all items on your timeline by pressing Ctrl + A.
  2. Copy the clips by pressing Ctrl + C.
  3. Go to File > New to create a new project.
  4. In the project setup window, choose the target FPS / Frame Rate profile you require.
  5. Click OK to open the blank project.
  6. Position the playhead at the start of the timeline and press Ctrl + V to paste all clips, cuts, tracks, and transitions into the new frame rate environment.
  7. Save the new project with a new file name.

Method 3: Edit the .kdenlive Project File

If Kdenlive prevents switching profiles due to existing timeline media, you can manually update the project file:

  1. Save and close your Kdenlive project.
  2. Create a backup copy of your .kdenlive project file.
  3. Open the .kdenlive file in a plain text editor such as Notepad, TextEdit, or VS Code.
  4. Locate the <profile> tag near the top of the XML code.
  5. Update the frame_rate_num and frame_rate_den attributes to match your target frame rate (for example, frame_rate_num="60" and frame_rate_den="1" for 60 FPS, or frame_rate_num="30000" and frame_rate_den="1001" for 29.97 FPS).
  6. Update the description field to match the standard MLT profile name if necessary.
  7. Save the file and reopen it in Kdenlive.
