How to Clean Uninstall Kdenlive on Mac

Removing Kdenlive from your Mac involves more than just dragging the application icon to the Trash. To perform a truly clean uninstallation, you must also locate and delete associated configuration files, caches, and application support data hidden within your macOS Library folders. This guide provides a straightforward, step-by-step process to completely remove Kdenlive and all its leftover data from your macOS system.

Step 1: Quit Kdenlive

Before deleting any files, ensure that Kdenlive is not running in the background.

  1. If the app is open, press Command + Q to quit it.
  2. If it is frozen, press Option + Command + Escape, select Kdenlive from the list, and click Force Quit.

Step 2: Remove the Kdenlive Application

  1. Open Finder and navigate to the Applications folder.
  2. Locate the Kdenlive icon.
  3. Drag the Kdenlive icon to the Trash, or right-click it and select Move to Trash.

Step 3: Delete Leftover Kdenlive Files and Folders

To perform a clean uninstall, you must delete the service files stored in your user Library.

  1. Open Finder.
  2. Click on Go in the top menu bar, then select Go to Folder... (or press Command + Shift + G).
  3. Type or paste the following path into the search bar and press Enter: ~/Library
  4. Search for files and folders related to Kdenlive in the following specific directories and move them to the Trash:
  • Application Support: Navigate to ~/Library/Application Support/ and delete the kdenlive folder.
  • Caches: Navigate to ~/Library/Caches/ and delete any folders named kdenlive or org.kde.kdenlive.
  • Preferences: Navigate to ~/Library/Preferences/ and delete kdenliverc and any files starting with org.kde.kdenlive.plist.
  • Saved Application State: Navigate to ~/Library/Saved Application State/ and delete the folder named org.kde.kdenlive.savedState.

(Note: The tilde ~ represents your user home folder. Be careful to only delete files associated with Kdenlive to avoid affecting other applications.)

Step 4: Empty the Trash

Once you have moved the application and all associated directories to the Trash, you must permanently delete them.

  1. Right-click on the Trash icon in your Dock.
  2. Select Empty Trash and confirm the action.

Kdenlive is now completely and cleanly uninstalled from your macOS system.
