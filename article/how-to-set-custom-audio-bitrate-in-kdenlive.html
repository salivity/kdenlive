How to Set Custom Audio Bitrate in Kdenlive

Exporting projects with specific audio requirements in Kdenlive requires adjusting FFmpeg parameters through custom render profiles. This guide outlines the straightforward process of accessing Kdenlive's render settings, modifying the audio bitrate commands, and saving custom presets for both video and audio-only exports.

1. Open the Render Window

Open your project in Kdenlive and access the Render dialog by clicking the Render button in the main toolbar or by pressing Ctrl + Return (Cmd + Return on macOS).

2. Create a Custom Profile

To modify FFmpeg arguments, you must create a new rendering profile based on an existing one:

  1. Select the format category you wish to use (such as Generic (mp4) or Audio only).
  2. Highlight a preset that closely matches your desired output format.
  3. Click the Create New Profile icon (the document icon with a plus sign) located next to the preset selection menu.

3. Modify the FFmpeg Audio Bitrate Parameter

In the profile creation window, you will see the profile name, file extension, and a text box containing the FFmpeg command-line parameters.

  1. Locate the audio bitrate parameter in the Parameters box. This is typically written as ab=%audiobitrate or b:a=%audiobitrate in standard presets.
  2. Replace the variable with your desired fixed bitrate value (e.g., ab=320k, b:a=256k, or b:a=128k).
  3. Ensure the audio codec is defined properly (e.g., acodec=aac or acodec=libmp3lame).

4. Save and Apply the Profile

  1. Enter a descriptive name in the Profile Name field (e.g., MP4 - High Quality 320k Audio).
  2. Click OK to save the new profile to your custom list.

5. Render Your Project

Select your newly created profile from the list, designate your output file destination, and click Render to File. Kdenlive will execute FFmpeg using your specified custom audio bitrate parameters.
