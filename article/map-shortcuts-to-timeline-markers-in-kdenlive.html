Map Shortcuts to Timeline Markers in Kdenlive

This guide explains how to map custom keyboard shortcuts in Kdenlive to quickly jump between timeline markers and guides. By assigning dedicated keys to marker navigation actions, you can significantly accelerate your timeline editing workflow and move between specific reference points without using the mouse.

Understanding Markers and Guides in Kdenlive

In Kdenlive, points of interest on the main project timeline are referred to as Guides, while Markers typically apply to individual source clips in the Project Bin. To jump between reference points on your timeline, you will configure shortcuts for Guide navigation.

Step-by-Step Configuration

  1. Open the Shortcuts Menu

    • Launch Kdenlive.
    • Go to the top menu and select Settings > Configure Keyboard Shortcuts... (or press Ctrl + Alt + , on Linux/Windows).

  2. Search for Guide Navigation Commands

    • In the search bar at the top of the shortcut configuration window, type Guide.
    • Look for the navigation actions:
      • Go to Previous Guide
      • Go to Next Guide
      • Specific numbered guide navigation commands (if available in your installed Kdenlive version).

  3. Assign Custom Keys

    • Click on the action you wish to customize (e.g., Go to Next Guide).
    • Select the Custom radio button.
    • Click the shortcut button (which defaults to None or the existing key) and press your preferred key combination on your keyboard (for example, Ctrl + Right Arrow or Alt + N).
    • If a conflict warning appears, choose a different combination or overwrite the conflicting command.

  4. Apply the Changes

    • Click OK or Apply to save your new keyboard shortcuts.

Navigating on the Timeline

Once configured, add guides to your timeline by right-clicking the timeline ruler and selecting Add Guide (or using the default shortcut G). Use your newly assigned shortcut keys to immediately jump the playhead back and forth across your marked points.
