Create Custom Wipe Transitions in Kdenlive

Custom wipe transitions in Kdenlive allow video editors to create unique, stylized scene changes using black and white PNG gradient maps. Kdenlive interprets the grayscale luminance values of the image—transitioning from pure black (0% brightness) to pure white (100% brightness)—to determine the sequence, shape, and softness of the wipe. By designing a custom grayscale image and loading it as a luma map, you can create virtually any transition pattern, from geometric sweeps to organic texture reveals.

1. Design the Grayscale Gradient Map

To create the transition asset, use an image editor such as GIMP, Photoshop, or Inkscape:

  1. Set the Resolution: Create a new canvas matching your Kdenlive project aspect ratio and resolution (e.g., 1920x1080 for Full HD).
  2. Use Grayscale Only: Design your transition using only black, white, and shades of gray.
    • Black areas will transition first.
    • White areas will transition last.
    • Gradients/Gray values create smooth, feathered edges between the scenes. Hard edges between black and white will create sharp, distinct cut lines.
  3. Export the File: Export the image as a standard black-and-white or grayscale .png file.

2. Add the Custom PNG to Kdenlive

You can use the custom wipe file directly in your project or install it permanently into Kdenlive's luma transition library.

Method A: Direct File Selection (Per Project)

  1. Place two video clips on overlapping tracks on the Kdenlive timeline (e.g., Video Track 1 and Video Track 2).
  2. Add a Wipe composition between the overlapping sections of the two clips.
  3. Select the Wipe transition block on the timeline to open its Properties pane.
  4. In the properties panel, locate the transition type dropdown and select Custom.
  5. Click the folder icon to browse your file system and select your custom grayscale PNG.

Method B: Permanent Installation (All Projects)

To make your custom wipe permanently available in the dropdown menu:

  • Linux: Copy the PNG file to ~/.local/share/kdenlive/lumas/HD/
  • Windows: Copy the PNG file to %APPDATA%\kdenlive\lumas\HD\
  • Restart Kdenlive, and your file will appear in the default Wipe composition dropdown list.

3. Adjust Transition Parameters

Once applied, fine-tune the transition behavior in the Wipe properties panel:

  • Invert: Flips the wipe direction, making white areas transition before black areas.
  • Softness: Adjusts the feathering along the gradient edge. Increasing softness blurs the transition boundary for a smoother look, while reducing it to zero creates a hard, crisp edge.
  • Duration: Change the length of the transition by dragging the edges of the Wipe composition block on the timeline.
