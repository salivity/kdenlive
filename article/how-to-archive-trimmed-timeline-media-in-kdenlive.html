How to Archive Trimmed Timeline Media in Kdenlive

Archiving a project in Kdenlive allows video editors to save substantial storage space by consolidating the project file with only the media segments used in the timeline. This guide outlines the exact steps to export a consolidated project archive containing only your trimmed timeline media, stripping out unused footage and assets for efficient backups or project handoffs.

Step 1: Open the Project Archive Tool

  1. Open your completed project in Kdenlive.
  2. Ensure your timeline cuts, edits, and transitions are finalized.
  3. In the top menu bar, click on Project and select Archive Project.

Step 2: Choose the Destination and Archive Format

  1. In the Archive Project dialog, select your destination directory under Archive to.
  2. Choose your preferred output structure:
    • Extract to directory: Keeps files uncompressed in a standard folder.
    • Tar.gz archive / Zip: Compresses the files into a single backup file.

Step 3: Configure Timeline-Only Settings

  1. Check the box labeled Only clips in timeline to exclude any unused assets currently sitting in the Project Bin.
  2. Check the box labeled Include proxy clips only if you intend to work purely on lightweight files, or leave it unchecked to process source media.

Step 4: Enable Clip Trimming

  1. Check the option for Extract trimmed clips (or Trim clips).
  2. Set the desired Extra frames (handle frames). Adding 25 to 50 extra frames ensures you have padding around cut points if you need to make minor trim adjustments later.
  3. Review the estimated archive size displayed at the bottom of the window to verify the storage reduction.

Step 5: Run the Archiving Process

  1. Click Start to initiate the consolidation.
  2. Kdenlive will cut the media segments according to your timeline in/out points, copy the trimmed media files to the target destination, and generate a new .kdenlive project file linked exclusively to the new trimmed clips.
  3. Once complete, open the newly created project file from the archive destination to verify that all media plays back correctly without missing file errors.
