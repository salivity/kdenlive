Display Clip File Names in Kdenlive

Using the Dynamic Text effect in Kdenlive allows video editors to automatically overlay clip metadata, such as source file names, directly onto the video preview and final render. This automated approach eliminates the need to create manual text titles for every cut, saving significant time during preview generation, client reviews, and multi-clip editing workflows. The following guide provides the exact steps required to apply and configure this effect.

Step 1: Add Media to the Timeline

  1. Open Kdenlive and add your video or audio clips to the Project Bin.
  2. Drag and drop the target clip onto a video track in the Timeline.

Step 2: Locate and Apply the Dynamic Text Effect

  1. Navigate to the Effects tab (typically located in the bottom-left or tabbed alongside the Project Bin).
  2. Use the search bar at the top of the Effects panel and type Dynamic Text.
  3. Drag the Dynamic Text effect from the list directly onto your clip in the timeline, or select the clip and double-click the effect.

Step 3: Configure the Text to Show File Names

  1. Select the clip on the timeline and open the Effect/Composition Stack panel.
  2. In the Dynamic Text settings, find the main text input field.
  3. Replace any default text or timecode strings with the file name keyword:
    • Type #filename# (or select File Name from the predefined dynamic keywords dropdown menu, depending on your Kdenlive version).
  4. Kdenlive will immediately parse the keyword and display the actual source file name on the video monitor.

Step 4: Adjust Formatting and Positioning

  1. Font and Size: Choose your preferred font family, size, weight, and color.
  2. Background: Enable an outline or background box (such as a semi-transparent black rectangle) to ensure the text remains legible over varied background footage.
  3. Alignment: Set the horizontal and vertical alignment (e.g., bottom-left, top-right, or centered).
  4. Padding and Offsets: Adjust the X and Y coordinates to place the text precisely where it will not obscure essential visual elements.

Applying to an Entire Track

To display file names automatically for every clip on a timeline without adding the effect individually to each one:

  1. Click the header of the video track (e.g., V1 or V2).
  2. Drag the Dynamic Text effect directly onto the track header.
  3. Configure the #filename# keyword in the track's effect settings. The text will now dynamically update as the playhead moves across different clips along that entire track.
