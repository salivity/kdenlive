How to Import a Sequence from Another Kdenlive Project

Reusing timelines and assets across different video editing projects can save a significant amount of post-production time. This guide provides a direct, step-by-step method to import a nested sequence or timeline from an entirely different Kdenlive project file into your current workspace.

Step 1: Open Your Active Project

Start by launching Kdenlive and opening the current project where you want to import the external sequence.

Step 2: Import the External Kdenlive File as a Clip

Kdenlive allows you to treat external project files (.kdenlive) as standard video clips.

  1. Go to the Project Bin panel.
  2. Click the Add Clip or Folder button (the paperclip icon), or right-click inside the Project Bin and select Add Clip or Folder.
  3. In the file browser, navigate to the location of the other Kdenlive project file you want to import.
  4. Select the .kdenlive file and click Open.

Step 3: Select the Desired Sequence

If the project you are importing contains multiple sequences, Kdenlive will prompt you with a dialog box. From this window, select the specific sequence or timeline you wish to import. If the external project only has one main timeline, it will load directly into your Project Bin.

Step 4: Add the Nested Sequence to Your Timeline

Once the project file appears in your Project Bin, it will function as a grouped "Project Clip."

  1. Click and hold the imported project clip in the Project Bin.
  2. Drag and drop it onto your active timeline.

The imported project will now behave as a single, nested sequence. You can move it, cut it, and apply effects to it just like any other video clip.

How to Edit the Imported Sequence

If you need to make changes to the nested sequence:

  • Right-click the nested clip in your Project Bin or timeline and select Edit Clip.
  • This will open the original Kdenlive project file in a separate window. Any changes you save in the original file will automatically update inside your current active project.
