Setup AMD AMF Hardware Encoding in Kdenlive Linux

This article provides a step-by-step guide to configuring hardware-accelerated video encoding using AMD Advanced Media Framework (AMF) in Kdenlive on Linux systems. By installing the necessary driver components, verifying FFmpeg integration, and setting up the appropriate render profiles within Kdenlive, you can significantly reduce export times and offload rendering tasks to your AMD graphics card.

1. Install AMD AMF Driver Components

To use AMF on Linux, your system requires the proprietary AMD AMF runtime components alongside your graphics drivers.

  • Ubuntu/Debian-based systems: Install the AMDGPU-PRO driver packages or install the AMF component directly from the official AMD driver installer using the --opencl=rocr --amf flags.
  • Arch Linux: Install the AMF runtime from the AUR via packages such as amf-amdgpu-pro or lib32-amf-amdgpu-pro.
  • Fedora/RHEL: Install the proprietary AMF wrapper packages available through compatible RPM repositories or the AMD proprietary installer.

2. Verify FFmpeg AMF Support

Kdenlive uses FFmpeg on the backend for encoding tasks. Your installed FFmpeg build must be compiled with the --enable-amf flag. Verify that your system's FFmpeg installation supports AMF encoders by running the following command in your terminal:

ffmpeg -encoders | grep amf

Ensure the output lists h264_amf (for H.264 encoding) and hevc_amf (for HEVC/H.265 encoding). If these encoders do not appear, install a custom build of FFmpeg compiled with AMF support or use a distribution package that includes AMF enabled by default.

3. Detect Hardware Encoders in Kdenlive

Once the drivers and FFmpeg are configured, configure Kdenlive to detect your hardware:

  1. Launch Kdenlive.
  2. Navigate to Settings > Configure Kdenlive... from the top menu.
  3. Select the Environment tab on the left sidebar.
  4. Open the Hardware Acceleration tab.
  5. Click Check hardware acceleration to scan for available encoders.
  6. Verify that AMD AMF is recognized by the system.

4. Create an AMF Render Profile in Kdenlive

After detection, set up a hardware-accelerated render profile to use during export:

  1. Open your project and click the Render button (or press Ctrl + Return).
  2. In the Render dialog, look for hardware-accelerated presets under the Hardware Accelerated or Generic categories (e.g., AMD AMF H264 or AMD AMF HEVC).
  3. If no pre-configured AMF profile appears, click the Create New Profile (plus icon) button to build a custom preset.
  4. Set the Extension to mp4.
  5. Enter the following parameters into the Parameters box for H.264: 
    properties=x264-medium f=mp4 vcodec=h264_amf b=%bitrate+'k' acodec=aac ab=%audiobitrate+'k'
  6. For HEVC/H.265 encoding, use: 
    properties=x265-medium f=mp4 vcodec=hevc_amf b=%bitrate+'k' acodec=aac ab=%audiobitrate+'k'
  7. Name the profile (e.g., "AMD AMF H.264") and click OK to save.

5. Render Using AMD AMF

To export your project:

  1. Select your newly created AMD AMF profile from the Render list.
  2. Adjust your desired output path, resolution, and average video bitrate.
  3. Click Render to File.
  4. Monitor GPU utilization using tools such as radeontop to confirm that the video encoding block on your AMD GPU is actively processing the export.
