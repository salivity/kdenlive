Kdenlive Dynamic Text Effect: Displaying Metadata

The "Dynamic Text" effect in Kdenlive is a versatile tool that allows video editors to automatically overlay real-time metadata directly onto their video tracks. This article explains the primary functions of the Dynamic Text effect, explores the types of metadata it can display—such as timecodes, frame numbers, and file information—and outlines how to use it to improve your editing and review workflows.

Primary Function of Dynamic Text

The main purpose of the Dynamic Text effect in Kdenlive is to generate and update text overlays automatically based on the properties of the video project or source files. Instead of manually typing static text, editors use dynamic variables (tags) that automatically extract and render information relative to the playhead's current position on the timeline.

This is highly useful for creating "timecode burns" (window dubs) during the rough-cut phase, allowing clients or collaborators to reference specific frames or times when giving feedback.

Key Metadata Types You Can Display

The Dynamic Text effect can read and display several types of metadata through specific keywords:

  • Timecode (#timecode#): Displays the current timeline or source clip timecode in the standard hours:minutes:seconds:frames (HH:MM:SS:FF) format.
  • Frame Number (#frame#): Shows the exact frame number of the current position, which is crucial for VFX alignment and frame-accurate editing.
  • File Name (#filename#): Displays the original name of the source video clip, helping editors keep track of source assets during complex multi-camera or multi-clip edits.
  • Date and Time (#date#): Extracts and renders the creation date and time of the source file or the current system time.

How to Apply and Configure the Effect

Using the Dynamic Text effect is straightforward and highly customizable:

  1. Add the Effect: Search for "Dynamic Text" in the Effects tab and drag it onto a clip on your timeline, or apply it to an entire track if you want a global overlay.
  2. Select the Metadata: In the Effect Properties panel, choose from the pre-configured templates (such as Timecode or Frame) or write custom text combined with metadata tags.
  3. Style the Overlay: Adjust the font size, color, alignment, and background rectangle opacity to ensure the metadata is legible against different video backgrounds.
