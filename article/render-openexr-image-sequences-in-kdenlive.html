Render OpenEXR Image Sequences in Kdenlive

Exporting your timeline as an OpenEXR image sequence in Kdenlive allows you to preserve high dynamic range data, wide color gamuts, and uncompressed visual fidelity for compositing and visual effects workflows. This guide covers the exact step-by-step procedure to configure the render settings, apply proper frame numbering syntax, and export your project directly into individual EXR frames.

Step 1: Open the Render Menu

Once your project timeline is finalized, open the render interface by clicking the Render button in the main toolbar, navigating to Project > Render in the top menu, or pressing the keyboard shortcut Ctrl + Return (Windows/Linux) or Cmd + Return (macOS).

Step 2: Select the Image Sequence Preset

  1. In the Render dialog box, locate the Presets panel on the left.
  2. Expand the Images or Image Sequence category.
  3. Look for an OpenEXR or EXR preset. If no dedicated EXR preset appears, select the generic Image sequence profile.

Step 3: Configure EXR Output and Codec Settings

If you are configuring a generic image profile or customizing output quality:

  1. Click the Edit Profile button (or create a custom profile) to ensure FFmpeg utilizes the OpenEXR encoder.
  2. In the profile parameters, verify that the video codec is set to exr (e.g., -vcodec exr).
  3. If specific compression is required (such as ZIP, PIZ, or RLE), you can pass corresponding FFmpeg flags via the custom parameters field.

Step 4: Define File Path and Frame Numbering

  1. In the Output file field, choose a dedicated destination folder to prevent cluttering directories with individual image files.
  2. Name your sequence using standard sequence syntax with numerical padding. For example, enter frame_%05d.exr.
    • The %05d token ensures a five-digit, zero-padded sequence (e.g., frame_00001.exr, frame_00002.exr).
    • Ensure the file extension is explicitly set to .exr.

Step 5: Set Render Zone and Export

  1. Under Render options, choose whether to render the Full Project or only the Selected Zone marked by your In/Out points.
  2. Select your desired frame rate and resolution to ensure they match your composition requirements.
  3. Click Render to File to begin generating the OpenEXR image sequence.
