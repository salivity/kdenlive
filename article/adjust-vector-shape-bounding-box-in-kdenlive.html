Adjust Vector Shape Bounding Box in Kdenlive

This guide explains how to select, resize, reposition, and precisely adjust the bounding box properties of vector shapes using Kdenlive’s built-in Title Tool. Whether you need freehand transformations directly on the canvas or exact pixel-based adjustments through numerical property controls, mastering these settings ensures clean, professional graphic overlays for your video projects.

Accessing the Title Tool and Selecting Vector Shapes

To begin modifying a shape's bounding box, open your title clip in Kdenlive:

  1. Right-click the Project Bin, select Add Title Clip, or double-click an existing title clip in your timeline or bin.
  2. Select the Rectangle or Ellipse tool from the top toolbar to draw a new vector shape, or click the Selection Tool (the arrow icon) to interact with an existing shape.
  3. Click directly on the shape on the canvas. A bounding box with transformation handles will appear around the object.

Direct Canvas Adjustments

Once the bounding box is active, you can manipulate the vector shape interactively:

  • Resize/Scale: Click and drag any of the outer control points (handles) on the corners or sides. Dragging a corner handle scales both width and height simultaneously, while dragging a side handle adjusts only that specific dimension.
  • Constrain Proportions: Hold Shift while dragging a corner handle to maintain the original aspect ratio of the shape.
  • Reposition: Click anywhere inside the bounding box (away from the handles) and drag the shape to its new location on the canvas.

Numeric and Coordinate Adjustments

For pixel-perfect layout adjustments, use the property fields located in the top and side toolbars of the Title Tool window:

  • X and Y Coordinates: Change the horizontal (\(X\)) and vertical (\(Y\)) input values to move the bounding box precisely across the canvas.
  • Width (W) and Height (H): Enter explicit pixel dimensions in the width and height boxes to resize the vector shape without manual dragging.
  • Rotation: Use the rotation angle input (if available in your Kdenlive version) to rotate the bounding box around its center origin.

Alignment and Stacking Order

The Title Tool provides automated alignment buttons that reference the canvas boundaries:

  • Canvas Alignment: Use the horizontal and vertical alignment icons in the toolbar to instantly snap the bounding box to the center, top, bottom, left, or right of the screen.
  • Layer Hierarchy (Z-Index): If multiple shapes or text elements overlap, use the Raise object to top, Raise object one step, Lower object one step, or Lower object to bottom buttons to adjust which vector's bounding box sits in front of or behind other elements.
