How to Create Web-Optimized AV1 Presets in Kdenlive

This guide provides a step-by-step walkthrough on setting up custom AV1 render presets in Kdenlive for high-efficiency web streaming. By leveraging modern AV1 encoders like SVT-AV1 alongside web-friendly container configurations, you can generate lightweight, high-visual-fidelity videos optimized for fast browser playback and bandwidth efficiency.

Step 1: Open the Render Window

  1. Open your project in Kdenlive.
  2. Click the Render button in the main toolbar or press Ctrl + Enter.
  3. In the Render dialog, ensure the Render Project tab is selected.

Step 2: Create a New Custom Preset

  1. In the Presets section, look for the toolbar icons above or beside the preset list.
  2. Click the Create New Profile (plus icon) button to open the Profile Editor.
  3. Enter a descriptive name in the Profile Name field, such as AV1 Web Optimized (MP4).
  4. Set the Group to Custom or Web to keep your workspace organized.

Step 3: Configure Encoder Parameters

In the Parameters box, enter the specific FFmpeg and MLT arguments to control the AV1 encoding process.

For an MP4 container with SVT-AV1 and Opus audio:

f=mp4
vcodec=libsvtav1
crf=28
preset=6
g=240
movflags=+faststart
pix_fmt=yuv420p
acodec=libopus
ab=128k
ar=48000

For a WebM container alternative:

f=webm
vcodec=libsvtav1
crf=28
preset=6
g=240
pix_fmt=yuv420p
acodec=libopus
ab=128k
ar=48000

Step 4: Key Settings Explained

  • vcodec=libsvtav1: Uses the scalable SVT-AV1 encoder for balanced speed and compression. If hardware acceleration is supported by your GPU, you can swap this with av1_nvenc (NVIDIA) or av1_amf (AMD).
  • crf=28: Constant Rate Factor. Controls quality. Lower values (e.g., 24) yield higher quality at the cost of file size; higher values (e.g., 32) reduce file size.
  • preset=6: Balances encoding speed and compression efficiency in SVT-AV1. Values range from 0 (slowest/most efficient) to 12 (fastest). Presets 5 to 7 are ideal for web output.
  • g=240: Keyframe interval (GOP size). Setting this to roughly 2–10 seconds worth of frames (240 frames at 24/30 fps) improves streaming seek times.
  • movflags=+faststart: Relocates the video index (moov atom) to the beginning of the MP4 file, allowing web browsers to start playback before the full file finishes downloading.
  • acodec=libopus / ab=128k: Encodes high-quality streaming audio at low bitrates.

Step 5: Save and Render

  1. Click OK to save the custom profile.
  2. Select your newly created preset from the list.
  3. Specify your output file path in the Output file field.
  4. Click Render to File to export your web-optimized AV1 video.
