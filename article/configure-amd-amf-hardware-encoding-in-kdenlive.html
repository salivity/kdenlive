Configure AMD AMF Hardware Encoding in Kdenlive

Configuring AMD Advanced Media Framework (AMF) in Kdenlive allows you to leverage your AMD GPU's dedicated hardware encoder (VCE or VCN) to significantly accelerate video rendering and reduce CPU load. This guide explains the required prerequisites, how to set up custom render profiles using the h264_amf and hevc_amf codecs, and how to verify that hardware acceleration is operating correctly.

Prerequisites

Before configuring Kdenlive, ensure your system meets the following requirements:

  1. Compatible AMD GPU: A graphics card with a Video Coding Engine (VCE) or Video Core Next (VCN) chip.
  2. AMD Drivers: The latest AMD Adrenalin drivers on Windows, or the AMDGPU driver stack with AMF components installed on Linux.
  3. FFmpeg with AMF Support: Kdenlive relies on FFmpeg for encoding. Your FFmpeg build must be compiled with the --enable-amf flag (included by default in official Windows builds and many Linux distributions).

To verify AMF support in your FFmpeg installation, run the following command in a terminal or command prompt:

ffmpeg -encoders | grep amf

Look for h264_amf and hevc_amf in the output list.

Setting Up AMF Render Profiles in Kdenlive

If your Kdenlive installation does not automatically list AMD hardware profiles, you can manually create custom AMF render presets.

Step 1: Open the Render Configuration

  1. Open your project in Kdenlive.
  2. Click the Render button in the main toolbar or press Ctrl + Return.
  3. In the Render dialog, click the Create New Profile button (represented by a plus icon or document icon next to the presets list).

Step 2: Create an H.264 AMF Profile

  1. Set the Group to Hardware Accelerated or Custom.
  2. Name the profile (e.g., MP4 - H.264 (AMD AMF)).
  3. Set the Extension to mp4.
  4. In the Parameters box, enter the following FFmpeg string:
f=mp4 vcodec=h264_amf acodec=aac ab=192k vb=%bitrate+'k' quality=balanced

Step 3: Create an HEVC (H.265) AMF Profile

For higher efficiency and smaller file sizes, create an HEVC profile:

  1. Click Create New Profile.
  2. Name the profile (e.g., MP4 - HEVC (AMD AMF)).
  3. Set the Extension to mp4.
  4. In the Parameters box, enter:
f=mp4 vcodec=hevc_amf acodec=aac ab=192k vb=%bitrate+'k' quality=balanced
  1. Click Save to apply the profile.

Tuning AMF Encoder Parameters

You can customize the encoding performance and visual quality by modifying the profile parameters:

  • Rate Control (rc): Specify rate control modes such as rc=cbr (Constant Bitrate) or rc=vbr_latency / rc=vbr_peak (Variable Bitrate).
  • Quality Preset (quality): Options include speed, balanced, and quality. Use quality=quality for the best visual output or quality=speed for the fastest rendering times.
  • Keyframe Interval (g): Set standard GOP size (e.g., g=60 for a 60-frame GOP size).

Rendering and Verification

  1. Select your newly created AMF profile in the Render window.
  2. Choose your output destination and target bitrate.
  3. Click Render to File.
  4. Open the Windows Task Manager (Performance tab > GPU > Video Encode) or use radeontop on Linux to verify that the GPU's dedicated video encoder is being utilized during the export process.
