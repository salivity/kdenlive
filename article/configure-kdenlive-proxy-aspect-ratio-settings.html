Configure Kdenlive Proxy Aspect Ratio Settings

When working with diverse video footage in Kdenlive, mismatched aspect ratios between source files and project profiles can result in distorted, stretched, or incorrectly cropped proxy files. This guide details how to adjust Kdenlive's proxy encoding profiles and project settings to ensure generated proxy clips automatically conform to the correct source aspect ratios without visual distortion.

Accessing Proxy Configuration in Kdenlive

Proxy settings can be configured globally for all future projects or specifically for the current project.

  1. Open Kdenlive.
  2. For global settings, navigate to Settings > Configure Kdenlive from the top menu, then select the Proxy Clips tab on the left.
  3. For project-specific settings, go to Project > Project Settings and select the Proxy tab.

Enabling and Conforming Proxy Profiles

To ensure proxy clips scale dynamically without enforcing rigid dimensions that distort non-standard aspect ratios (such as vertical 9:16 or anamorphic video):

  1. Check the box labeled Enable proxy clips.
  2. Locate the Proxy profile dropdown menu.
  3. Click the Manage proxy profiles (wrench/edit icon) button next to the profile dropdown to view the underlying FFmpeg commands used for proxy generation.

Editing FFmpeg Parameters for Dynamic Aspect Ratios

Standard proxy profiles often use fixed scaling parameters (e.g., -vf scale=640:-1 or fixed width/height values) that can conflict with certain pixel aspect ratios (PAR) or display aspect ratios (DAR).

To automatically conform mismatched aspect ratios, create or edit a custom profile:

  1. Click the Add new profile button.
  2. Name the profile (e.g., Dynamic Conforming Proxy).
  3. In the Parameters field, modify the video filter (-vf) argument to dynamically calculate dimensions while preserving the original aspect ratio. Use: 
    -vf scale='min(1280,iw)':'-2' -c:v libx264 -preset ultrafast -crf 23 -c:a aac
    • The min(1280,iw) formula scales the width down to a maximum of 1280 pixels only if the source is larger, maintaining native width for smaller clips.
    • The '-2' flag ensures the height is automatically calculated to preserve the source aspect ratio while remaining divisible by 2 (a requirement for most video codecs).
  4. For strictly vertical or mixed-orientation footage, use FFmpeg's force_original_aspect_ratio parameter: 
    -vf scale=1280:720:force_original_aspect_ratio=decrease,pad=1280:720:(ow-iw)/2:(oh-ih)/2 -c:v libx264 -preset ultrafast -crf 23 -c:a aac
  5. Click OK to save the custom profile and set it as the active profile.

Correcting Existing Proxy Clips

If existing project clips display mismatched aspect ratios:

  1. Right-click the affected clip in the Project Bin.
  2. Select Clip Properties.
  3. Under the Video Properties tab, verify that the Aspect Ratio matches the source file's native ratio. Adjust if set incorrectly.
  4. Navigate to the Proxy section in Clip Properties, uncheck Proxy Clip to delete the old proxy, and then re-check Proxy Clip to regenerate it using the updated configuration.
