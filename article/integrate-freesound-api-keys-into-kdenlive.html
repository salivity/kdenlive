Integrate Freesound API Keys into Kdenlive

Integrating a Freesound API key into Kdenlive allows video editors to search, preview, and import thousands of high-quality, royalty-free sound effects directly within the video editing interface. This guide provides a clear, step-by-step walkthrough on how to obtain your API key from Freesound and configure it inside Kdenlive to streamline your audio workflow.

Step 1: Obtain Your Freesound API Key

To connect Kdenlive to Freesound's library, you must first generate an API key from the Freesound website.

  1. Go to the official Freesound website and log into your account (or create a free account if you do not have one).
  2. Navigate to the Freesound API section by visiting freesound.org/apiv2/apply or clicking on the "Developers" link at the bottom of the homepage.
  3. Click on Apply for a new credentials or Create a new client.
  4. Fill out the brief application form. For the "Project Name," you can enter "Kdenlive Integration." For the "Description," write a simple sentence such as "Integrating Freesound search into Kdenlive for video editing."
  5. Submit the form. Your request is usually approved instantly, and your new credentials will be displayed.
  6. Copy the Client Key (also referred to as the API Key or Token).

Step 2: Configure Kdenlive with the API Key

Once you have copied your key, you need to input it into Kdenlive to unlock the search functionality.

  1. Open Kdenlive.
  2. Ensure the Online Resources widget is visible. If you do not see it, go to the top menu and select View > Online Resources to enable the panel.
  3. In the Online Resources panel, click on the dropdown menu at the top and select Freesound.
  4. Click on the Configure button (represented by a gear icon) within the Online Resources panel.
  5. In the settings window that appears, paste your copied Freesound API key into the designated API Key or Client Key field.
  6. Click OK or Save to apply the changes.

Step 3: Search and Download Sound Effects

With the integration complete, you can now search and download audio files seamlessly.

  1. Type your desired sound effect (e.g., "explosion," "ambient rain") into the search bar of the Online Resources panel.
  2. Press Enter to search. Kdenlive will display a list of matching results directly from Freesound.
  3. Double-click any sound to preview it, or click the Import button to download the file directly into your Kdenlive Project Bin.
  4. Drag and drop the downloaded audio clip from your Project Bin straight onto your timeline.
