Hardware Accelerated Proxy Clips in Kdenlive

Proxy clips allow you to edit high-resolution video smoothly by using lightweight, lower-resolution copies of your source files during the editing process. By default, Kdenlive uses CPU-based software encoding to generate these proxies, which can be slow on large projects. Configuring Kdenlive to utilize your graphics card’s hardware encoder (such as NVIDIA NVENC, Intel QSV, or AMD/VAAPI) drastically cuts down the time required to create proxy files.

1. Verify Hardware Acceleration Support

Before changing proxy profiles, ensure Kdenlive detects your system's hardware encoding capabilities:

  1. Open Kdenlive and navigate to Settings > Configure Kdenlive (or Kdenlive > Preferences on macOS).
  2. Select the Hardware Acceleration tab on the left.
  3. Check the box for Hardware Accelerated Decoding/Encoding.
  4. Review the detected encoders (e.g., h264_nvenc, hevc_nvenc, h264_vaapi, h264_qsv). Ensure your preferred GPU encoder is listed and functional.

2. Access Proxy Clip Settings

  1. In the same Configure Kdenlive window, select the Proxy Clips tab on the left.
  2. Check the box labeled Enable Proxy Clips.
  3. Set your desired automatic generation conditions, such as Generate for videos larger than (commonly set to 1000 or 1920 pixels).

3. Select or Create a Hardware-Accelerated Profile

Kdenlive uses FFmpeg encoding profiles to render proxies. To switch to a hardware encoder:

  1. Under the Encoding Profile section in the Proxy Clips settings, open the dropdown menu.
  2. Look for pre-configured hardware profiles:
    • NVIDIA: Look for profiles containing NVENC (e.g., H264-NVENC or NVENC Fast).
    • Intel / AMD (Linux): Look for VAAPI profiles (e.g., H264-VAAPI).
    • Intel (Windows): Look for QSV profiles.
  3. If no hardware profile exists in the list, click the Manage Profiles (wrench/edit) icon next to the dropdown to create a custom profile:
    • Click the Add new profile (+) button.
    • Set a profile name (e.g., Hardware NVENC Proxy).
    • Enter the appropriate parameters for your hardware:
      • For NVIDIA: -vf scale=-1:720 -c:v h264_nvenc -preset fast -b:v 2000k -c:a aac -b:a 128k
      • For VAAPI (Linux): -vaapi_device /dev/dri/renderD128 -vf 'format=nv12,hwupload,scale_vaapi=w=-1:h=720' -c:v h264_vaapi -b:v 2000k -c:a aac -b:a 128k
  4. Click OK to save the custom profile and select it as your active proxy encoding profile.

4. Apply Settings and Verify

  1. Click Apply and then OK to exit the configuration menu.
  2. Import a large video file into the Project Bin.
  3. Right-click the clip and select Proxy Clip (if not generated automatically).
  4. Open your system's task manager or GPU monitoring tool to confirm that GPU video engine usage spikes during the generation process, confirming hardware encoding is active.
