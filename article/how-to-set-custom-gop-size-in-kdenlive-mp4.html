How to Set Custom GOP Size in Kdenlive MP4

Setting a custom Group of Pictures (GOP) size in Kdenlive allows video editors to control keyframe intervals for MP4 exports, optimizing deliverables for streaming, precise scrubbing, or platform-specific compliance. This guide outlines the exact steps to modify and save custom FFmpeg encoding parameters in Kdenlive to set fixed GOP lengths, open or closed GOP structures, and all-intra frame sequences.

Understanding GOP in Kdenlive

A Group of Pictures (GOP) defines the distance between full keyframes (I-frames) in compressed video. In Kdenlive, MP4 rendering uses FFmpeg via the MLT framework. The GOP length is controlled by passing standard FFmpeg parameters into the render profile.

  • g=value: Specifies the maximum GOP size in frames (e.g., g=60 means a keyframe at least every 60 frames).
  • keyint_min=value: Specifies the minimum interval between IDR/I-frames.
  • sc_threshold=0: Disables scene-change detection to enforce a strictly fixed GOP length.
  • flags=+cgop: Enforces closed GOPs, which is often required for HLS/DASH streaming workflows.

Step-by-Step Process to Set a Custom GOP Size

1. Open the Render Window

Open your project in Kdenlive and open the rendering dialog by clicking the Render button in the main toolbar or by pressing Ctrl + Return.

2. Select an MP4 Profile

Under the Render Project tab, navigate to the Generic category and select MP4-H264/AAC (or your preferred base MP4 preset).

3. Create or Edit a Render Profile

Kdenlive does not allow overwriting default system presets, so you must create a custom profile:

  1. Click the Create New Profile button (represented by an icon with a plus sign next to a film strip) or click the Edit Profile button.
  2. In the profile configuration window, give your new preset a descriptive name (e.g., MP4 - H.264 Fixed GOP 30).
  3. Ensure the file extension is set to mp4.

4. Insert the GOP Parameters

Locate the Parameters text box containing the FFmpeg/MLT encoding strings. Add or adjust the following arguments:

  • For standard custom GOP (e.g., 2-second interval at 30 fps): 
    g=60
  • For strictly fixed, closed GOP (required for broadcast and adaptive streaming): 
    g=60 keyint_min=60 sc_threshold=0 flags=+cgop
  • For an All-Intra (I-frame only) MP4: 
    g=1

Ensure each parameter is separated by a space and added within the existing parameter string (typically alongside options like vcodec=libx264, crf=..., etc.).

5. Save the Preset and Render

  1. Click OK to save the custom profile.
  2. Select your newly created preset from the list under Custom Profiles.
  3. Choose your output destination and click Render to File.

Verifying the GOP Size

To verify that the custom GOP size was applied correctly to your exported MP4:

  1. Open a terminal or command prompt.
  2. Run ffprobe to inspect frame types: 
    ffprobe -show_frames -select_streams v:0 output.mp4
  3. Check the distance between frames labeled pict_type=I to confirm they match your designated GOP value.
