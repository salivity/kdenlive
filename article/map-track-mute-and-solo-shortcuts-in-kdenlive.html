Map Track Mute and Solo Shortcuts in Kdenlive

Efficiently managing audio and video tracks in Kdenlive often requires quickly isolating or silencing specific layers during playback and editing. This guide explains how to configure custom keyboard shortcuts to instantly toggle track mute and track solo states on the Kdenlive timeline, eliminating the need to manually click track header icons and significantly speeding up your editing workflow.

Accessing the Keyboard Shortcuts Menu

  1. Launch Kdenlive and open any project or create a new one.
  2. In the top application menu bar, click on Settings.
  3. Select Configure Keyboard Shortcuts... from the dropdown menu (or use the default shortcut Ctrl+Alt+, on Linux/Windows).

Locating Track Mute and Solo Commands

  1. In the search bar at the top of the Configure Shortcuts window, type track.
  2. Look through the filtered list of actions to find the specific commands:
    • Toggle Track Mute (or Mute Track)
    • Toggle Track Solo (or Solo Track)
  3. Note that Kdenlive applies these actions to the currently active or selected track on the timeline.

Assigning Custom Keys

  1. Select the action you want to assign (for example, Toggle Track Mute).
  2. Choose the Custom radio button underneath the shortcut details.
  3. Click the button displaying None (or the existing shortcut if one is already defined).
  4. Press the key or combination of keys you want to map (such as M or Alt + M for mute, and S or Alt + S for solo). If a conflict warning appears indicating the key is already in use, choose a different key combination or reassign the conflicting command.
  5. Repeat the process for Toggle Track Solo.
  6. Click OK or Apply at the bottom of the dialog window to save your new configuration.

Using the Shortcuts on the Timeline

To toggle mute or solo states instantly using your new keymaps:

  1. Ensure the timeline is focused.
  2. Select the target track either by clicking its header or using the Select Track Above / Select Track Below shortcuts (by default Up and Down arrow keys).
  3. Press your assigned mute or solo key. The track header icon will immediately update to reflect the muted or soloed state.
