How to Create Custom Luma Transitions in Kdenlive

Custom luma transitions in Kdenlive allow video editors to create dynamic, personalized scene changes using grayscale map images. By using a black and white radial texture, you can produce smooth circular wipes, iris dissolves, and focused reveal effects between overlapping video clips. This guide walks through creating a radial texture image, importing it into Kdenlive, and applying it properly within the timeline.

Step 1: Create the Black and White Radial Texture

A luma transition relies on luminance values, where pure black represents the start of the transition and pure white represents the end (or vice versa).

  1. Open an image editor such as GIMP, Photoshop, or an online gradient generator.
  2. Create a new document matching your video project resolution (for example, 1920x1080 or 3840x2160).
  3. Select the Gradient Tool and set the shape to Radial.
  4. Set the foreground color to solid black (#000000) and the background color to solid white (#FFFFFF).
  5. Click the center of the canvas and drag outward to the edge to draw a smooth radial gradient.
  6. Export or save the image as a standard PNG or PGM file (for example, radial_wipe.png).

Step 2: Import the Custom Texture into Kdenlive

You can place your custom file directly into Kdenlive's user directory so it appears in the preset list:

  • Linux: ~/.local/share/kdenlive/lumas/
  • Windows: %APPDATA%\kdenlive\lumas\

Alternatively, you can load the custom image directly from your project folder through the composition properties panel during editing.

Step 3: Apply the Transition to the Timeline

  1. Place the outgoing clip on an upper video track (e.g., Track V2).
  2. Place the incoming clip on a lower video track (e.g., Track V1), overlapping the two clips for the intended duration of the transition.
  3. Right-click the overlap area on the upper clip, select Add Composition, and choose Wipe.
  4. With the Wipe composition selected, open the Properties panel.
  5. In the Image or Wipe Method dropdown, select your radial texture. If you did not place it in the system directory, click the folder icon to browse and select your saved image file.

Step 4: Adjust Transition Parameters

  • Softness: Increase the softness slider to create a smooth, feathered edge between the clips rather than a hard circular cut.
  • Invert: Check the invert option if you want the transition to expand from the center outward instead of shrinking from the edges inward.
  • Duration: Drag the edges of the composition block on the timeline to speed up or slow down the transition speed.
