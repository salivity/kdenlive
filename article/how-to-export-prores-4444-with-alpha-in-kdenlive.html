How to Export ProRes 4444 with Alpha in Kdenlive

Exporting video with a transparent background in Kdenlive requires using a video codec that supports an alpha channel, such as Apple ProRes 4444. This guide explains how to configure your project timeline, create a custom ProRes 4444 render profile using FFmpeg arguments, and export transparent video files in .mov format without losing color or transparency data.

Step 1: Prepare the Timeline for Transparency

  1. Open your project in Kdenlive.
  2. Ensure there are no solid background clips, black color clips, or opaque tracks underneath the elements you want to remain transparent.
  3. Empty space on the timeline automatically acts as a transparent alpha layer.

Step 2: Create a Custom ProRes 4444 Render Preset

Kdenlive relies on FFmpeg for encoding, but a dedicated ProRes 4444 profile with alpha support is not always enabled by default. You can create one easily:

  1. Open the render menu by clicking Project > Render (or press Ctrl + M).
  2. In the Render window, click the Create New Profile button (the icon with a plus sign or document beside the presets).
  3. Set the Group to Alpha / Transparent (or ProRes).
  4. Set the Profile Name to ProRes 4444 with Alpha.
  5. Set the Extension to mov.
  6. Enter the following encoding parameters into the Parameters box:
f=mov vcodec=prores_ks profile=4 pix_fmt=yuva444p10le vendor=apl0 qscale=4 acodec=pcm_s16le
  • vcodec=prores_ks: Uses the FFmpeg ProRes encoder that supports alpha transparency.
  • profile=4: Sets the encoding level to ProRes 4444.
  • pix_fmt=yuva444p10le: Enables a 10-bit YUV format with an active alpha channel (a).
  • acodec=pcm_s16le: Encodes uncompressed audio.
  1. Click OK or Save to store the preset.

Step 3: Render the Video

  1. In the Render window, select your newly created ProRes 4444 with Alpha profile from the list.
  2. Specify the destination folder and file name in the Output file field.
  3. Ensure Full Project (or Selected Zone) is chosen based on what you need to export.
  4. Click Render to File.

Step 4: Verify the Export

To confirm that the alpha channel rendered properly, import the exported .mov file back into Kdenlive and place it on a track above a colored background or video clip. The background should clearly show through the transparent sections of your ProRes 4444 asset.
