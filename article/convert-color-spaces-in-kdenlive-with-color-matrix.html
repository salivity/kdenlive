Convert Color Spaces in Kdenlive With Color Matrix

Converting color spaces natively in Kdenlive ensures accurate color rendition across various video standards, such as shifting older standard definition footage to modern high-definition workspaces. This guide explains how to locate, apply, and configure the native Color Matrix filter within Kdenlive to correctly transform color coefficients between standards like Rec. 601, Rec. 709, and SMPTE-240M without relying on external transcoding tools.

Why Use the Color Matrix Filter?

Different video standards use different mathematical matrix coefficients to translate RGB color signals into YUV (and vice versa). For instance, standard-definition video uses the BT.601 standard, while high-definition video uses BT.709. If a video is displayed or encoded using the incorrect matrix, colors can appear distorted, oversaturated, or washed out (frequently visible as shifted red and green hues). The Color Matrix filter recalculates these color coordinates natively on your timeline.

Step 1: Add Your Footage to the Timeline

  1. Open Kdenlive and import your source video into the Project Bin.
  2. Drag and drop the clip onto a video track in the Timeline.

Step 2: Apply the Color Matrix Effect

  1. Open the Effects panel (go to View > Effects if it is not visible).
  2. Use the search bar at the top of the Effects panel and type Color Matrix (listed under FFmpeg/avfilter video effects).
  3. Drag the Color Matrix effect directly onto the clip in your timeline, or select the clip and double-click the effect.

Step 3: Configure Source and Target Color Spaces

Select the clip in the timeline and open the Effect/Composition Stack panel to adjust the filter parameters:

  1. Source (Input Space): Set this parameter to match the original color standard of your raw footage.
    • Use bt601 (or smpte170m) for standard-definition (SD) footage, DVDs, or older digital cameras.
    • Use bt709 for standard high-definition (HD) footage.
    • Use smpte240m or fcc if working with specific broadcast archival formats.
  2. Destination (Output Space): Select the target color space standard you want to convert the clip into (most commonly bt709 for modern web and broadcast deliverables).

Step 4: Verify the Color Transform

To ensure the conversion was applied accurately:

  1. Open Kdenlive's built-in analysis tools by navigating to View > Vectorscope and View > RGB Parade.
  2. Toggle the effect on and off using the eye icon in the Effect Stack to visually monitor the gamut shifts.
  3. Check the Clip Monitor to confirm that skin tones, saturation levels, and luminance values align with your project's target display standard.
