How to Use Glaxnimate in Kdenlive for Motion Graphics

Integrating Glaxnimate with Kdenlive provides a powerful, open-source workflow for designing and rendering 2D vector animations directly inside your video projects. This article outlines the step-by-step process of configuring Glaxnimate within Kdenlive, creating animation clips, editing vector motion graphics, and utilizing the non-destructive roundtrip workflow for seamless timeline updates.

1. Install Kdenlive and Glaxnimate

Ensure you have the latest stable releases of both Kdenlive and Glaxnimate installed on your system.

  • On Linux, you can install them via Flatpak, AppImage, or your distribution’s package manager.
  • On Windows and macOS, download the official installer or standalone packages for both applications.

2. Configure the Glaxnimate Path in Kdenlive

For Kdenlive to launch Glaxnimate automatically, the video editor must know where the binary executable is located:

  1. Open Kdenlive and navigate to Settings > Configure Kdenlive (or Kdenlive > Preferences on macOS).
  2. Select the Environment tab on the left sidebar.
  3. Click on the Default Apps sub-tab.
  4. Locate the Glaxnimate field.
  5. Enter the path to the Glaxnimate executable or click the folder icon to browse and select the binary (e.g., glaxnimate.exe on Windows or /usr/bin/glaxnimate on Linux).
  6. Click Apply and then OK.

3. Create an Animation Clip in Kdenlive

Once linked, you can generate motion graphic assets directly from the project bin:

  1. Go to the Project Bin panel.
  2. Click the Add Clip dropdown button (or right-click an empty area in the bin).
  3. Select Create Animation... (or Add Animation).
  4. Enter a name for the animation file (saved by default in Glaxnimate's .rawr format) and choose a save directory.
  5. Specify the animation frame rate and duration to match your project settings.
  6. Click OK. Kdenlive will create the file and immediately launch Glaxnimate.

4. Animate in Glaxnimate

Glaxnimate will open with a canvas matching the resolution and frame rate configured in Kdenlive:

  1. Use the shape, path, and text tools to design visual elements.
  2. Use the timeline at the bottom to set keyframes for position, scale, rotation, opacity, and path modifications.
  3. Utilize the timeline background feature if you need to reference video frames from Kdenlive for rotoscoping or precision placement.

5. Save and Automatic Timeline Synchronization

The workflow between Kdenlive and Glaxnimate uses a real-time roundtrip setup:

  1. When you finish editing in Glaxnimate, press Ctrl + S (or Cmd + S on macOS) to save the file.
  2. Return to Kdenlive. The animation clip in the Project Bin and on the timeline will immediately reflect the changes.
  3. To make further adjustments later, right-click the clip on the Kdenlive timeline or bin and choose Edit Clip to reopen it in Glaxnimate.
