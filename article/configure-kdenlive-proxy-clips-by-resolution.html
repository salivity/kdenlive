Configure Kdenlive Proxy Clips by Resolution

This article explains how to configure Kdenlive to automatically generate proxy clips only for video files that exceed a specific resolution threshold. Using proxy clips—lower-resolution copies of your source media—significantly improves timeline playback and editing performance. By limiting this process to high-resolution videos, such as 4K or 2K footage, you can save valuable CPU power and storage space by avoiding unnecessary proxy generation for smaller, easily editable 1080p or 720p files.

Step-by-Step Configuration

To set up resolution-based automatic proxy generation in Kdenlive, follow these steps:

  1. Open the Configuration Menu

    • On Windows or Linux, click on Settings in the top menu bar and select Configure Kdenlive....
    • On macOS, click on Kdenlive in the top menu bar and select Preferences....

  2. Navigate to the Proxy Clips Settings

    • In the configuration window that appears, look at the left-hand sidebar and click on the Proxy Clips category.

  3. Enable Proxy Clips

    • At the top of the Proxy Clips settings page, check the box next to Enable Proxy Clips. This activates the proxy system for your projects.

  4. Set the Resolution Threshold

    • Look for the setting labeled Generate for videos larger than (or Limit source image width in some versions).
    • Check the box next to this option to enable the size threshold.
    • Enter your desired resolution width in pixels in the input box. For example:
      • Enter 1920 if you only want proxies for videos larger than standard Full HD (such as 2K, 4K, or higher).
      • Enter 3840 if you only want to generate proxies for 4K UHD videos and higher.

  5. Apply and Save

    • Click the Apply button in the bottom right corner, and then click OK to close the window.

How It Works

Once configured, Kdenlive will analyze the dimensions of any video file you drag into your Project Bin. If the width of the video exceeds the pixel threshold you specified, Kdenlive will automatically render a lightweight proxy clip in the background. If the video resolution falls below your limit, Kdenlive will use the original file directly, keeping your storage clean and your workflow efficient.
