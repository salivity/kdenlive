How to Make Split Screen Grids in Kdenlive

Creating a seamless split-screen video grid in Kdenlive involves stacking multiple video tracks, applying the Transform effect to each layer, and calculating precise pixel coordinates to position your clips without gaps or overlaps. This guide outlines the exact setup, sizing rules, and alignment settings required to construct multi-panel grid layouts in Kdenlive efficiently.

1. Project and Timeline Setup

  1. Create a project with your target resolution and frame rate (e.g., 1920x1080 at 30fps or 60fps).
  2. Create as many video tracks as you have video panels. For a standard 2x2 four-screen grid, ensure you have four video tracks (V1, V2, V3, and V4).
  3. Drag each video clip onto its own track, aligning their start points so they play simultaneously.

2. Sizing and Coordinates Math (1080p 2x2 Example)

To prevent visible seams, calculate the size and coordinate offsets precisely based on your project resolution. For a standard Full HD (1920x1080) project divided into a 2x2 grid:

  • Panel Width: 1920 / 2 = 960 px
  • Panel Height: 1080 / 2 = 540 px
  • Scale Factor: 50%

Use the following coordinates for each track's Transform effect:

  • Top-Left (Track 1): X: 0, Y: 0, Size: 50% (or W: 960, H: 540)
  • Top-Right (Track 2): X: 960, Y: 0, Size: 50%
  • Bottom-Left (Track 3): X: 0, Y: 540, Size: 50%
  • Bottom-Right (Track 4): X: 960, Y: 540, Size: 50%

3. Applying the Transform Effect

  1. Open the Effects tab and search for Transform.
  2. Drag and drop the Transform effect onto the clip in V1.
  3. In the Effect Stack, set the Size / Scale to 50%.
  4. Set the X and Y values according to your coordinate map (e.g., X: 0, Y: 0).
  5. Repeat the process for the remaining clips on V2, V3, and V4, applying the corresponding X and Y coordinates for each quadrant.

4. Alternative Method: Track-Level Transformation

If your grid contains multiple cuts or sequential clips per quadrant, apply the Transform effect directly to the track header instead of individual clips:

  1. Click the header of V1 to select the entire track.
  2. Add the Transform effect and adjust the position and size.
  3. Any clip placed on that track will automatically inherit the split-screen position.

5. Handling Non-Standard Grid Dimensions (Cropping)

If you want to maintain a 1:1 aspect ratio or create vertical column splits without distorting footage:

  1. Add the Crop, Scale, Tilt or Edge Crop effect above the Transform effect in the stack.
  2. Crop the edges to fit the target panel aspect ratio.
  3. Position the cropped clip using the Transform effect's X and Y coordinates.

6. Verification and Export

  1. Enable Guides or the Grid Overlay in the Project Monitor settings to verify alignment.
  2. Zoom in to 100% or 200% in the Project Monitor to confirm there are no black borders or overlapping pixels along the seams.
  3. Press Render to export the synchronized split-screen video.
