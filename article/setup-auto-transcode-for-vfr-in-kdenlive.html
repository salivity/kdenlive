Setup Auto Transcode for VFR in Kdenlive

Variable Frame Rate (VFR) video often leads to timeline lag and audio desynchronization issues in non-linear video editors. Configuring an automated transcode profile in Kdenlive ensures that incoming VFR footage is automatically converted into an edit-friendly Constant Frame Rate (CFR) format upon import. This guide provides the exact steps needed to create a CFR transcoding profile and enable automatic conversion inside Kdenlive.

Step 1: Open the Transcode Settings

  1. Launch Kdenlive.
  2. Click Settings in the top menu bar.
  3. Select Configure Kdenlive... (or press Ctrl + Shift + , on Linux/Windows).
  4. Select the Transcode tab from the left-hand navigation pane.

Step 2: Create a CFR Transcoding Profile

  1. In the Transcode settings window, locate the list of available profiles.
  2. Click the Add Profile (plus sign) button to create a new preset.
  3. In the Profile Name field, assign a recognizable name, such as VFR to CFR Conversion.
  4. Set the Extension field to mp4 (or mov if you prefer ProRes/DNxHR).

Step 3: Enter FFmpeg Encoding Parameters

Enter the MLT/FFmpeg parameters in the Parameters box to enforce constant frame rate and maintain visual quality:

f=mp4 vcodec=libx264 acodec=aac crf=18 preset=faster vsync=cfr
  • vcodec=libx264: Encodes the video stream to H.264.
  • acodec=aac: Ensures universal audio compatibility.
  • crf=18: Provides visually lossless output suitable for intermediate editing.
  • vsync=cfr: Forces the output to Constant Frame Rate.

Click Save or Apply to register the new profile.

Step 4: Enable Automatic Transcoding on Import

  1. In the Configure Kdenlive menu, navigate to the Clips tab (or Timeline depending on your Kdenlive version).
  2. Look for the Automatic Transcode or Variable Frame Rate Warning section.
  3. Check the box for Always transcode variable frame rate clips on import.
  4. Set the default profile dropdown to the custom profile you created in Step 3 (VFR to CFR Conversion).
  5. Click OK to close the configuration dialog.

Step 5: Test the Automation

  1. Drag and drop a known VFR video file (such as smartphone footage or screen recordings) into the Project Bin.
  2. Kdenlive will detect the variable frame rate and trigger the background transcoding job automatically.
  3. Once the job completes in the background, the transcoded CFR clip will be placed in the Project Bin, ready for timeline editing without audio sync drift.
