Batch Render Social Media Cuts in Kdenlive

This guide outlines the process of preparing and exporting multiple aspect ratio cuts—such as 16:9 for YouTube, 9:16 for TikTok/Reels, and 1:1 for Instagram—using Kdenlive's batch rendering features. By configuring project profiles, reframing sequence timelines, and sending individual jobs to the render queue, you can automate your multi-platform export workflow efficiently without waiting for each video to render individually.

Step 1: Create Timeline Sequences for Each Aspect Ratio

Kdenlive supports multiple sequences within a single project, allowing you to manage various aspect ratios without creating separate project files.

  1. Open your master project.
  2. In the Project Bin, click the Add Sequence icon (or right-click and choose Create Sequence).
  3. Name your sequence according to its target platform (e.g., Sequence_Vertical_9x16, Sequence_Square_1x1).
  4. Copy your master edit from the primary timeline and paste it into the new sequence.

Step 2: Adjust Framing and Positioning

Different aspect ratios require visual reframing to keep key elements centered.

  1. Switch to your new sequence tab.
  2. Apply the Transform or Position and Scale effect to your video clips.
  3. Adjust the X/Y coordinates and Scale parameters so the subject remains within the visible frame for that specific format.
  4. Adjust text, subtitles, and graphic overlays so they fit within the platform-specific safe zones.

Step 3: Configure Render Settings and Add to Queue

Instead of rendering each cut immediately, add each sequence to the render queue.

  1. Click the Render button in the main toolbar (or press Ctrl + Enter).
  2. Under Timeline, select the specific sequence you want to export.
  3. Select your desired output preset (e.g., MP4 - H.264/AAC).
  4. In the Project Profile section of the render window, select the matching aspect ratio profile (e.g., Vertical HD 1080x1920 or Custom Square 1080x1080).
  5. Specify an output file path and name indicating the format (e.g., video_tiktok_9x16.mp4).
  6. Instead of clicking "Render to File", click Generate Script or Add to Queue (depending on your Kdenlive version).

Step 4: Repeat for Remaining Aspect Ratios

  1. In the Render dialog, select the next sequence.
  2. Adjust the output resolution, destination file name, and render profile to match the new ratio.
  3. Click Add to Queue.
  4. Repeat this step for all required formats (e.g., landscape, vertical, square).

Step 5: Start the Batch Render

  1. Open the Job Queue tab in the Render dialog window.
  2. Verify that all queued jobs have distinct file names and correct profile settings.
  3. Click Start Job (or Start Queue) to begin processing.

Kdenlive will render each file sequentially in the background, freeing your system once the entire queue is complete.
