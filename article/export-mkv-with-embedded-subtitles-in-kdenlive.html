Export MKV with Embedded Subtitles in Kdenlive

Exporting a finalized video with embedded subtitle tracks in Kdenlive allows viewers to toggle subtitles on or off during playback without permanently burning them into the video frames. This guide covers the exact steps to create or import your subtitles, configure the Matroska (MKV) rendering profile, and export your project with soft-coded subtitles intact.

1. Add or Import Subtitles

Ensure your subtitle track is created and aligned with your video on the timeline before exporting.

  • Go to the top menu and select Project > Subtitles > Add Subtitle Track (or press the subtitle icon above the timeline).
  • Add subtitle blocks manually by double-clicking on the subtitle track, or import an existing .srt or .vtt file by selecting Project > Subtitles > Import Subtitle File.

2. Open the Render Window

Once your edit and subtitles are finalized:

  • Click the Render button in the main toolbar, or use the keyboard shortcut Ctrl + Return (or Cmd + Return on macOS).

3. Choose the Matroska (MKV) Profile

  • In the Presets tab on the left side of the Render window, expand the Generic or Video category.
  • Select Matroska (mkv) as your output profile. You can choose standard presets like Matroska H264/AAC or Matroska H265/AAC depending on your compression preference.

4. Enable Subtitle Embedding

  • Click the More Options expander at the bottom of the Render dialog if advanced settings are hidden.
  • Locate the Subtitles section.
  • Check the box labeled Export subtitles (or Embed subtitles depending on your Kdenlive version).
  • Ensure that the option to Burn-in is unchecked, as burning-in will hardcode the text permanently into the image instead of embedding it as a toggleable stream.

5. Set the Destination and Render

  • In the Output file field at the top, choose your desired save location and verify that the file extension is .mkv.
  • Click Render to File.

6. Verify the Export

Open the rendered .mkv file in a media player like VLC or MPV to ensure the subtitle track can be selected, enabled, and disabled successfully from the player's subtitle menu.
