Configure ProRes Proxy in Kdenlive for Fast Scrubbing

Editing high-resolution video footage often leads to timeline lag, dropped frames, and sluggish scrubbing. Configuring Kdenlive to generate low-resolution Apple ProRes Proxy clips replaces demanding original camera files with an intra-frame, edit-friendly format during the editing process. This guide details how to create a custom ProRes Proxy encoding profile, set scaling parameters, and apply the configuration to your project for fluid timeline performance.

Step 1: Open Proxy Clip Settings

  1. Launch Kdenlive.
  2. Go to the top menu and select Settings > Configure Kdenlive.
  3. In the left sidebar, click on Proxy Clips.

Step 2: Enable Proxy Clips

  1. Check the box labeled Enable Proxy Clips.
  2. Optional: Set a resolution threshold (e.g., Generate for videos larger than 1000 pixels) to ensure proxies are automatically triggered for 1080p, 4K, or higher-resolution media.
  3. Check Enable external proxy clips if you plan to use pre-rendered proxies from external software.

Step 3: Create a Low-Resolution ProRes Proxy Profile

Kdenlive uses FFmpeg presets to generate proxy media. To add a dedicated low-resolution ProRes Proxy preset:

  1. In the Proxy Clips settings window, locate the Encoding profile section.
  2. Click the Manage Video Profiles (wrench/edit) icon next to the profile dropdown.
  3. Click the Add new profile (plus) button.
  4. Set the Profile Name to: ProRes Proxy 720p
  5. Set the File Extension to: mov
  6. In the Parameters field, paste the following FFmpeg command:
-c:v prores_ks -profile:v 0 -vf scale=-2:720 -pix_fmt yuv422p -c:a pcm_s16le
  • -profile:v 0: Selects the ProRes Proxy variant (the most lightweight ProRes flavor).
  • -vf scale=-2:720: Downscales the height to 720p while preserving the aspect ratio and ensuring dimensions are divisible by 2.
  • -c:a pcm_s16le: Transcodes audio to uncompressed PCM for zero-latency audio decoding.
  1. Click Save to store the new profile.

Step 4: Apply the ProRes Profile to Your Project

  1. In the Proxy Clips configuration menu, change the Encoding profile dropdown to your newly created ProRes Proxy 720p.
  2. Click Apply, then click OK.
  3. To set this for an existing project, go to Project > Project Settings > Proxy tab, ensure Enable Proxy Clips is checked, and select the ProRes Proxy 720p profile.

Step 5: Generate and Scrub Proxies

  1. Import your media into the Project Bin.
  2. If automatic generation is enabled, Kdenlive will immediately transcode the files in the background.
  3. To manually create a proxy for an existing clip, right-click the clip in the Project Bin and select Proxy Clip.
  4. Once processing finishes, a small yellow P icon appears on the clip thumbnail.

Drag the clip to your timeline. Scrubbing across the playhead will now decode the lightweight ProRes frames with minimal CPU overhead, providing smooth playback and precise timeline navigation. When rendering the final project, Kdenlive will automatically bypass the proxy files and use the full-resolution original media.
