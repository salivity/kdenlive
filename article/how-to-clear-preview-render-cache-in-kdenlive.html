How to Clear Preview Render Cache in Kdenlive

Timeline preview rendering in Kdenlive generates temporary video files to ensure smooth real-time playback of complex edits, transitions, and effects. Over time, these rendered chunks can consume substantial disk space. This guide outlines the exact steps to safely clear your local timeline preview cache directly within Kdenlive without deleting project files, proxy clips, or original source media.

Method 1: Delete Preview Data from the Timeline Menu

The fastest way to clear rendered timeline chunks for the currently open project is through the timeline menu:

  1. Open your project in Kdenlive.
  2. In the top application menu, click on Timeline.
  3. Hover over Timeline Preview.
  4. Click Remove All Preview Data (or Remove Selection Preview Data if you only want to clear a specific section).

This action removes the pre-rendered timeline cache files immediately, leaving all source clips intact.

Method 2: Use the Project Cache Manager

Kdenlive includes a built-in project cache management tool that separates preview renders from other cached assets:

  1. Go to Project in the main menu and select Project Settings.
  2. Navigate to the Cache Data tab (or Project Files tab depending on your Kdenlive version).
  3. Locate the Timeline Preview entry.
  4. Click the Delete (trash bin) icon next to the Timeline Preview category.
  5. Click Apply or OK to confirm.

Method 3: Clear Global Cache Across Multiple Projects

To clean up old preview renders from past projects that are still taking up storage:

  1. Click on Settings in the top menu and select Manage Cached Data (or access it via Project > Manage Cache Data).
  2. The cache dialog will list stored data categorized by type: Timeline Preview, Proxy Clips, Audio Thumbnails, and Video Thumbnails.
  3. Check the box for Timeline Preview under your current project or all stored projects.
  4. Click Delete Selected to clear the cached files.

Why Your Source Files Are Safe

Kdenlive stores timeline preview renders in a dedicated cache directory separate from your source media. Deleting preview cache only forces Kdenlive to rebuild temporary playback frames when requested; it does not alter, move, or delete your original video, audio, or image files.
