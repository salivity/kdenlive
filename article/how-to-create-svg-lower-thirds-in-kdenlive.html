How to Create SVG Lower Thirds in Kdenlive

Creating complex graphic lower thirds using SVG vector files in Kdenlive allows video editors to achieve sharp, resolution-independent overlays with custom animations. This guide explains how to design vector graphics in external software like Inkscape, import and layer them within Kdenlive, add dynamic text overlays, and animate the graphics using keyframed transform effects for a professional broadcast finish.

1. Designing the Vector Graphic in Inkscape

Before working inside Kdenlive, create your graphic components in a vector editor such as Inkscape.

  1. Set your document page dimensions to match your video project (for example, 1920x1080 for Full HD).
  2. Draw your lower third background, accent shapes, logos, and framing lines in the lower-left or lower-right portion of the canvas.
  3. Keep the background transparent by ensuring the page background alpha is set to 0.
  4. If you plan to animate elements separately, export individual graphic components as separate SVG files (e.g., base-banner.svg, accent-line.svg).
  5. Save the final vector file in standard SVG format.

2. Importing SVG Files into Kdenlive

  1. Open your Kdenlive project.
  2. In the Project Bin, right-click and select Add Clip or Folder, or drag and drop your SVG files directly into the bin.
  3. Kdenlive natively supports SVG rendering, ensuring edges remain sharp regardless of scaling.

3. Adding Text via the Title Clip Editor

While text can be embedded directly in your SVG, creating text within Kdenlive makes updating names and titles easier across different projects.

  1. Right-click the Project Bin and choose Add Title Clip.
  2. Type the presenter's name and title in the text area.
  3. Adjust the font, size, weight, and color to align with your SVG design.
  4. Position the text over the transparent preview canvas where your SVG elements will sit, then click Create Clip.

4. Arranging Timeline Layers

  1. Drag the SVG asset onto a higher video track (e.g., V2) above your primary footage track (V1).
  2. Drag the Title Clip onto the track directly above the SVG asset (e.g., V3).
  3. Align the start points and durations of both the SVG graphic and text clips.

5. Animating the Lower Third

Apply keyframe animation to make the lower third smoothly slide or fade into the frame.

  1. Select the SVG clip on track V2, open the Effects panel, and search for the Transform effect.
  2. Drag the Transform effect onto the SVG clip.
  3. In the Effect/Composition Stack, add a keyframe at frame 0 and set the X position or Opacity to slide or fade the graphic off-screen.
  4. Move the playhead forward by 15–30 frames, add a second keyframe, and reset the values to the default resting position.
  5. Add a keyframe near the end of the clip and another at the final frame to animate the graphic leaving the screen.
  6. Apply the same Transform effect to the Title Clip on track V3, offsetting the keyframes slightly to create a staggered, polished reveal.

6. Saving as a Template

To reuse the lower third in future projects:

  1. Select both the SVG clip and the Title clip on the timeline.
  2. Right-click and choose Create Library Clip (or save the timeline selection as a sequence).
  3. Name the template for quick drag-and-drop reuse from Kdenlive’s Library panel.
