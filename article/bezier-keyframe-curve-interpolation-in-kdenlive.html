Bezier Keyframe Curve Interpolation in Kdenlive

Adjusting keyframe interpolation in Kdenlive allows video editors to replace rigid, mechanical movements with dynamic, natural motion. By switching from standard linear interpolation to Bezier curves, you gain precise control over acceleration and deceleration (ease-in and ease-out) for parameters such as position, scale, and opacity. This guide provides a straightforward walkthrough on configuring and refining Bezier keyframes within Kdenlive’s effect controls.

1. Apply a Keyframeable Effect

  1. Select the clip on your timeline that requires animated movement.
  2. Open the Effects tab and add an effect that supports keyframing, such as the Transform effect.
  3. Move the playhead to the desired starting point in the timeline or effect controls and click the Add Keyframe button (the small plus or diamond icon).

2. Set Up Keyframes for Motion

  1. Adjust the properties (such as X/Y position, size, or rotation) for your initial keyframe.
  2. Advance the playhead to the point where the animation should complete.
  3. Modify the effect parameters again to automatically create a second keyframe. By default, Kdenlive connects these two points with a linear interpolation, resulting in a constant, abrupt velocity.

3. Change Interpolation Type to Smooth (Bezier)

  1. Locate the keyframe ruler inside the effect options panel.
  2. Right-click the starting keyframe icon directly on the keyframe timeline, or click on the keyframe and locate the Interpolation dropdown menu in the effect parameters.
  3. Change the interpolation mode from Linear to Smooth (or B-Spline / Cubic depending on the specific effect version).
  4. Repeat this step for the ending keyframe to ensure seamless entry and exit transitions.

4. Adjust the Bezier Curve Handles

  1. Toggle the curve graph view in the effect panel if available, which displays the parameter value against time.
  2. Click on the keyframe node to expose the Bezier tangent handles (represented by lines extending from the keyframe point).
  3. Drag the tangent handles horizontally to adjust the timing of the acceleration:
    • Ease Out (Start): Pull the right handle horizontally outward to create a flat curve at the start, making the motion accelerate gradually.
    • Ease In (End): Pull the left handle horizontally outward on the destination keyframe to create a flat curve before arrival, causing the motion to gently decelerate to a stop.
  4. Drag the tangent handles vertically if you need to create overshoot or elastic bounce effects.

5. Preview and Fine-Tune

  1. Play back the timeline section around the keyframes using the Spacebar.
  2. If the motion feels too sudden, extend the length of the tangent handles to flatten the curve further.
  3. If the motion is uneven, ensure the incoming and outgoing handle angles maintain a continuous, smooth slope across intermediate keyframes.
