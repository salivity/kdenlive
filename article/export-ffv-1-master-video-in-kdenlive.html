Export FFV1 Master Video in Kdenlive

Exporting a video using the FFV1 codec in Kdenlive allows you to create a high-quality, lossless master file ideal for long-term archiving and post-production workflows. This guide covers the exact step-by-step process to configure the render settings, select or create an FFV1 profile, and export an uncompressed video directly from your Kdenlive project timeline.

Step 1: Open the Render Dialog

  1. Open your completed project in Kdenlive.
  2. Click the Render button on the main toolbar, or navigate to Project > Render from the top menu. You can also press Ctrl + Return (or Cmd + Return on macOS).

Step 2: Select the Lossless Preset Category

  1. In the Render window, look at the Presets panel on the left side.
  2. Expand the Lossless/HQ or Ultra-High Quality category.
  3. Look for a predefined preset named FFV1 or FFV1 / PCM.

Step 3: Create a Custom FFV1 Profile (If Not Pre-Installed)

If your Kdenlive installation does not include a default FFV1 preset, you can create one manually:

  1. Click the Create New Preset icon (the document icon with a plus sign) located next to the preset selection menu.
  2. Set the Group to Lossless/HQ.
  3. Set the Preset Name to FFV1 Lossless Master.
  4. Set the Extension to mkv (recommended) or avi.
  5. In the Parameters box, enter the following FFmpeg render string: 
    vcodec=ffv1 level=3 coder=1 context=1 g=1 slicecrc=1 acodec=pcm_s24le
  6. Click Save to store the preset for future use.

Step 4: Configure Output Details and File Destination

  1. Click the folder icon next to Output file to choose the destination directory and name your master file.
  2. Under the Render options section, ensure Full project is selected to render the entire timeline, or choose Selected zone if you only need a specific portion.
  3. Confirm that the video resolution and frame rate match your project settings.

Step 5: Start the Render Process

  1. Click the Render to File button at the bottom of the window.
  2. Monitor the Job Queue to track the rendering progress.
  3. Once the process reaches 100%, your lossless FFV1 master file is ready for archiving or further editing.
