How to Auto Transcode Media in Kdenlive

This guide explains how to configure Kdenlive to automatically detect and transcode unsupported or problematic container formats and codecs when you import media files into your project. Setting up automatic transcoding ensures smoother timeline playback, prevents stability issues, and converts non-standard video files into editing-friendly formats immediately upon import.

Step 1: Open Kdenlive Settings

  1. Launch Kdenlive.
  2. In the top menu bar, click on Settings (or Kdenlive on macOS).
  3. Select Configure Kdenlive... from the dropdown menu to open the main configuration window.

Step 2: Navigate to Transcoding Preferences

  1. In the left-hand sidebar of the configuration window, select the Project Defaults or Transcode section (depending on your Kdenlive version).
  2. Locate the Automatic Transcoding settings.

Step 3: Configure Transcode Triggers on Import

  1. Check the box labeled Enable Transcoding (or Ask to transcode clips on import).
  2. Select your preferred prompt behavior:
    • Always ask: Displays a pop-up prompting you to transcode whenever an unsupported format or variable frame rate (VFR) media is imported.
    • Always transcode: Automatically converts unsupported formats in the background without prompting.
  3. Under the file format trigger rules, ensure options for unsupported video containers, variable frame rate videos, and high-efficiency formats (such as HEVC/H.265 if your system lacks hardware decoding) are enabled.

Step 4: Choose a Default Transcoding Profile

  1. In the Transcode Profile dropdown menu, select the profile you want Kdenlive to use by default.
    • ProRes or DNxHR / DNxHD: Best for high-quality, frame-accurate editing and performance.
    • Lossless / Remux: Best if only the container format needs to be changed (e.g., MKV to MP4) without re-encoding the video stream.
    • x264 / Intermediate: A good balance between file size and system compatibility.
  2. Click Apply, then click OK to save your preferences.

Step 5: Test the Configuration

  1. Drag and drop a file with an unsupported container or variable frame rate into the Project Bin.
  2. Kdenlive will either automatically begin transcoding the clip or display a transcode dialogue with your selected profile pre-set.
  3. Once completed, the newly transcoded file will automatically replace the source file inside your Project Bin ready for editing.
