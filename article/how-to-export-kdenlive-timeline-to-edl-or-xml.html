How to Export Kdenlive Timeline to EDL or XML

Moving your video project from Kdenlive to another non-linear editor (NLE) like DaVinci Resolve or Premiere Pro requires exporting your timeline in a compatible format. This guide provides a clear, step-by-step walkthrough on how to export your Kdenlive timeline as an Edit Decision List (EDL) or Final Cut Pro XML file, ensuring a smooth transition of your cuts, tracks, and timing between different editing platforms.

Option 1: Exporting as an EDL (Edit Decision List)

An EDL is a simple text file that contains an ordered list of reel and timecode data. It is best used for simple, single-track video cuts.

  1. Open Your Project: Launch Kdenlive and open the project timeline you wish to export.
  2. Access the Export Menu: Click on Project in the top menu bar, hover over Export, and select Export EDL....
  3. Configure Settings: A dialog window will appear. Here, you can select which video and audio tracks you want to include in the EDL, as the format typically only supports one video track at a time.
  4. Save the File: Choose your destination folder, name your file with the .edl extension, and click Save.

Option 2: Exporting as FCP XML

If your project contains multiple video and audio tracks, exporting as an XML (specifically Final Cut Pro XML format) is the preferred method. It preserves track structures, basic transitions, and clip placements much better than an EDL.

  1. Open Your Project: Ensure your Kdenlive timeline is ready for export.
  2. Select the XML Export Option: Click on Project in the top menu, hover over Export, and select Export FCP XML....
  3. Choose File Destination: A file browser window will open. Select the folder where you want to save the file.
  4. Save the File: Enter a name for your project file (it will save with the .xml extension) and click Save.

Importing the File into Other Editing Software

Once you have generated your EDL or XML file, you can bring it into your target video editor:

  • In DaVinci Resolve: Go to File > Import > Timeline... (or Pre-conformed EDL... if using an EDL) and select your exported file.
  • In Adobe Premiere Pro: Go to File > Import, locate your XML file, and double-click it. Premiere will automatically reconstruct the timeline and prompt you to link the offline media.
  • In Final Cut Pro: Go to File > Import > XML... and select the XML file exported from Kdenlive.

Note: Because different video editors use different render engines and effects libraries, advanced transitions, color grading, and custom effects applied in Kdenlive will not transfer over and must be reapplied in the destination software.
