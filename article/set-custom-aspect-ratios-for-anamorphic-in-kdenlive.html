Set Custom Aspect Ratios for Anamorphic in Kdenlive

Working with anamorphic footage in Kdenlive requires adjusting project settings, clip pixel aspect ratios, and monitor configurations to ensure footage previews accurately without distortion. This guide outlines the exact steps needed to desqueeze anamorphic video, configure custom project profiles, and adjust monitor display settings within Kdenlive.

Step 1: Create or Select an Anamorphic Project Profile

  1. Open Kdenlive and navigate to Project > Project Settings.
  2. Go to the Project Profile tab.
  3. If an existing profile does not match your footage's squeeze factor (e.g., 1.33x, 1.5x, 1.8x, or 2.0x), click the Manage Project Profiles button (the icon next to the profile dropdown).
  4. Click the Add New Profile button (+).
  5. Name the profile appropriately (e.g., 4K Anamorphic 2x).
  6. Set the Frame size to your target resolution (e.g., 3840 x 2160).
  7. Adjust the Pixel Aspect Ratio:
    • For standard square pixels, leave it at 1/1.
    • For non-square anamorphic timeline rendering, set the ratio matching your lens squeeze (e.g., 4/3 for 1.33x or 2/1 for 2.0x).
  8. Click Save and select this profile for your project.

Step 2: Configure Clip Pixel Aspect Ratio

If your source video files are flagged as standard 1:1 (square pixel) footage, Kdenlive will display them squeezed. You must set the individual clip properties:

  1. Import your anamorphic clips into the Project Bin.
  2. Right-click on the clip and select Clip Properties.
  3. Under the Video tab, locate the Pixel Aspect Ratio setting.
  4. Uncheck Use clip aspect ratio if it is automatically detected incorrectly.
  5. Enter the custom aspect ratio or choose your lens squeeze multiplier from the dropdown list.
  6. Click Apply. The clip will now desqueeze automatically in the timeline and preview monitors.

Step 3: Configure the Clip and Project Monitors

To ensure your monitors display the full desqueezed image correctly:

  1. Click the Options (gear) icon in the top right corner of the Project Monitor or Clip Monitor.
  2. Ensure Force Pixel Aspect Ratio is enabled so the monitor honors non-square pixel settings.
  3. If you are editing square-pixel footage inside an anamorphic framing workflow, click the Guides overlay option in the monitor settings to display custom aspect ratio guide lines (such as 2.39:1).

Step 4: Exporting Anamorphic Media

  1. Open the Render window (Project > Render or press Ctrl + Return).
  2. Select your desired output format (such as MP4 / H.264 or ProRes).
  3. If exporting at full desqueezed resolution (e.g., standard widescreen flat display), ensure the render profile resolution matches your desqueezed canvas size.
  4. If exporting with anamorphic flags, check More Options and verify that the output pixel aspect ratio matches your project profile.
