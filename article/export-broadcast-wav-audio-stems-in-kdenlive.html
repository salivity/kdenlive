Export Broadcast WAV Audio Stems in Kdenlive

Exporting individual audio stems in uncompressed broadcast WAV format from Kdenlive is essential for professional audio mixing, post-production mastering, and archiving. This guide details how to organize your timeline tracks, configure render settings for uncompressed Linear PCM audio, and export synchronized multi-track stems with consistent timecode alignment.

1. Organize and Label Timeline Tracks

Ensure all audio clips are separated onto dedicated tracks based on their type (e.g., Dialogue, Sound Effects, Foley, Music). Rename each track header in the timeline to match the stem name for easy identification.

2. Set Timeline Zones

To ensure all exported stems have the exact same duration and align perfectly in a Digital Audio Workstation (DAW):

  1. Move the playhead to the beginning of the project and press I to set the In point.
  2. Move the playhead to the end of the project and press O to set the Out point.

3. Isolate the Target Track

Because Kdenlive processes timeline audio through the master bus during rendering, you must solo the track you want to export:

  1. Click the Solo button (headphones icon) on the track header you want to render.
  2. Ensure all other non-target audio tracks are muted to prevent audio bleed.

4. Open the Render Settings

  1. Click the Render button in the main toolbar or press Ctrl + Return.
  2. Set the Render Project option to Selected Zone to preserve timeline alignment.

5. Select the Uncompressed WAV Profile

  1. In the Presets panel, expand the Audio only category.
  2. Select WAV 48kHz or standard WAV.
  3. Click the Edit Profile button (wrench icon) or create a custom profile to ensure broadcast standards:
    • Codec: pcm_s24le (24-bit uncompressed PCM) or pcm_s16le (16-bit uncompressed PCM).
    • Sample Rate: Set ar=48000 (48 kHz, standard for broadcast video/audio).
    • Channels: Set ac=2 for stereo or ac=1 for mono.

6. Render the Stem

  1. Specify an Output file path and name the file clearly (e.g., ProjectName_Stem_Dialogue_48k24b.wav).
  2. Click Render to File.

7. Repeat for Remaining Stems

  1. Return to the timeline, unmute the next track, and solo it.
  2. Open the Render window, update the output file name, and click Render to File.
  3. Repeat this process until all dialogue, effects, and music stems have been rendered.
