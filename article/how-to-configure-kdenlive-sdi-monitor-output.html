How to Configure Kdenlive SDI Monitor Output

Configuring Kdenlive to output real-time preview streams over an SDI monitor card allows video editors to achieve accurate color grading and broadcast-standard monitoring on external reference displays. This guide outlines the necessary hardware driver setup, the underlying MLT framework requirements, and the step-by-step configuration within Kdenlive's playback settings to enable direct SDI output via supported hardware like Blackmagic Design DeckLink cards.

1. Install Required Hardware Drivers

Kdenlive relies on the MLT Multimedia Framework to communicate with hardware interfaces, with Blackmagic Design DeckLink cards being the primary supported SDI output hardware.

  1. Download and install the official Blackmagic Desktop Video drivers for your operating system (Linux or Windows).
  2. Verify that your system recognizes the card by running the Desktop Video Setup utility provided by Blackmagic.
  3. Ensure your user account has the necessary permissions to access video hardware devices (on Linux, ensure your user is added to the video group).

2. Verify MLT DeckLink Support

Because Kdenlive utilizes MLT for video rendering and I/O, MLT must be built with DeckLink module support. Most modern standard repository packages, Flatpaks, and AppImages of Kdenlive include DeckLink support by default.

You can confirm MLT DeckLink availability on Linux via terminal:

melt -query "consumers" | grep decklink

If decklink appears in the output, your installation is ready to stream preview video over SDI.

3. Configure External Display in Kdenlive

Once the hardware and drivers are functional, route Kdenlive's preview monitor to your SDI card:

  1. Open Kdenlive and navigate to Settings > Configure Kdenlive...
  2. Select the Playback tab from the left-hand sidebar.
  3. Locate the External Display or Monitor Audio/Video Output section.
  4. Set the display driver/backend to Blackmagic DeckLink (or Decklink SDI depending on your card model).
  5. Choose your specific SDI device from the detected device dropdown list.
  6. Select the preferred video format, resolution, and framerate that matches your reference monitor's supported input signal (e.g., 1080p24, 1080i59.94, or 2160p30).
  7. Click Apply, then OK.

4. Align Project Profiles for Smooth Playback

SDI hardware often requires an exact match between the project profile settings and the card's broadcast standard capabilities:

  • Go to Project > Project Settings.
  • Ensure the project timeline resolution and framerate match standard broadcast specifications (e.g., 1920x1080 at 25 fps, 29.97 fps, or 59.94 fps). Non-standard resolutions or framerates may result in a black screen or dropped signals on SDI monitors.
  • Restart Kdenlive if the preview does not initialize immediately after changing project profiles.
