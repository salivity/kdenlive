Convert Rec.601 and Rec.709 in Kdenlive

This guide provides a straightforward, step-by-step walkthrough on how to cross-convert video footage between the Rec.601 (Standard Definition) and Rec.709 (High Definition) color spaces using the Color Matrix filter in Kdenlive. Properly configuring this filter prevents luminance shifts, inaccurate color saturation, and hue errors when mixing legacy media formats within modern video projects.

Step 1: Add Footage to the Timeline

  1. Open Kdenlive and create or open your project.
  2. Drag your video clip from the Project Bin onto a video track in the Timeline.

Step 2: Locate the Color Matrix Filter

  1. Navigate to the Effects tab (typically docked near the Project Bin).
  2. Use the search bar at the top of the Effects panel and type Color Matrix (or locate it under the Color and Image Correction category).

Step 3: Apply the Filter to the Clip

  1. Click and drag the Color Matrix effect directly onto the target video clip on the timeline.
  2. Alternatively, select the clip in the timeline and double-click the Color Matrix effect in the Effects list.

Step 4: Configure the Matrix Parameters

  1. Select the clip on the timeline and go to the Effect/Composition Stack panel to view the filter settings.
  2. Set the Input Color Space parameter:
    • Select Rec.601 (or SD/BT.601) if you are working with standard-definition footage.
    • Select Rec.709 (or HD/BT.709) if your source footage is high-definition.
  3. Set the Output Color Space parameter:
    • Choose Rec.709 if converting SD footage to match an HD timeline.
    • Choose Rec.601 if downscaling or exporting an HD source for standard-definition distribution.

Step 5: Verify and Render

  1. Open the Vectorscope or RGB Parade via View > Scopes to ensure the color values sit correctly within the target gamut without clipping.
  2. Play back the clip in the Clip Monitor or Project Monitor to check for visual accuracy.
  3. Proceed with your project editing or click Render to export the finalized video.
