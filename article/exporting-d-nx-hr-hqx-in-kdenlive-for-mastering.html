Exporting DNxHR HQX in Kdenlive for Mastering

This guide details the step-by-step procedure for rendering a finalized project timeline in Kdenlive using the DNxHR HQX (High Quality Extended) profile. Utilizing DNxHR HQX provides a virtually visually lossless, 10-bit intermediate format ideal for archival, professional grading, and high-end post-production mastering workflows.

1. Prepare the Timeline

Ensure your project timeline is finalized. Verify that your project profile matches your intended master resolution and frame rate (e.g., 4K UHD at 23.98, 24, 29.97, or 60 fps) by navigating to Project > Project Settings. Set the timeline in/out points to encompass the entire sequence you wish to export.

2. Open the Render Window

Open the export dialogue by clicking the Render button on the main toolbar, selecting Project > Render from the top menu, or pressing the keyboard shortcut Ctrl + Return (Windows/Linux) or Cmd + Return (macOS).

3. Select the DNxHR HQX Profile

  1. In the Render window, make sure the Render Project tab is selected.
  2. In the preset tree on the left, expand the Intermediate / Edit-Friendly Formats or Lossless/HQ category.
  3. Select DNxHR.
  4. In the profile variations, choose DNxHR HQX (High Quality Extended - 10-bit).

Note: If the HQX profile is not visible by default, create a custom profile or edit the parameters by clicking the Create new profile button and entering the following FFmpeg command line:

f=mov vcodec=dnxhr profile=dnxhr_hqx pix_fmt=yuv422p10le acodec=pcm_s16le

4. Configure Audio and File Destination

  1. Set the destination path and file name under Output file at the top of the Render window. Ensure the extension is .mov or .mkv.
  2. Under the Audio section, confirm that the audio format is set to uncompressed PCM audio (typically 24-bit or 16-bit at 48kHz) to preserve audio fidelity for the master.

5. Finalize Render Settings and Export

  1. Under Render Options, select Full Project (or Selected Zone if rendering a specific segment).
  2. Set the Quality / Encoder Threads settings according to your CPU capacity to optimize render performance.
  3. Click the Render to File button at the bottom of the window.

Once the rendering process reaches 100%, the resulting file will be a 10-bit DNxHR HQX master ready for professional delivery, grading, or long-term archiving.
