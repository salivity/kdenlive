How to Nudge Clips Frame by Frame in Kdenlive

Fine-tuning clip placement on the timeline is essential for precise video and audio synchronization. While Kdenlive allows you to drag clips with the mouse, setting up dedicated keyboard shortcuts to nudge selected clips by single frame increments creates a much faster, frame-accurate editing workflow. This guide explains where to find the appropriate commands in Kdenlive's shortcut configuration and how to map them to your preferred keys.

Step 1: Open the Shortcut Configuration Menu

  1. Launch Kdenlive and open any project.
  2. In the top application menu, click Settings.
  3. Select Configure Keyboard Shortcuts... (or press Ctrl + Alt + , on default configurations).

Step 2: Locate the Nudge Commands

  1. In the search bar at the top of the Configure Shortcuts window, type Nudge or Move selected.
  2. Locate the following actions in the list:
    • Nudge selected clip left (or Move selected clip 1 frame left)
    • Nudge selected clip right (or Move selected clip 1 frame right)

Step 3: Assign Your Custom Hotkeys

  1. Click on the action you want to modify (e.g., Nudge selected clip left).
  2. Select the Custom radio button underneath the shortcut details.
  3. Click the shortcut button (which may currently say None).
  4. Press the key combination you wish to use (common options include Alt + Left Arrow for left and Alt + Right Arrow for right).
  5. If Kdenlive warns you that the key combination is already in use by another action, choose whether to reassign it or select an alternative key combination.
  6. Repeat the process for the right nudge action.

Step 4: Apply and Test the Shortcuts

  1. Click OK at the bottom of the window to save your changes.
  2. Click on a clip in the timeline to select it.
  3. Press your newly assigned hotkeys to nudge the clip one frame backward or forward along the timeline.
