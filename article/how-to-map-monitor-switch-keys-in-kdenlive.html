How to Map Monitor Switch Keys in Kdenlive

This guide explains how to map custom keyboard shortcuts to switch seamlessly between the Clip Monitor and the Project Monitor in Kdenlive. By assigning dedicated keys to focus on each monitor, you can preview source footage, edit timeline clips, and manage playback controls without taking your hands off the keyboard or relying on mouse clicks.

Step 1: Open the Keyboard Shortcuts Configuration

  1. Launch Kdenlive.
  2. In the top menu bar, click on Settings.
  3. Select Configure Keyboard Shortcuts... (or press Ctrl + Alt + , on default configurations).

Step 2: Locate the Monitor Actions

  1. In the search box at the top of the Configure Shortcuts window, type Monitor.
  2. Look through the filtered list under the Kdenlive or Monitor categories for the following actions:
    • Clip Monitor (or Focus Clip Monitor)
    • Project Monitor (or Focus Project Monitor)

(Note: Depending on your Kdenlive version, there may also be a single toggle action named Switch Monitor or Toggle Monitor Focus).

Step 3: Assign Your Custom Shortcuts

  1. Click on the action you want to modify (for example, Clip Monitor).
  2. Select the Custom radio button next to the shortcut field.
  3. Click on the button labeled None (or the existing assigned key).
  4. Press the key or key combination you want to assign (for example, F10 for Clip Monitor and F11 for Project Monitor, or Ctrl + 1 and Ctrl + 2).
  5. If the shortcut is already in use by another function, Kdenlive will notify you of the conflict. Confirm the reassignment if you wish to overwrite the previous shortcut.
  6. Repeat the process for the Project Monitor action.

Step 4: Save and Test the Changes

  1. Click OK or Apply to save your new configuration.
  2. Return to the main workspace and press your assigned keys.
  3. Verify that the active focus switches between the Clip Monitor and Project Monitor, allowing you to control playback and set in/out points instantly on either monitor.
