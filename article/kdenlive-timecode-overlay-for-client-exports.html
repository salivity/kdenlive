Kdenlive Timecode Overlay for Client Exports

Adding a timecode overlay to video exports allows clients to provide exact, frame-accurate feedback during the review process. In Kdenlive, this overlay can be applied non-destructively across your entire project using either the Master track or a dedicated adjustment layer. This guide covers the step-by-step workflow to insert, customize, and export a project with an active timecode generator overlay.

Method 1: Applying Timecode to the Master Track

Applying the effect directly to the Master track ensures that every visual element across all video tracks will display the timecode without altering individual clips.

  1. Open your completed project in Kdenlive.
  2. Locate the timeline header area on the left and click on the Master track header to select it.
  3. Open the Effects tab (typically located in the bottom-left or top-left dock).
  4. Search for the Dynamic Text or Timecode effect.
  5. Drag and drop the effect onto the Master track stack.

Method 2: Using an Adjustment Clip

If you prefer to toggle the overlay on and off easily, use an adjustment clip on a top video track.

  1. Create a new video track above all existing tracks by right-clicking a track header and selecting Insert Track.
  2. Right-click in the Project Bin and choose Add Color Clip or Add Title Clip.
  3. Name the clip "Timecode Layer" and drag it onto the top video track.
  4. Extend the clip so it spans the entire length of your timeline edit.
  5. In the Effects panel, search for Dynamic Text or Timecode and apply it to this clip.

Configuring the Timecode Settings

Once the effect is applied, adjust its parameters in the Effect/Composition Stack panel:

  • Text Format: If using Dynamic Text, set the text field to #timecode# to display project timecode, or #frame# for frame numbers.
  • Font and Size: Choose a clear, legible sans-serif font (such as Arial or Open Sans) at a medium size (around 30–50 pt).
  • Position: Use the geometry settings to position the overlay in an unobtrusive location, such as the bottom-right or top-center of the frame.
  • Background Box: Enable a semi-transparent black background behind the text to ensure readability over bright footage.
  • Opacity: Set the background opacity between 50% and 75% for optimal contrast without obstructing the footage.

Exporting the Review File

  1. Click the Render button in the top toolbar or press Ctrl + Return.
  2. Select an efficient delivery preset, such as MP4 - H.264 / AAC, to keep file sizes manageable for sharing.
  3. Under the Render Project dialog, ensure Full Project is selected under the Guide / Zones section.
  4. Set your output file destination and name the file with a review tag (e.g., ProjectName_Review_v1.mp4).
  5. Click Render to File to produce the timecoded review video.
