Split Screen with Track Transforms in Kdenlive

Creating a dynamic split-screen sequence in Kdenlive involves layering multiple video tracks, applying the Transform effect to manage positioning, and using keyframes to smoothly animate each panel. This guide explains the complete workflow for arranging clips on separate tracks, masking boundaries with crop tools, and synchronizing animated track transforms to create seamless transitions and multi-panel layouts.

1. Arrange Clips on Multiple Video Tracks

  1. Open Kdenlive and import the video clips you want to include in the split screen.
  2. In the timeline, create as many video tracks as you have clips (e.g., Track V1, Track V2, Track V3).
  3. Stack the clips vertically at the exact same timestamp so they play simultaneously.

2. Apply the Transform Effect

  1. Open the Effects tab.
  2. Search for the Transform effect (located under Transform, Distort and Perspective).
  3. Drag and drop the Transform effect onto each clip on the timeline. Alternatively, apply the effect to the entire track header if you plan to reuse the layout across multiple cuts.

3. Crop and Frame the Footage

Before animating movement, define the visible boundary for each clip:

  1. Apply the Edge Crop or Crop by Padding effect before the Transform effect in the clip's effect stack.
  2. Adjust the Left, Right, Top, or Bottom parameters to isolate the desired portion of each video (for example, cropping 50% from the right on Clip 1 and 50% from the left on Clip 2 for a two-way split).
  3. Ensure the bounding edges align properly to prevent visible gaps or unwanted overlap.

4. Animate the Split Screen with Keyframes

  1. Select a clip to open its Transform settings in the Properties panel.
  2. Move the timeline playhead to the point where the animation should begin.
  3. Add a keyframe in the Transform parameter window.
  4. Move the playhead to the end point of the transition and create a second keyframe.
  5. Adjust the X and Y coordinates, or the Size parameter, on the keyframes:
    • Slide-in effect: Set the initial keyframe position entirely off-screen (e.g., negative X values or values exceeding 100%) and the final keyframe at the target split-screen coordinate (e.g., X: 0, Y: 0).
    • Expansion effect: Animate the size from 100% to 50% while shifting the position from center to side.
  6. Repeat this process for the other clips on the remaining tracks, setting opposite coordinates so the clips slide or expand into place concurrently.

5. Smooth the Motion

  1. In the Transform keyframe ruler, right-click on the keyframes.
  2. Change the keyframe interpolation type from Linear to Smooth (or use Cubic) to apply easing to the motion.
  3. Match the duration between keyframes across all tracks to ensure that every split-screen element reaches its resting position at the exact same moment.
