Auto Purge Timeline Preview Cache in Kdenlive

Timeline preview rendering in Kdenlive enables smooth, real-time playback for complex edits, but the generated temporary render files can quickly consume vast amounts of disk space. This guide explains how to configure Kdenlive to automatically remove or manage these temporary timeline preview render files when closing projects, keeping your storage drive clutter-free without interrupting your workflow.

Configuring Automatic Cache Cleanup in Project Settings

Kdenlive allows you to configure preview render behavior at the project level to ensure temporary preview files do not linger permanently on your drive.

  1. Open Kdenlive and navigate to the top menu bar.
  2. Click on Project and select Project Settings from the dropdown menu (or press Shift + F10).
  3. In the Project Settings window, select the Timeline Preview tab.
  4. Review the timeline preview rendering settings. Ensure that the Preview Chunk Size and storage locations are designated properly.
  5. Switch to the Cache Data tab within the same Project Settings window.
  6. Locate the cache management options for timeline previews and proxy files. Check the option to limit cache retention or enable automatic deletion of cached preview files upon project close or after a set threshold.
  7. Click OK to apply the changes to the current project.

Setting Global Cache Limits in Kdenlive Preferences

To ensure that temporary render files are routinely purged across all projects rather than configuring them individually, adjust the global application preferences:

  1. Go to the top menu and select Settings > Configure Kdenlive.
  2. From the left sidebar, click on Timeline and navigate to the Timeline Preview or Cache Data section (depending on your Kdenlive version).
  3. Set the Maximum Cache Size threshold. When this threshold is reached, Kdenlive automatically purges the oldest rendered chunks to free up space.
  4. Enable the automated cache maintenance rules so temporary render chunks are cleared automatically when projects are unloaded or when Kdenlive shuts down.
  5. Click Apply and then OK to save your global settings.

Manually Purging Preview Files

If you need to instantly reclaim space without changing your automated rules:

  1. Click on Timeline in the main menu.
  2. Navigate to Timeline Preview.
  3. Select Remove All Preview Renders (or Remove Preview by Range to clear specific sections).
  4. Alternatively, go to Project > Manage Cached Data to review all cached files across all projects and delete unwanted preview data with a single click.
