Export Multi-Track EDL Files in Kdenlive

This article provides a step-by-step guide on exporting an Edit Decision List (EDL) from Kdenlive while preserving multi-track transition references. It covers the preparation of your timeline, configuring export parameters for track-to-track transitions, and verifying the generated EDL data to ensure seamless compatibility with external finishing software such as DaVinci Resolve or other NLE platforms.

1. Structure Multi-Track Transitions on the Timeline

Ensure your project timeline is properly organized before initiating the export:

  • Place adjacent or overlapping video clips on separate, sequential tracks (such as Video 1 and Video 2).
  • Apply standard transitions (such as crossfades, dissolves, or wipes) directly between the overlapping tracks.
  • Verify that timecode integrity and track assignments are correct, as EDLs rely heavily on sequential track logic for two-track transition calculations.

2. Access the EDL Export Menu

  • Open the main menu bar in Kdenlive.
  • Navigate to Project > Export (or File > Export depending on your specific Kdenlive version).
  • Select Export to EDL... to launch the Edit Decision List configuration dialog.

3. Configure Multi-Track Export Parameters

In the EDL export dialog, adjust the parameters to capture multi-track relations:

  • Format Selection: Choose the standard CMX 3600 format, which offers the broadest cross-platform support for multi-track cut and dissolve data.
  • Track Selection: Specify which video and audio tracks to include. Ensure both the outgoing track (from) and the incoming track (to) are selected so transition cross-references are captured.
  • Include Transitions: Ensure the option to include video transitions is checked. This ensures the exporter writes transition type flags (such as D for Dissolve or W for Wipe) along with transition durations in frames.

4. Save and Generate the File

  • Click the file browser icon to designate an output folder.
  • Provide a clear file name ending in the .edl extension.
  • Click Save or Export to generate the file.

5. Verify the Exported EDL

Open the generated .edl file in a text editor to confirm proper transition referencing:

  • Check the event numbers to ensure each transition lists the source track, destination track, transition type, duration, and corresponding source/record timecodes.
  • Confirm that overlapping cuts have associated transition lines (e.g., standard CMX 3600 dissolve lines showing the frame length of the effect).
