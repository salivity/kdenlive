How to Configure Multi-Pass Encoding in Kdenlive

Multi-pass encoding in Kdenlive optimizes video output by analyzing video frames in an initial pass and applying compression efficiently during subsequent passes, resulting in higher visual fidelity at a controlled bitrate. This guide outlines the necessary steps to create, configure, and execute custom multi-pass encoding profiles directly within Kdenlive's render dialog.

1. Open the Render Window

  1. Open your project in Kdenlive.
  2. Click the Render button in the main toolbar or press Ctrl + Return (Cmd + Return on macOS) to open the rendering dialog.

2. Access the Custom Profile Editor

  1. In the Render Project dialog, navigate to the Presets panel.
  2. Select a base format (such as MP4 - H.264/AAC).
  3. Click the Create New Profile button (represented by a document icon with a plus sign) or the Edit Profile button (pencil icon) to modify an existing profile.

3. Add Multi-Pass Parameters

Kdenlive uses the MLT framework and FFmpeg backend for rendering. Multi-pass encoding requires setting specific bitrate constraints and passing the multi-pass command to the encoder.

In the Parameters text field, add or adjust the following parameters:

  • Target Video Bitrate: Multi-pass encoding requires an explicit target bitrate rather than Constant Rate Factor (CRF). Set this using b= (e.g., b=6000k for a 6 Mbps video stream).
  • Multi-Pass Directive: Add passes=2 to instruct Kdenlive and MLT to perform a two-pass render.

A standard configuration for a two-pass H.264 profile looks like this:

f=mp4
vcodec=libx264
b=6000k
passes=2
acodec=aac
ab=192k
movflags=+faststart
preset=medium

4. Save the Custom Profile

  1. Enter a descriptive name in the Profile Name field (for example, MP4 H.264 2-Pass 6Mbps).
  2. Set the file extension field to mp4.
  3. Click OK to save the new profile into your custom presets list.

5. Render the Project

  1. In the Render Project window, select your newly created profile under the Custom category.
  2. Choose your output file destination path.
  3. Click Render to File.

Kdenlive will automatically run the analysis pass first (generating temporary log data) followed by the encoding pass to output the final video file.
