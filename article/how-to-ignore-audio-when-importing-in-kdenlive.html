How to Ignore Audio When Importing in Kdenlive

This guide explains how to automatically strip or ignore audio streams when importing video assets into Kdenlive. By configuring automatic transcoding rules or adjusting clip properties in the Project Bin, you can streamline your workflow and ensure imported media contains only video streams.

Method 1: Use an Automatic Transcoding Profile on Import

The most effective way to automatically remove audio streams upon import is to set up a custom transcoding profile in Kdenlive's global settings.

  1. Open Kdenlive and go to Settings > Configure Kdenlive (or Kdenlive > Preferences on macOS).
  2. Select the Transcoding tab from the left sidebar.
  3. Click the Add Profile (plus icon) button to create a new profile.
  4. Name the profile (e.g., Video Only - No Audio).
  5. In the parameters box, insert an FFmpeg command that copies the video stream while stripping the audio, such as: 
    -c:v copy -an
  6. Set the extension to match your source container (e.g., mp4 or mkv).
  7. Check the option Enable automatic transcoding if you want Kdenlive to prompt or automatically apply this profile when adding video clips to the Project Bin.
  8. Click Apply and then OK.

When you add videos to the Project Bin, select this transcoding profile to import only the video stream without the audio track.

Method 2: Disable Audio Streams via Clip Properties

If you have already imported assets into the Project Bin and want to disable their audio without re-encoding:

  1. Select the video asset in the Project Bin.
  2. Open the Clip Properties panel (if hidden, go to View > Clip Properties or right-click the clip and select Clip Properties).
  3. Switch to the Audio tab inside the Clip Properties panel.
  4. Uncheck the enabled audio stream (e.g., Stream 0 or Stream 1).
  5. Click Apply.

The clip in your Project Bin will now ignore the embedded audio, allowing you to drag it into the timeline as a pure video clip.

Method 3: Drag Video Only from the Clip Monitor

If you want to keep the audio in the Project Bin for reference but avoid adding it to the timeline:

  1. Double-click the clip in the Project Bin to load it into the Clip Monitor.
  2. Hover over the video preview area.
  3. Click and drag the Video Only icon (a filmstrip icon located below the monitor) directly onto a video track in your timeline.
