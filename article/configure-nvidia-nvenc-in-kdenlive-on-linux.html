Configure NVIDIA NVENC in Kdenlive on Linux

This guide provides a straightforward walkthrough on configuring NVIDIA NVENC hardware-accelerated video encoding in Kdenlive on Linux. By offloading rendering tasks from the CPU to your NVIDIA GPU, you can drastically reduce export times. The following sections cover driver and software verification, enabling hardware encoding settings in Kdenlive, and setting up custom NVENC rendering profiles.

1. Verify Prerequisites and FFmpeg Support

Before configuring Kdenlive, ensure your Linux system has the proprietary NVIDIA drivers installed and that your system's FFmpeg build supports NVENC.

Open a terminal and verify the NVIDIA driver is functioning:

nvidia-smi

Next, confirm that FFmpeg includes the NVENC codecs:

ffmpeg -encoders | grep nvenc

You should see h264_nvenc and hevc_nvenc in the output list. If they do not appear, install a full build of FFmpeg from your distribution's package manager or enable the non-free repositories.

2. Enable Hardware Acceleration in Kdenlive

  1. Launch Kdenlive.
  2. Go to Settings > Configure Kdenlive...
  3. Navigate to the Environment tab on the left sidebar.
  4. Select the Hardware Acceleration or GPU Acceleration tab (naming may vary slightly depending on your Kdenlive version).
  5. Check the box to enable hardware acceleration detection. Kdenlive will run an automated check to verify support for VAAPI and NVENC. Ensure that h264_nvenc or hevc_nvenc is detected.
  6. Click Apply, then OK.

3. Configure the NVENC Render Profile

Once hardware encoding is detected, you can use the built-in NVENC presets or create a custom profile.

Using Default NVENC Profiles

  1. Click the Render button in the top toolbar or press Ctrl + Return.
  2. Under the Hardware Accelerated category in the presets list, select NVENC H264 or NVENC HEVC.
  3. Choose your desired output path and adjust the quality or bitrate slider.
  4. Click Render to File.

Creating a Custom NVENC Profile

If your Kdenlive installation lacks the default NVENC preset, create one manually:

  1. In the Render window, click the Create New Profile icon (the small "+" button).
  2. Set the Profile Name to MP4 - NVENC H.264.
  3. Set the Extension to mp4.
  4. In the Parameters box, enter the following FFmpeg arguments:
f=mp4 vcodec=h264_nvenc acodec=aac ab=192k rc=vbr cq=23 preset=p4

Note: For HEVC/H.265, change vcodec=h264_nvenc to vcodec=hevc_nvenc.

  1. Click OK to save the profile.

4. Verify GPU Utilization During Export

To confirm that rendering utilizes the dedicated NVENC encoder:

  1. Start your video render in Kdenlive.
  2. Open a terminal and run:
watch -n 1 nvidia-smi

Look at the Encoder (ENC) utilization percentage under the GPU utilization metrics. A non-zero percentage confirms that hardware-accelerated NVENC encoding is actively processing your render.
