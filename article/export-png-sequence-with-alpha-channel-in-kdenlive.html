Export PNG Sequence with Alpha Channel in Kdenlive

Exporting a high-resolution PNG image sequence with preserved transparency from Kdenlive is essential for visual effects, motion graphics, and cross-platform video compositing. This guide provides a straightforward procedure for setting up your project resolution, configuring the render profile with an alpha channel (RGBA), and properly outputting every individual frame as a lossless, transparent PNG file.

Step 1: Configure Project Settings

Before rendering, ensure that your timeline matches the target resolution:

  1. Open Kdenlive and go to Project > Project Settings.
  2. Select your desired high-resolution profile (such as 1080p, 4K UHD, or a custom resolution matching your assets).
  3. Confirm that the frame rate matches your intended output and click OK.

Step 2: Prepare the Timeline with Alpha Transparency

To ensure transparency is exported:

  1. Arrange your clips on the timeline and verify there is no solid color clip or background footage on lower tracks.
  2. The empty areas of the timeline naturally represent full transparency (alpha = 0).
  3. If using transitions or compositing effects, ensure they are set to blend properly without generating an opaque background.

Step 3: Open the Render Window

  1. Click the Render button in the main toolbar, or press Ctrl + Enter (or Cmd + Return on macOS).
  2. Ensure Full Project or Selected Zone is chosen depending on the portion of the timeline you wish to export.

Step 4: Select and Edit the PNG Image Sequence Preset

  1. In the Presets panel, expand the Images sequence category.
  2. Select PNG.
  3. Click the Edit Profile button (wrench/pencil icon) or create a new profile based on the PNG preset.
  4. Verify the rendering parameters contain the following flags to ensure lossless compression and alpha channel preservation:
    • vcodec=png
    • pix_fmt=rgba
  5. Ensure that the pixel format is explicitly set to rgba (or rgba64be for 16-bit depth). Standard formats like rgb24 or yuv420p will discard the transparency data.
  6. Click OK or Save to apply the preset.

Step 5: Specify Output Destination and File Naming

  1. Click the file browser icon next to the Output file field.
  2. Create and select a new, empty folder, as image sequences generate an individual file for every frame.
  3. Name your file using sequential numbering syntax, such as frame_%05d.png (this formats frame numbers as frame_00001.png, frame_00002.png, etc.).

Step 6: Render the Sequence

  1. Double-check that Rescale is unchecked if you want to export at full project resolution.
  2. Click Render to File.
  3. Once the render job completes, open the output directory to verify that the PNG sequence files contain clean edges and a transparent background when imported into your compositing or animation software.
