How to Set 320kbps Audio Bitrate in Kdenlive

This guide outlines how to configure a custom render profile in Kdenlive to export audio at bitrates up to 320kbps. While Kdenlive’s default presets often restrict audio bitrates to 192kbps or lower, you can easily create and save a custom rendering preset with customized FFmpeg parameters to achieve higher audio fidelity in your final video exports.

Step-by-Step Procedure

  1. Open the Render Window Open your project in Kdenlive and access the render settings by pressing Ctrl + Return (or Ctrl + Enter) on your keyboard, or by selecting Project > Render from the top menu bar.

  2. Select a Base Profile Under the Presets tab, select the standard video format you wish to duplicate or modify (such as Generic (MP4-H264/AAC)).

  3. Create a New Profile Click the Create new profile button (represented by a plus icon or duplicate icon near the profile selection area). This opens the profile configuration editor.

  4. Modify the Audio Bitrate Parameter In the Parameters box, locate the audio encoding settings.

    • Look for the parameter defining audio bitrate, typically written as ab=%audiobitrate+'k', ab=192k, or b:a=192k.
    • Replace or adjust the value to explicitly set 320kbps: 
      ab=320k
      (Alternatively, if using FFmpeg standard syntax: b:a=320k)
    • Ensure the audio codec is set to a format that supports 320kbps (such as aac, libmp3lame, or libvorbis).

  5. Save the Custom Profile

    • Enter a distinct name in the Profile name field (for example, MP4 H264 - 320kbps Audio).
    • Choose a target group (e.g., Custom).
    • Click Save (or OK) to store the preset.

  6. Render Your Project Select your newly created custom profile from the list, configure your output file destination, and click Render to File. Kdenlive will now encode your project's audio track at 320kbps.
