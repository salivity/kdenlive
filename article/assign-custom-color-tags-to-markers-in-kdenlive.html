Assign Custom Color Tags to Markers in Kdenlive

Organizing your video project with color-coded markers helps streamline your editing workflow in Kdenlive. This guide provides a straightforward walkthrough on how to configure custom marker categories with specific colors and apply them directly to markers and guides on your timeline or individual clips.

Configuring Marker Categories and Colors

In Kdenlive, marker colors are defined by Categories. You must first set up or edit these categories to use custom color tags:

  1. Open Kdenlive and go to Settings > Configure Kdenlive... in the top menu bar (on macOS, go to Kdenlive > Preferences).
  2. Select the Timeline tab from the left sidebar.
  3. Click on the Categories or Guides Categories sub-tab.
  4. You will see a list of numbered categories, each with an assigned color and label.
  5. To change a color, double-click the color box next to a category and select your desired color from the color picker.
  6. Double-click the text field next to the color to rename the category (e.g., "B-Roll", "Audio Fixes", "Cuts").
  7. Click Apply, then click OK to save your changes.

Adding a Colored Marker on the Timeline

Once your categories are configured, you can apply them whenever you create a new marker or guide:

  1. Place the timeline playhead at the exact frame where you want to place the marker.
  2. Right-click on the timeline ruler at the top and select Add Guide (or use the default shortcut G).
  3. In the pop-up dialog box:
    • Enter a comment or label for the marker.
    • Open the Category dropdown menu.
    • Select your custom color category.
  4. Click OK. The marker icon on the timeline will display the chosen color.

Adding a Colored Marker to a Clip

You can also assign colored markers directly to source clips:

  1. Double-click a clip in the Project Bin to open it in the Clip Monitor, or select the clip on the timeline.
  2. Position the playhead on the desired frame.
  3. Right-click the clip on the timeline or in the Project Bin and select Markers > Add Marker (or use the shortcut Numpad *).
  4. Select your preferred color category from the dropdown menu and click OK.

Changing the Color of an Existing Marker

To update the color of a marker that has already been placed:

  1. Double-click the existing marker/guide on the timeline ruler.
  2. In the edit dialog, select a different color category from the Category dropdown list.
  3. Click OK to apply the update.

Alternatively, you can manage all timeline guides simultaneously by opening the Guides window via View > Guides. From this panel, you can view, sort, and change the category for all markers in your project.
