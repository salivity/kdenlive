How to Set Up Speech to Text in Kdenlive

This article provides a step-by-step walkthrough for configuring and using automated speech-to-text models to generate subtitles directly within Kdenlive. By integrating engines like OpenAI's Whisper or Vosk, you can automatically transcribe spoken dialogue in your video timeline into perfectly timed subtitle tracks, saving significant manual editing time.

Step 1: Access the Speech-to-Text Configuration

  1. Open Kdenlive.
  2. In the top menu, navigate to Settings > Configure Kdenlive (on macOS, Kdenlive > Preferences).
  3. In the left sidebar of the settings window, select the Speech to Text tab.

Step 2: Choose and Install the Speech Recognition Engine

Kdenlive primarily supports two engines: Whisper (recommended for modern systems and higher accuracy) and Vosk (lightweight and faster on older hardware).

  1. Select Whisper as your speech recognition engine.
  2. Click the Check Configuration or Install button. Kdenlive will prompt you to set up a Python virtual environment and install the required dependencies (such as torch and openai-whisper) automatically.
  3. Wait for the terminal/installation process inside Kdenlive to finish downloading and configuring the Python packages.

Step 3: Download a Language Model

  1. Once the engine dependencies are installed, go to the model selection section within the same Speech to Text settings window.
  2. Choose a model size that matches your system capabilities:
    • Tiny / Base: Fast and consumes minimal system resources; suitable for clear audio.
    • Small: Balanced performance and accuracy for general use.
    • Medium / Large: Highly accurate across multiple languages and accents, but requires significant CPU/GPU resources and RAM.
  3. Click Download next to your chosen model and wait for the file to finish downloading.
  4. Click Apply and then OK to close the configuration window.

Step 4: Generate Subtitles on the Timeline

  1. Ensure your audio or video clip with dialogue is placed on the timeline.
  2. In the top menu, go to Project > Subtitles > Speech Recognition (or open the Subtitles panel and click the Magic Wand / Speech Recognition icon).
  3. In the Speech Recognition dialog:
    • Select the target track or choose Selected clips only / Timeline Zone.
    • Choose your installed model from the dropdown.
    • Select the spoken language (or use auto-detect if using Whisper).
  4. Click Process. Kdenlive will analyze the audio and automatically place generated subtitle blocks onto a dedicated subtitle track above your video tracks.

Step 5: Review and Edit the Generated Subtitles

  1. Open the Subtitles panel via View > Subtitles.
  2. Click on any generated subtitle segment to edit text errors, fix punctuation, or adjust timecodes.
  3. Use the timeline handles on individual subtitle clips to fine-tune start and end timings.
