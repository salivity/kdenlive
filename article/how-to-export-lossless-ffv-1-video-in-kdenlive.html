How to Export Lossless FFV1 Video in Kdenlive

Exporting a master sequence to the lossless FFV1 codec in Kdenlive ensures your final edit is preserved with maximum visual fidelity for long-term archiving or intermediate post-production workflows. This guide covers the complete, step-by-step procedure to configure render settings, select the FFV1 profile, and export your project directly from the Kdenlive timeline.

Step 1: Prepare the Timeline

  1. Open your completed project in Kdenlive.
  2. Ensure there are no unwanted gaps or disabled tracks in your master sequence.
  3. If you only want to export a specific section, define the range using the Set Zone In (I) and Set Zone Out (O) shortcuts. Otherwise, leave the timeline set to render the entire project.

Step 2: Open the Render Dialog

  1. Click the Render button on the main toolbar, or select Project > Render from the top menu bar.
  2. Alternatively, press the default keyboard shortcut Ctrl + Return to open the Render window.

Step 3: Select the FFV1 Export Preset

  1. In the Presets panel on the left side of the Render window, expand the Lossless / HQ category.
  2. Scroll through the available presets and select FFV1.
  3. Note the default output parameters:
    • Container: Typically .mkv (Matroska) or .avi.
    • Video Codec: ffv1 (lossless intra-frame video).
    • Audio Codec: flac or uncompressed pcm_s16le.

Step 4: Customize Export Settings (Optional)

If you need specific custom parameters or if the default preset is not present:

  1. Click the Create New Preset (or Edit Preset) button.
  2. In the preset parameters, specify:
    • f=matroska or f=avi
    • vcodec=ffv1
    • acodec=flac (or acodec=pcm_s24le for uncompressed audio)
  3. Set your preferred intra-frame version or slice settings (e.g., coder=1 or context=1 for FFV1 level 3) if your workflow requires specific FFV1 specifications.

Step 5: Specify Output Destination and Scope

  1. In the Output file field at the top of the Render dialog, click the folder icon to select the destination folder and name your master file.
  2. Under the Render options section:
    • Choose Full Project to export the entire timeline, or Selected Zone to export only the defined In/Out section.
    • Check More Options to enable parallel processing if supported by your system configuration.

Step 6: Render the Master File

  1. Click the Render to File button at the bottom of the window.
  2. Monitor the progress in the Job Queue tab. Once the status shows 100%, your lossless FFV1 master file is ready for archiving or distribution.
