How to Isolate Offline Media in Kdenlive

Managing large video projects often results in misplaced, renamed, or deleted source files that become offline assets. This guide explains how to configure and use the Kdenlive Project Bin tools to instantly locate, filter, and isolate missing clips so you can relink or remove them without disrupting your editing workflow.

Filter Missing Clips in the Project Bin

The fastest way to isolate offline assets in Kdenlive is through the Project Bin's built-in filter bar:

  1. Locate the search and filter bar at the top of the Project Bin panel.
  2. Click the Filter icon (funnel icon) next to the search input.
  3. Select Missing Clips (or Invalid Clips) from the drop-down filter menu.
  4. The Project Bin will instantly hide all working media and display only the clips whose source files cannot be located on your drive.

Switch to Tree View for Status Indicators

Tree View provides clear visual cues for offline media across different folders:

  1. Click the Options menu (three horizontal lines or gear icon) in the top-right corner of the Project Bin.
  2. Under View Mode, select Tree View.
  3. Offline clips will display a red warning icon or a broken link symbol next to their file names, making them immediately recognizable within their respective folder structures.

Use the Clip Problems Dialog

For a dedicated management window that lists only missing or altered files:

  1. Go to the top menu bar and select Project.
  2. Click Clip Problems (or Check Missing Clips in older versions).
  3. A dedicated window will open, isolating every missing file path in your project.
  4. From this window, you can view the original file paths and use the Search or Relink buttons to point Kdenlive to the new location of the media.

Relinking Isolated Media

Once your offline clips are isolated in the Project Bin:

  1. Right-click the missing clip.
  2. Select Reload Clip if the file was restored to its original directory.
  3. Select Clip Properties or Change URL to browse your local storage and assign the new file path. All timeline instances of that clip will update automatically.
