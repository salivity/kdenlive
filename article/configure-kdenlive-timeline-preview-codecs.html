Configure Kdenlive Timeline Preview Codecs

Configuring Kdenlive’s timeline preview rendering with lightweight intermediate codecs significantly improves playback smoothness and reduces rendering times for complex edits, transitions, and effects. This guide walks you through enabling timeline previews, selecting fast-rendering intermediate profiles such as ProRes Proxy or DNxHR, and customizing preview profiles to optimize system resource usage during video editing.

Access Timeline Preview Settings

  1. Open Kdenlive.
  2. In the top menu bar, navigate to Settings > Configure Kdenlive... (on macOS, select Kdenlive > Preferences...).
  3. In the configuration window, select the Timeline category from the left sidebar.
  4. Click on the Preview tab.

Select an Intermediate Codec Profile

  1. Check the box labeled Enable Timeline Preview if it is not already active.
  2. Open the Preview Profile drop-down menu to view the available presets.
  3. Choose a lightweight intermediate codec suitable for your workflow:
    • ProRes Proxy: Offers high-speed decoding, low CPU overhead, and minimal compression artifacts while editing.
    • DNxHR LB (Low Bandwidth): A fast, low-overhead alternative optimized for smooth timeline playback on multi-track projects.
    • MJPEG (QuickTime or AVI): An older intra-frame format with very low encoding latency, suitable for older hardware.

Create a Custom Lightweight Preview Profile (Optional)

If your system requires even faster rendering or lower storage usage, create a custom preview profile:

  1. Click the Manage Timeline Preview Profiles icon (wrench/tools icon) next to the profile dropdown.
  2. Click the Add New Profile (+) button.
  3. Enter a name (e.g., Custom ProRes Proxy 720p).
  4. Set the Extension to mov (for ProRes/DNxHR) or mp4.
  5. In the Parameters field, define your FFmpeg encoding arguments. For example, for low-resolution, fast ProRes: 
    vcodec=prores_ks profile=0 qscale=10 s=1280x720 acodec=pcm_s16le
  6. Click Save and close the profile manager.
  7. Select your newly created profile from the Preview Profile dropdown and click Apply and OK.

Render Previews in the Timeline

  1. In your project timeline, define the area that needs rendering by setting the In point (I) and Out point (O).
  2. Press Shift + R or click the Start Preview Render button in the timeline toolbar.
  3. A colored bar (green/red) above the timeline ruler indicates the preview status:
    • Red/Yellow: Unrendered frames or modified sections.
    • Green: Cached, pre-rendered frames playing back via your chosen intermediate codec.
