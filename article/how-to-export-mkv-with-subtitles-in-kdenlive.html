How to Export MKV with Subtitles in Kdenlive

This guide explains how to export a completed video project into a Matroska (MKV) container with switchable, soft subtitles using Kdenlive. Soft subtitles are embedded as a separate data stream within the MKV file, allowing viewers to toggle them on or off or switch between languages in compatible media players. Follow the step-by-step instructions below to configure your subtitle tracks and render settings properly.

Step 1: Create or Import Subtitles

  1. Open your completed timeline project in Kdenlive.
  2. If you have not created subtitles yet, open the Subtitle Tool by navigating to Project > Subtitles > Add Subtitle Track (or press Shift + S).
  3. Type and time your subtitles along the timeline, or import an existing .srt file via Project > Subtitles > Import Subtitle File.

Step 2: Open the Render Dialog

  1. Click the Render button in the main toolbar, or select Project > Render from the top menu (shortcut: Ctrl + Return).
  2. The Render window will open displaying output format presets and encoding parameters.

Step 3: Select the MKV Container Preset

  1. In the preset tree on the left, navigate to Generic or MP4 / Matroska.
  2. Select Matroska (MKV) or H.264 / AAC (MKV). Matroska natively supports embedded soft subtitles alongside video and audio tracks.

Step 4: Configure Subtitle Export Settings

  1. Look at the lower section of the Render dialog window.
  2. Locate the Subtitles section or click More Options to expand advanced rendering parameters.
  3. Ensure that Burn in subtitles is unchecked. Leaving this unchecked ensures the text is not permanently hard-coded onto the video frames.
  4. Check the box labeled Export subtitles or Embed subtitles. This tells the encoder to multiplex the subtitle track into the MKV container as an independent subtitle stream.

Step 5: Render and Verify the File

  1. Choose your desired output path and file name under Output file.
  2. Click Render to File.
  3. Once rendering finishes, open the resulting .mkv file in a media player (such as VLC or MPV).
  4. Access the player's subtitle menu to verify that the subtitle track appears and can be switched on, switched off, or synchronized as intended.
