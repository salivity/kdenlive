Create a 4-Way Split Screen Grid in Kdenlive

Creating a four-way split-screen grid in Kdenlive allows you to display four separate video clips simultaneously in a balanced 2x2 layout. This technique is accomplished by stacking four video clips across separate timeline tracks, scaling each clip down to 50% of its original size using the Transform effect, and repositioning each clip into its designated quadrant: top-left, top-right, bottom-left, and bottom-right.

1. Prepare Your Timeline Tracks

  1. Open your project in Kdenlive.
  2. Ensure your timeline has at least four video tracks. If you need more tracks, right-click on the track header area and select Insert Track.
  3. Place your four video clips directly above one another on tracks V1, V2, V3, and V4, aligning their start times.

2. Apply the Transform Effect

  1. Open the Effects tab.
  2. Search for the Transform effect (located under the Transform, Distort and Crop category).
  3. Drag and drop the Transform effect onto each of the four video clips on your timeline.

3. Scale and Position the Clips

Select each clip one by one to adjust its parameters in the Effect/Composition Stack panel. For a standard 16:9 project (such as 1920x1080), adjust the scale and coordinates as follows:

Top-Left Quadrant (Track V4)

  • Size / Scale: Set to 50% (or set Width to 960 and Height to 540).
  • X Position: 0
  • Y Position: 0

Top-Right Quadrant (Track V3)

  • Size / Scale: Set to 50% (or set Width to 960 and Height to 540).
  • X Position: 960 (or 50% of project width)
  • Y Position: 0

Bottom-Left Quadrant (Track V2)

  • Size / Scale: Set to 50% (or set Width to 960 and Height to 540).
  • X Position: 0
  • Y Position: 540 (or 50% of project height)

Bottom-Right Quadrant (Track V1)

  • Size / Scale: Set to 50% (or set Width to 960 and Height to 540).
  • X Position: 960 (or 50% of project width)
  • Y Position: 540 (or 50% of project height)

4. Align and Preview

Play back the timeline in the Project Monitor to confirm that all four videos render cleanly in their respective corners without overlapping or leaving unwanted gaps. If your source videos have mismatched aspect ratios, use the Crop, Scale and Tilt or Edge Crop effect prior to the Transform effect to ensure each clip fills its 960x540 quadrant proportionally.
