How to Extract Captions from Video in Kdenlive

Extracting embedded closed captions or subtitle streams from a video container in Kdenlive allows you to edit, repurpose, or export transcriptions without relying on external third-party software. This guide details the step-by-step process of using Kdenlive's built-in clip management tools to extract subtitle data directly from imported media containers, place the text onto your timeline, and export it as a standalone caption file.

Step 1: Add the Video File to Your Project Bin

  1. Open Kdenlive and create a new project or open an existing one.
  2. Drag and drop your video file (such as MKV, MP4, or TS containing embedded subtitle tracks) into the Project Bin, or click the Add Clip button.

Step 2: Run the Subtitle Extraction Job

  1. Right-click the imported video clip in the Project Bin.
  2. Hover over the Clip Jobs submenu.
  3. Select Extract Subtitles (or Extract Subtitle Stream depending on your Kdenlive version).
  4. If your container contains multiple subtitle tracks (such as different languages), select the specific stream you wish to extract from the pop-up prompt.
  5. Kdenlive will run a background job using FFmpeg to extract the subtitle data into a standard subtitle format (such as .srt) within your project folder.

Step 3: Add the Extracted Captions to the Timeline

  1. Ensure your video clip is placed on the video track in the timeline.
  2. Go to the top menu and select Project > Subtitles > Import Subtitle File.
  3. Navigate to your project directory, select the newly extracted .srt file, and click Open.
  4. The captions will automatically populate along a dedicated Subtitle Track at the top of your timeline, synchronized with your video.

Step 4: Edit or Export the Caption File

  1. To modify timing or text, click any subtitle segment in the timeline and use the Subtitles tool panel.
  2. To save the captions as an external file for use elsewhere, go to Project > Subtitles > Export Subtitle File, choose your desired format (e.g., SRT or VTT), and select Save.
