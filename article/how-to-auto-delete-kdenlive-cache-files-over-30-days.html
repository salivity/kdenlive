How to Auto-Delete Kdenlive Cache Files Over 30 Days

Over time, Kdenlive generates substantial amounts of temporary cache data—such as audio waveforms, proxy clips, and timeline preview renders—that can quickly consume your hard drive space. This guide provides a straightforward walkthrough on how to configure Kdenlive's built-in cache management settings to automatically remove temporary files older than thirty days, ensuring optimal storage management without risking your original media or saved project files.

Step-by-Step Configuration

  1. Open the Configuration Menu

    • Linux/Windows: Launch Kdenlive and go to the top menu bar, click Settings, and select Configure Kdenlive...
    • macOS: Click Kdenlive in the menu bar and select Preferences... (or press Cmd + ,).

  2. Navigate to Cache Settings

    • In the left sidebar of the configuration window, select the Cache Data tab (or Environment > Default Folders / Cache Management depending on your Kdenlive version).

  3. Enable Automatic Cache Cleaning

    • Locate the section titled Cached Data or Cache Management.
    • Check the box labeled Delete cached data older than (or Automatically delete files older than).

  4. Set the 30-Day Threshold

    • Enter 30 in the number field.
    • If a dropdown menu is available for the time unit, ensure it is set to Days (or choose 1 Month if the system only supports monthly increments).

  5. Apply and Save

    • Click Apply at the bottom right, then click OK to save your preferences and close the window.

What This Setting Affects

Setting a 30-day purge threshold automatically removes:

  • Audio Thumbnails: Generated waveform previews for timeline audio.
  • Video Thumbnails: Frame thumbnails shown on the video tracks.
  • Timeline Preview Renders: Temporary render files used for smooth timeline playback.
  • Unused Proxy Clips: Scaled-down editing versions of your footage.

This automation does not affect your .kdenlive project files, imported original source media, or finished exported videos. If you reopen an older project after its cache has been cleared, Kdenlive will simply regenerate any necessary temporary files in the background.
