Custom FFmpeg Audio Sample Formats in Kdenlive

Configuring custom FFmpeg audio sample formats in Kdenlive allows creators to tailor audio bit depth and precision—such as 16-bit integer, 24-bit, or 32-bit float—to meet specific mastering, broadcast, or archiving requirements. This guide provides a direct walkthrough of how to access Kdenlive's render profile editor, insert the appropriate FFmpeg audio parameters, and verify that the output file reflects the chosen sample format.

Step 1: Open the Render Window

  1. Open your project in Kdenlive.
  2. Click the Render button in the main toolbar, or use the keyboard shortcut Ctrl + Return (or Cmd + Return on macOS).

Step 2: Access Custom Render Profiles

  1. Select the base format or category you want to use (such as MP4, MKV, or Lossless/HQ).
  2. Click the Create New Profile button (the page icon with a plus sign) or select an existing custom profile and click the Edit Profile button (the pencil icon).

Step 3: Configure the Sample Format Parameter

In the Profile Parameters text box, Kdenlive displays the underlying MLT and FFmpeg command-line string. To define the audio sample format:

  1. Locate the audio codec setting, defined by acodec= (for example, acodec=aac or acodec=pcm_s24le).
  2. Add the sample_fmt parameter directly into the parameter string.

Common format parameters include:

  • sample_fmt=s16 (Signed 16-bit integer, interleaved)
  • sample_fmt=s16p (Signed 16-bit integer, planar)
  • sample_fmt=s32 (Signed 32-bit integer, interleaved)
  • sample_fmt=flt (32-bit floating point, interleaved)
  • sample_fmt=fltp (32-bit floating point, planar)

Example Custom String (AAC with planar float):

f=mp4 vcodec=libx264 acodec=aac sample_fmt=fltp ab=320k crf=18

Example Custom String (Lossless PCM 24-bit):

f=matroska vcodec=ffv1 acodec=pcm_s24le sample_fmt=s32

Note: The chosen sample_fmt must be supported by the selected audio codec (acodec). If an incompatible format is defined, the FFmpeg rendering backend will report an error and fail the render.

Step 4: Save and Apply

  1. Give your profile a recognizable name in the Profile Name field.
  2. Select the appropriate file extension in the Extension field (e.g., mp4, mkv, mov).
  3. Click OK to save the custom profile.

Step 5: Verify the Output

After rendering a clip using your new profile, you can confirm that the audio stream contains the configured sample format using ffprobe in your terminal:

ffprobe -v error -select_streams a:0 -show_entries stream=sample_fmt,bits_per_sample -of default=noprint_wrappers=1 input_file.mp4

The output will display the active sample_fmt confirming that your custom Kdenlive render configuration is functioning as intended.
