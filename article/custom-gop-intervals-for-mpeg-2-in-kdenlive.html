Custom GOP Intervals for MPEG-2 in Kdenlive

Setting a custom Group of Pictures (GOP) interval in Kdenlive is essential for producing broadcast-compliant MPEG-2 video streams, such as XDCAM HD, D-10, or ATSC/DVB standards. This guide details how to create and customize a render profile using FFmpeg arguments within Kdenlive to lock the GOP length, enforce closed GOPs, and ensure precise frame-cadence compliance.

Step 1: Open the Render Configuration

  1. Open your project in Kdenlive.
  2. Click the Render button in the main toolbar or press Ctrl + Return.
  3. In the Render dialog, click the Create New Profile icon (the document with a plus sign) located near the preset profile selector.

Step 2: Configure the Base MPEG-2 Settings

Broadcast delivery typically requires strict bitrates, color subsampling, and container formats. In the profile configuration window, set the following baseline properties:

  • Profile Name: Broadcast MPEG-2 (Custom GOP)
  • Extension: m2t, ts, or mpg (depending on delivery specs)

Step 3: Insert GOP and Encoding Parameters

In the Parameters text box, define the video codec and append the specific GOP-controlling arguments:

f=mpegts vcodec=mpeg2video acodec=mp2 ab=384k b=50M minrate=50M maxrate=50M bufsize=17825792 g=12 keyint_min=12 flags=+cgop sc_threshold=0 bf=2

Explanation of Key GOP Parameters

  • g=12 (or g=15): Sets the maximum GOP size (number of frames between I-frames). Broadcast standards typically require a GOP of 12 for 25/29.97/59.94 fps, or 15 for 25/30 fps.
  • keyint_min=12: Sets the minimum GOP size. Matching this to the g value forces a constant, fixed-length GOP.
  • sc_threshold=0: Disables scene change detection, preventing FFmpeg from inserting unexpected I-frames when cuts occur.
  • flags=+cgop: Forces "Closed GOP" structures, ensuring that frames within a GOP do not reference frames from outside the GOP. This is mandatory for seamless broadcast splicing and ingest servers.
  • bf=2: Sets the number of consecutive B-frames (e.g., bf=2 yields an \(M=3\) GOP structure like \(I-B-B-P-B-B-P\)).

Step 4: Save and Render

  1. Click OK to save the custom profile.
  2. Select your newly created profile from the list in the Render window.
  3. Choose the export destination and click Render to File.

The resulting output will strictly conform to the defined GOP interval and structure required by broadcast ingest systems.
