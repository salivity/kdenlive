Setup Jog Shuttle Controller in Kdenlive on Linux

This guide provides a straightforward walkthrough for configuring external hardware jog and shuttle controllers (such as the Contour ShuttlePRO or ShuttleXpress) in Kdenlive using Linux HID drivers. By establishing the correct device permissions through udev rules and configuring Kdenlive’s built-in jog shuttle interface, you can achieve seamless timeline scrubbing, playback speed control, and custom shortcut mapping for faster video editing.

1. Identify Your Hardware Device

Connect your jog/shuttle controller to an available USB port. Open a terminal and verify that the Linux kernel detects the Human Interface Device (HID):

lsusb

Locate your device in the output list. Next, check that the input event interface is created:

ls -l /dev/input/by-id/

Look for an entry corresponding to your device model (e.g., usb-Contour_Design_ShuttlePRO_v2-event-joystick or similar).

2. Configure Udev Permissions

By default, Linux limits read and write access to /dev/input/ devices to the root user. To allow Kdenlive to access the controller without administrative privileges, create a custom udev rule:

  1. Create a new rules file:

    sudo nano /etc/udev/rules.d/90-jogshuttle.rules

  2. Add a rule granting access to the input group or setting mode permissions. For Contour Shuttle devices, add:

    SUBSYSTEM=="input", ATTRS{idVendor}=="0b33", MODE="0660", GROUP="input"

    (Replace the vendor ID 0b33 with your device's specific vendor ID found from the lsusb output if using a different brand).

  3. Ensure your current user account belongs to the input group:

    sudo usermod -aG input $USER

  4. Reload the udev rules and apply them:

    sudo udevadm control --reload-rules
sudo udevadm trigger

    (Log out and log back in to ensure the group membership takes effect).

3. Enable Jog Shuttle in Kdenlive

  1. Launch Kdenlive.
  2. Navigate to Settings > Configure Kdenlive... (or Kdenlive > Preferences on some desktop environments).
  3. Select the Jog Shuttle section from the left-hand navigation pane.
  4. Check the box labeled Enable Jog Shuttle device.

4. Select Device and Map Controls

  1. Device Path: In the Device dropdown or file picker, select your controller's path (typically /dev/input/by-id/usb-... rather than /dev/input/eventX to ensure persistent mapping across reboots).
  2. Device Type: Select your hardware preset (such as Contour ShuttlePRO v2) from the preset dropdown to automatically apply default jog wheel and shuttle ring behaviors.
  3. Button Mapping: Assign your preferred Kdenlive actions (such as Play/Pause, Cut Clip, Insert Track, Previous Frame, Next Frame) to each numbered physical button on the hardware.
  4. Click Apply, then OK to save the configuration.

5. Verify and Test Timeline Scrubbing

Open a video project in Kdenlive to test the setup:

  • Rotate the inner jog dial to move the playhead frame-by-frame forward or backward.
  • Turn the spring-loaded outer shuttle ring to scrub through footage at variable playback speeds depending on the angle of rotation.
  • Press the mapped hardware buttons to confirm that editor actions trigger as expected.
