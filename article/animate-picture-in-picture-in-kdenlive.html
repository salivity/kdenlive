Animate Picture-in-Picture in Kdenlive

This guide demonstrates how to create a polished, animated picture-in-picture (PiP) effect using the Transform tool in Kdenlive. You will learn how to layer your video tracks, scale and position an overlay clip, and use keyframes with smooth interpolation to transition the overlay smoothly onto and off the screen.

1. Arrange the Timeline Tracks

  1. Open Kdenlive and add two video tracks to your timeline.
  2. Place your main background video on the lower track (Track V1).
  3. Place the video clip you want to use as the Picture-in-Picture overlay on the upper track (Track V2), directly above the background video.

2. Apply the Transform Effect

  1. Open the Effects tab in your workspace.
  2. In the search bar, type Transform.
  3. Drag the Transform effect and drop it directly onto the overlay clip on Track V2.
  4. Select the clip on Track V2 to open its properties in the Effect/Composition Stack panel.

3. Set the Final PiP Size and Position

  1. Move the timeline playhead to the point in time where the PiP clip should be fully visible.
  2. In the Transform effect settings, adjust the Size (e.g., set to 25% or 30%).
  3. Adjust the X and Y position parameters or drag the bounding box directly in the Clip Monitor to place the video in your desired corner.

4. Create the Entry Animation Using Keyframes

  1. Move the playhead to the very beginning of the overlay clip.
  2. Add a new keyframe in the Transform panel by clicking the Add Keyframe button (the + icon).
  3. Modify the parameters for this starting frame:
    • Slide-in effect: Change the X or Y coordinates to position the clip completely off-screen.
    • Zoom-in effect: Set the Size to 0%.
    • Fade-in effect: Lower the Opacity to 0%.
  4. Move the playhead forward (e.g., 15 to 30 frames) to the point where the animation should finish entering.
  5. Create another keyframe and ensure the size, position, and opacity match the final PiP values you set in Step 3.

5. Make the Motion Smooth

  1. In the keyframe list in the Transform panel, right-click each keyframe or use the interpolation dropdown menu.
  2. Change the interpolation mode from Linear to Smooth (or Catmull-Rom).
  3. This adds natural acceleration and deceleration (easing) to the animation instead of an abrupt start and stop.

6. Create the Exit Animation

  1. Move the playhead to roughly 15 to 30 frames before the end of the overlay clip.
  2. Add a keyframe to lock in the final PiP position.
  3. Move the playhead to the last frame of the clip and add a final keyframe.
  4. Adjust the coordinates, scale, or opacity on this last keyframe to send the clip off-screen or fade it out.
  5. Set the interpolation for these ending keyframes to Smooth.
