How to Export Kdenlive Markers for Client Feedback

Managing client revisions requires an efficient method to capture, organize, and share timecoded notes directly from your video editing timeline. This guide outlines the exact steps to configure, export, and automate timeline markers and guides in Kdenlive to produce structured client feedback logs. By utilizing Kdenlive’s native guide export tools along with lightweight XML automation scripts, you can seamlessly convert timeline annotations into shareable review sheets.

Step 1: Define Marker and Guide Categories

Before logging feedback, set up structured marker categories to categorize review notes systematically:

  1. Open Kdenlive and navigate to Settings > Configure Kdenlive > Timeline.
  2. Select the Guides or Markers tab.
  3. Define color-coded categories tailored for feedback, such as "Client Request" (Blue), "Internal Note" (Yellow), or "Approved Fix" (Green).
  4. Save your configuration so these categories are permanently available across all project timelines.

Step 2: Annotate the Timeline

During playback or review sessions, insert structured notes at specific timecodes:

  1. Position the timeline playhead at the timestamp requiring revision.
  2. Press G (or right-click the timeline ruler) to Add Guide, or use Add Marker directly on a specific clip.
  3. Enter a concise title and detailed note describing the required change.
  4. Assign the appropriate category tag to ensure proper sorting during export.

Step 3: Export Guides Natively to Plain Text

Kdenlive includes built-in functionality to export timeline guides into human-readable text formats:

  1. Open the Guides dock via View > Guides.
  2. Click the Export icon at the top of the Guides panel.
  3. Choose the export format (such as plain text, CSV, or formatted chapter marks).
  4. Select the desired destination path and export the file. This generates a structured list containing timecodes, categories, and review comments.

Step 4: Automate Feedback Log Extraction via Scripting

Because Kdenlive project files (.kdenlive) are standard MLT XML documents, you can automate log generation without opening the GUI by parsing guide elements using a command-line script:

  1. Locate the <guides> node inside the project's .kdenlive XML file.
  2. Create a lightweight Python or Bash script that reads the project file, extracts all <guide> tags, their frame positions, category IDs, and comment strings.
  3. Calculate frame-to-timecode conversions based on the project’s frames-per-second (FPS) setting.
  4. Set the script to output directly into Markdown, CSV, or HTML tables formatted for client review.

Step 5: Integrate into Client Reporting Pipelines

Once automated, link the script to your project folder workflow:

  1. Run the script automatically upon saving or committing a project milestone.
  2. Import the resulting CSV file into Google Sheets, Notion, or Excel.
  3. Share the generated sheet with clients, providing a synchronized list of timecoded changes, completion statuses, and sign-off columns for streamlined approval.
