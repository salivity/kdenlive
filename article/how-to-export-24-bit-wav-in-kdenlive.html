How to Export 24-Bit WAV in Kdenlive

Exporting an uncompressed 24-bit WAV file from Kdenlive requires utilizing the Audio Only render category and configuring a custom render profile. While Kdenlive provides standard WAV export presets, they frequently default to 16-bit depth. By modifying the render profile parameters to specify the 24-bit Linear PCM audio codec, you can export uncompressed, studio-grade 24-bit audio directly from your project timeline.

Step 1: Open the Render Window

Ensure your audio tracks and timeline edits are finalized. Open the rendering dialogue by clicking the Render button in the top toolbar, navigating to Project > Render in the menu, or pressing Ctrl + Return (or Cmd + Return on macOS).

Step 2: Access the Audio Presets

In the Render window:

  1. In the left-hand preset menu, expand the Audio only category.
  2. Highlight the standard WAV preset.

Step 3: Configure a 24-Bit Render Profile

To ensure the output file uses a 24-bit depth rather than the standard 16-bit depth, create a dedicated profile:

  1. Click the Create New Profile button (represented by a + icon next to the presets list).
  2. Set the Profile Name to something identifiable, such as WAV 24-Bit Uncompressed.
  3. Set the Extension field to wav.
  4. In the Parameters field, enter the following FFmpeg command arguments: f=wav acodec=pcm_s24le
  5. If you want to force a specific sample rate, you can append ar=48000 (for 48 kHz) or ar=44100 (for 44.1 kHz).
  6. Click OK or Save to add the profile to your preset list.

Step 4: Render the Audio File

  1. Select your new WAV 24-Bit Uncompressed preset from the Audio only list.
  2. In the Output file field, choose your desired save location and assign a filename.
  3. Under Render options, select Full Project to export the entire timeline or Selected Zone to export only a marked region.
  4. Click the Render to File button at the bottom of the window.

Kdenlive will render the timeline audio and output an uncompressed 24-bit PCM WAV file.
