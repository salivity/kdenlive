How to Show Detailed Metadata in Kdenlive Project Bin

This guide explains how to configure the Project Bin in Kdenlive to display detailed technical metadata columns for your media assets. By switching the Project Bin layout and customizing the visible data fields, you can view critical file specifications—such as resolution, frame rate, duration, and codecs—directly within your project workspace.

Step 1: Switch to Detailed View Mode

By default, Kdenlive may display your clips as large icon thumbnails. To see metadata in tabular form:

  1. Locate the Project Bin panel in your Kdenlive workspace.
  2. Find the view mode toggle buttons at the bottom or top toolbar of the Project Bin.
  3. Select the Detailed View (or Tree View) icon. This switches the clip listing from an icon grid to a list with standard columns like Name and Date.

Step 2: Access the Column Header Settings

Once in detailed view, you can choose which technical metadata columns to show:

  1. Move your cursor to the header row of the Project Bin table (where the labels Name, Type, or Date are located).
  2. Right-click anywhere on this header bar to open the context menu listing all available metadata fields.

Step 3: Enable Desired Metadata Columns

Check the boxes next to the technical properties you want to monitor. Recommended technical columns include:

  • Duration: Displays the total runtime of the source clip.
  • Frame Size / Resolution: Shows the video dimensions (e.g., 1920x1080, 3840x2160).
  • Frame Rate (FPS): Displays the clip's native framerate.
  • Codec: Indicates the compression format (e.g., H.264, ProRes, VP9).
  • Audio Channels / Sample Rate: Displays audio configuration (e.g., Stereo, 48000 Hz).
  • File Path / Size: Shows the storage location and disk usage.

Step 4: Reorder and Resize Columns

  1. Resize Columns: Hover your mouse over the dividing line between two column headers until the cursor changes to a resize arrow, then click and drag to adjust the width.
  2. Reorder Columns: Click and hold a column header, then drag it horizontally to your preferred position.
  3. Sort Clips: Click any column header to sort your bin assets alphabetically or numerically by that specific metadata property.
