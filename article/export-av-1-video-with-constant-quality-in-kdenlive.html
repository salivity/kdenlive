Export AV1 Video with Constant Quality in Kdenlive

This guide outlines the exact steps to render an MP4 video using the modern AV1 codec in Kdenlive with Constant Quality (CRF) encoding. By utilizing AV1 with constant quality settings, you achieve high visual fidelity and efficient compression, ensuring the output file maintains consistent quality throughout the entire sequence.

1. Open the Render Dialog

With your project finalized on the timeline:

  • Click the Render button in the top toolbar, or press the shortcut Ctrl + Return (Windows/Linux) / Cmd + Return (macOS).

2. Select the Output Container and Preset

  • In the Render window, expand the Generic or MP4 preset categories in the presets list.
  • Select an AV1 preset (e.g., MP4 - AV1 (libsvtav1) or AV1 / AAC).
  • If an AV1/MP4 preset is not visible by default, click the Create New Profile button to define one manually using standard FFmpeg parameters (e.g., f=mp4 vcodec=libsvtav1 acodec=aac).

3. Configure Constant Quality (CRF) Settings

  • Under the Quality or Rate Control section, ensure the mode is set to Quality (Constant Rate Factor / CRF) rather than fixed bitrate.
  • Adjust the quality slider or set the CRF value:
    • For libsvtav1, a CRF value between 24 and 32 provides an optimal balance between visual quality and file size (lower values mean higher quality).
    • For standard high-definition exports, a setting around 28 is recommended as a baseline.
  • Set the CPU/Preset speed if available (a preset value between 4 and 6 provides a good balance between encoding speed and compression efficiency).

4. Set the Output Destination

  • In the Output file field at the top of the Render window, click the folder icon to browse to your desired save location.
  • Enter a file name and ensure the extension is .mp4.

5. Start the Export

  • Under Render options, ensure Full Project (or Selected Zone if you only want to export a specific section) is selected.
  • Click Render to File to start the export process.
