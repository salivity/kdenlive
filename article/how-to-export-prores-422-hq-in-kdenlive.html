How to Export ProRes 422 HQ in Kdenlive

Exporting intermediate mastering files using the Apple ProRes 422 HQ profile in Kdenlive allows editors to preserve maximum video fidelity and 10-bit color depth for archiving, mastering, or further post-production workflows. This guide details the exact steps required to locate or configure the ProRes 422 HQ preset within Kdenlive’s rendering dialog and generate high-bitrate master files.

Step 1: Open the Render Dialog

  1. Open your completed project in Kdenlive.
  2. Click the Render button on the main toolbar, or navigate to Project > Render from the top menu (shortcut: Ctrl + Return on Linux/Windows).

Step 2: Select the Intermediate Preset Category

  1. In the Render window, locate the preset categories list on the left side.
  2. Expand the Intermediate or Lossless/HQ category (the naming depends on your Kdenlive version).
  3. Select the ProRes 422 HQ preset from the list.

Step 3: Configure or Verify the FFmpeg Parameters

If the ProRes 422 HQ profile is not listed by default, or if you want to verify the exact codec settings:

  1. Click the Create New Profile (plus icon) or edit the selected profile.
  2. Set the file extension to .mov.
  3. Ensure the encoding parameters contain the following FFmpeg arguments: 
    f=mov vcodec=prores_ks profile=3 pix_fmt=yuv422p10le acodec=pcm_s24le
    • vcodec=prores_ks: Uses the native FFmpeg Apple ProRes encoder.
    • profile=3: Specifies the ProRes 422 HQ profile (0 = Proxy, 1 = LT, 2 = Standard, 3 = HQ, 4 = 4444).
    • pix_fmt=yuv422p10le: Ensures a 10-bit 4:2:2 chroma subsampling output.
    • acodec=pcm_s24le: Encodes uncompressed 24-bit PCM master audio.

Step 4: Set the Output Path and Export

  1. Under Output file, click the folder icon to select your destination drive and specify a file name ending in .mov.
  2. Set the Render section to Full Project or specify an in/out zone if you only need a segment.
  3. Choose your desired thread count or enable parallel processing if supported by your hardware.
  4. Click Render to File to begin generating the ProRes 422 HQ master file.
