Filter Clips by Frame Rate in Kdenlive Project Bin

Filtering assets by technical metadata is essential for maintaining an organized video editing workflow, especially when working with mixed-format footage. This guide explains how to use Kdenlive's built-in Project Bin search filters to quickly isolate video clips that match specific frame rates using search syntax and property filters.

Accessing the Search Bar

  1. Open your project in Kdenlive and navigate to the Project Bin panel (typically located on the top-left section of the default workspace).
  2. Locate the search text field positioned at the top of the Project Bin interface. If the search bar is hidden, ensure the Project Bin toolbar is enabled by right-clicking inside the panel and checking toolbar visibility options.

Using the Frame Rate Filter Syntax

Kdenlive’s search bar supports property-based query syntax to filter clips according to internal metadata:

  1. Click inside the Project Bin search bar.
  2. Type the property prefix fps: followed immediately by the desired frame rate value.
    • Exact match: Enter fps:60 to display only 60 fps clips, or fps:24 for 24 fps clips.
    • Fractional/NTSC rates: Enter the specific decimal value, such as fps:29.97 or fps:23.98.
  3. Press Enter or wait for the list to update automatically. The Project Bin will dynamically hide any clip that does not match the specified frame rate criteria.

Combining and Clearing Filters

  • Combining Filters: You can combine the frame rate query with other metadata queries or keywords by separating them with a space (e.g., fps:60 b-roll or fps:24 4k).
  • Resetting the Filter: To view all project assets again, click the clear (X) icon on the right side of the search bar or delete the text query completely.
