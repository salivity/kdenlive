Custom Render Color Space in Kdenlive with FFmpeg

This article explains the step-by-step procedure for defining and applying custom render output color spaces in Kdenlive using FFmpeg parameters. By editing or creating custom render profiles, users can explicitly flag output color parameters—such as color primaries, transfer characteristics, color matrices, and dynamic range—ensuring accurate color reproduction across different media players, web platforms, and broadcast devices.

Step 1: Access the Render Dialog

  1. Open your project in Kdenlive.
  2. Click the Render button in the main toolbar or press Ctrl + Return to open the rendering interface.

Step 2: Create a Custom Render Profile

  1. In the Render dialog, select an existing preset that matches your target container and codec (such as Generic (MP4) or Ultra-High Definition (Apple ProRes)).
  2. Click the Create New Profile button (plus icon) in the top-right corner of the Presets panel, or click Edit Profile to modify a user preset.
  3. Assign a recognizable name to your new preset (e.g., MP4 H.264 Rec.709 or ProRes Rec.2020 HLG).

Step 3: Configure FFmpeg Color Space Parameters

Kdenlive processes render commands via MLT and FFmpeg. To override or explicitly set the output color metadata, append the required FFmpeg color arguments directly into the Parameters text box.

Key Color Space Arguments

  • color_primaries: Defines the chromaticity coordinates of the source primaries.
    • Rec. 709 (HD): color_primaries=bt709
    • Rec. 2020 (UHD/HDR): color_primaries=bt2020
    • DCI-P3: color_primaries=smpte432
  • color_trc: Specifies the Transfer Characteristics (gamma curve).
    • Standard Rec. 709: color_trc=bt709
    • sRGB: color_trc=iec61966-2-1
    • HDR10 (PQ): color_trc=smpte2084
    • HLG: color_trc=arib-std-b67
  • colorspace: Specifies the matrix coefficients used for color transformation (YUV to RGB).
    • Rec. 709: colorspace=bt709
    • Rec. 2020 non-constant luminance: colorspace=bt2020nc
    • Rec. 601 (SD): colorspace=smpte170m
  • color_range: Controls the luma/chroma quantization range.
    • Limited/TV range (Standard for broadcast and web video): color_range=tv
    • Full/PC range: color_range=pc

Step 4: Add Parameters to the Profile

Add your chosen parameters separated by spaces into the profile string.

Example: Standard HD (Rec.709 Limited Range)

properties=x264-medium f=mp4 vcodec=libx264 acodec=aac ab=192k crf=18 color_primaries=bt709 color_trc=bt709 colorspace=bt709 color_range=tv

Example: HDR10 (Rec.2020 PQ 10-bit)

properties=x265-medium f=mp4 vcodec=libx265 acodec=aac ab=256k crf=18 pix_fmt=yuv420p10le color_primaries=bt2020 color_trc=smpte2084 colorspace=bt2020nc color_range=tv

Step 5: Save and Export

  1. Click OK to save the custom profile.
  2. Select your newly created preset from the list.
  3. Specify your output destination file path.
  4. Click Render to File to generate the export with the embedded color space metadata.
