How to Export OpenTimelineIO from Kdenlive

Migrating a video editing project between different non-linear editors (NLEs) is streamlined using OpenTimelineIO (OTIO), an open-source interchange standard developed by Pixar. This guide explains how to export an OpenTimelineIO file directly from Kdenlive to seamlessly transfer your timeline structure, cuts, and clip arrangements to other supported video editing software like DaVinci Resolve, Adobe Premiere Pro, or Final Cut Pro.

Why Use OpenTimelineIO?

OpenTimelineIO serves as a modern alternative to legacy interchange formats like XML, EDL, and AAF. It stores editorial timeline data—including tracks, clips, gaps, transitions, and markers—in an open, JSON-based format without altering your original source media.

Step-by-Step: Exporting an OTIO File from Kdenlive

  1. Finalize Your Timeline: Before exporting, ensure your project is saved. Clean up unused tracks and verify that all source media files are properly linked in your project bin.
  2. Access the Export Menu: In the main menu bar at the top of the Kdenlive interface, click on Project (or File depending on your Kdenlive release version) and navigate to Export.
  3. Select OpenTimelineIO: Choose OpenTimelineIO (or Export to OpenTimelineIO / .otio) from the list of export formats.
  4. Choose File Location: A file dialog window will appear. Select your target directory, enter a name for your export file, and ensure the .otio extension is selected.
  5. Complete the Export: Click Save or Export to generate the file. Kdenlive will quickly write the timeline data to the designated .otio file.

Importing the OTIO File into Another NLE

Once you have your .otio file:

  1. Open the Destination Editor: Launch your destination software (such as DaVinci Resolve or any editor with native or plugin-based OTIO support).
  2. Import the Timeline: Navigate to the import menu (e.g., File > Import > Timeline or Import OTIO) and select your generated .otio file.
  3. Relink Source Media: When prompted, point the target editor to the folder containing your original media assets so the software can reconnect the video and audio files to the timeline cuts.

Migration Best Practices and Limitations

  • Supported Data: OTIO transfers cut points, track layering, clip speed changes, and basic transitions.
  • Unsupported Data: Proprietary elements—such as Kdenlive-specific effects, keyframed filters, complex title generators, and color grading—will not transfer and must be recreated in the target software.
  • File Paths: Keep your project assets organized in a single folder structure before export to simplify the media relinking process in your new editor.
