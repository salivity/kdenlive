Archive Kdenlive Project with Active Media Only

Archiving a Kdenlive project ensures that all critical video, audio, and graphic files are consolidated into a single location for storage or transfer to another machine. By configuring Kdenlive's built-in archive utility to copy only the media actively used on your timeline, you can drastically reduce the final archive size by omitting unused assets from the Project Bin.

Step 1: Open the Project and Finalize the Timeline

Open your project in Kdenlive. Ensure your timeline edit is complete and that all required media clips, titles, and audio tracks are in their final positions.

Step 2: Open the Archive Project Utility

Navigate to the top menu bar and click Project > Archive Project. This action opens the Project Archive dialog window.

Step 3: Set the Archive Destination and Format

Choose how and where you want to store the consolidated files:

  • Destination Directory: Click the folder icon next to the "Archive folder" or destination path field and select the target directory on your local drive or external storage.
  • Archive Mode: Choose whether you want to copy the files into a standard folder structure or compress them into an archive format (such as .tar.gz or .zip). A standard folder is typically recommended for faster access and editing.

Step 4: Isolate Active Timeline Media

To ensure only the files placed on the timeline are exported:

  1. Locate the options section in the Archive dialog.
  2. Check the box labeled Archive only timeline clips (or Only clips in timeline, depending on your Kdenlive version).
  3. Ensure the option to include unused Project Bin clips is unchecked.
  4. (Optional) Check or uncheck settings for proxy clips, depending on whether you want full-resolution media only or lightweight proxies included.

Step 5: Start the Archiving Process

Click the Start button at the bottom of the dialog. Kdenlive will scan the timeline, generate a modified .kdenlive project file with updated relative file paths, and copy the active media assets into the selected destination directory.

Step 6: Verify the Archive

Once the process finishes, navigate to the target directory. Open the newly generated .kdenlive file inside the archive folder to verify that the project loads without missing media warnings and that only the active assets were copied.
