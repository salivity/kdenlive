How to Create Animated Titles in Kdenlive

This article provides a step-by-step guide on creating custom, professional animated title cards in Kdenlive using layered shape assets and keyframed effects. You will learn how to design graphic elements within the Titler tool, organize them across timeline tracks, and apply motion using the Transform effect to produce seamless, reusable on-screen graphics.

Step 1: Design Graphic Layers in the Titler

  1. In the Project Bin, click the drop-down arrow next to Add Clip and select Add Title Clip.
  2. To create background shapes, select the Rectangle tool from the top toolbar. Draw a shape on the canvas and customize its fill color, border, and opacity using the properties panel on the right.
  3. For multi-layered designs with independent movement, create separate title clips for each element (e.g., one clip for the background banner, one for accent lines, and one for the main text).
  4. Alternatively, you can import custom SVG vector shapes created in external software like Inkscape directly into your Project Bin.

Step 2: Arrange Layers on the Timeline

  1. Create multiple video tracks in your timeline (e.g., Track V1 for main footage, Track V2 for background shapes, Track V3 for accent graphics, Track V4 for text).
  2. Drag your background shape clip onto Track V2.
  3. Place secondary graphic shapes on Track V3.
  4. Place your text clip on Track V4 directly above the graphic layers.
  5. Align the start and end points of these clips so they match the desired duration of your title card.

Step 3: Animate Shapes Using the Transform Effect

  1. Open the Effects tab and search for the Transform effect.
  2. Drag and drop the Transform effect onto the shape clip on Track V2.
  3. In the Effect/Composition Stack, move the playhead to the beginning of the clip.
  4. Add a keyframe, then change the X/Y Position or Scale parameter to position the shape off-screen (or set Opacity to 0%).
  5. Move the playhead forward (e.g., 15 to 30 frames), add a second keyframe, and reset the position or scale to its final visible state.
  6. Right-click on the keyframes and select Smooth to enable ease-in and ease-out interpolation for more natural movement.

Step 4: Stagger and Animate Additional Layers

  1. Apply the Transform effect to the clips on Track V3 (accent shapes) and Track V4 (text).
  2. Offset the keyframes slightly for each layer to create a staggered animation sequence where the background appears first, followed quickly by the accent line and text.
  3. To create a reveal effect where text slides out from behind a shape, add the Rectangular Alpha Mask or Alpha Shapes effect to the text track and position the mask boundaries along the edge of the shape layer.

Step 5: Animate the Outro and Save

  1. Add closing keyframes toward the end of each clip to animate the shapes and text sliding off-screen or fading out.
  2. Select all layers on the timeline, right-click, and select Group Clips to keep the title card synchronized.
  3. To reuse the animated graphic in future projects, select the clips on the timeline, click Timeline in the top menu, and choose Create Library Clip to store the title card in your Kdenlive Library.
