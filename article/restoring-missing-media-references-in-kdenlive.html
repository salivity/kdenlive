Restoring Missing Media References in Kdenlive

When source files are moved, renamed, or stored on an unmounted drive, Kdenlive displays placeholder warnings for the offline assets. Instead of manually relinking each file one by one, Kdenlive provides an automatic search directory feature that scans specified folders to restore all missing media references simultaneously. This guide explains how to trigger and use this automated tool to quickly reconnect your project files.

Step 1: Open the Clip Problems Dialog

When you open a project with missing files, Kdenlive will automatically display the Missing Clips (or Clip Problems) dialog window listing all unresolved file paths.

If the dialog does not appear automatically:

  1. Go to the top menu and select Project.
  2. Click on Clean Project or check the Clip Problems option if files show as offline in your Project Bin.

Step 2: Use the Search Directory Function

  1. In the Clip Problems window, you will see a list of all missing media files.
  2. Select the missing files from the list (or leave them all highlighted to scan for every missing item).
  3. Click the Search or Search Folder button (often represented by a folder/magnifying glass icon depending on your Kdenlive version).

Step 3: Select the Root Search Folder

  1. A file browser window will open. Navigate to the parent directory or drive where your media files are currently located.
  2. Select the folder containing your moved or reorganized assets.
  3. Click Choose or Open.

Step 4: Allow Kdenlive to Scan and Relink

Kdenlive will recursively scan the selected directory and its subfolders to match existing files with the missing filenames. Once matches are found:

  • The missing file paths in the list will update to the new valid locations.
  • The status indicator for each resolved clip will change from missing/red to found/green.

Step 5: Apply Changes and Save

  1. Click OK or Apply in the Clip Problems dialog to finalize the updated paths.
  2. Verify that your timeline and Project Bin now display the media correctly.
  3. Save your project immediately (Ctrl + S or File > Save) to commit the new file paths to the project file.
