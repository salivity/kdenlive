Preserve Audio Channels in Kdenlive Proxies

This guide explains how to configure proxy clip settings in Kdenlive to retain your source media's original multi-channel and multi-track audio layouts. By creating or modifying custom proxy profiles using specific FFmpeg parameters, you can edit with lightweight proxy files without downmixing multi-channel audio to stereo or dropping secondary audio tracks.

Why Kdenlive Alters Audio in Default Proxies

Kdenlive relies on FFmpeg to generate proxy clips. Many default proxy presets are optimized strictly for video performance and file size, frequently using standard stereo encoding arguments such as -ac 2. This forces any multi-channel audio (such as 5.1 surround sound or discrete multi-mic inputs) into a two-channel stereo mix, making separate track manipulation impossible during the editing phase.

Step 1: Open Proxy Profile Settings

  1. Open Kdenlive.
  2. Navigate to Settings in the top menu bar.
  3. Select Configure Kdenlive... (or press Ctrl + Shift + , on Linux/Windows).
  4. In the left-hand navigation pane, select Proxy and Transcode Jobs (labeled Proxy Clips in older versions).

Step 2: Create a Custom Proxy Profile

To avoid modifying default profiles that may be overwritten during software updates, create a dedicated profile:

  1. Click the Add Profile button (indicated by a plus icon or "Manage Proxy Profiles").
  2. Enter a descriptive name, such as Custom Multi-Channel Proxy.
  3. Select an appropriate file extension, such as mkv or mp4 (Matroska .mkv is recommended for robust multi-track audio support).

Step 3: Configure FFmpeg Parameters for Audio Preservation

In the Parameters field, modify the FFmpeg command line to preserve all audio streams and channel configurations.

Option A: Direct Audio Stream Copy (Recommended)

Copying the audio stream directly without re-encoding is the fastest method and guarantees 100% audio fidelity and exact channel mappings.

-vf scale=-1:720 -c:v libx264 -preset ultrafast -crf 28 -map 0:v -map 0:a? -c:a copy
  • -map 0:v: Includes the video stream.
  • -map 0:a?: Maps all existing audio tracks and channels from the source file.
  • -c:a copy: Copies audio streams directly without transcoding or downmixing.

Option B: Transcoding with Multi-Channel Audio

If the source audio codec is not natively supported inside the proxy container format (e.g., PCM audio inside an MP4 container), transcode the audio while preserving all channels:

-vf scale=-1:720 -c:v libx264 -preset ultrafast -crf 28 -map 0:v -map 0:a? -c:a aac -b:a 384k

Ensure you do not include -ac 2, as omitting the channel count argument allows FFmpeg to match the source channel count automatically.

Step 4: Apply the Profile and Regenerate Proxies

  1. Click Apply and then OK to save your settings.
  2. Set your newly created profile as the default proxy profile under Project Settings > Project Files > Proxy.
  3. For existing clips with incorrect audio mappings:
    • Right-click the clip in the Project Bin.
    • Uncheck Proxy Clip to remove the old proxy.
    • Right-click the clip again and check Proxy Clip to regenerate it using the updated multi-channel profile.
