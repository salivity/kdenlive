Set Up Kdenlive Auto-Save on NAS Storage

Configuring Kdenlive to store auto-save and backup files on a Network-Attached Storage (NAS) device ensures your project history is protected from local hardware failures and accessible across multiple workstations. Setting this up requires mounting your network share to the local operating system, configuring the storage paths within Kdenlive's settings, and verifying network write permissions for uninterrupted background saves.

Step 1: Mount the NAS Share Locally

Kdenlive accesses file systems through your operating system's native file explorer, meaning the NAS share must be persistently mounted before configuring the software.

  • Linux: Mount your NFS or SMB share to a static local directory (e.g., /mnt/nas/kdenlive_backups) using your /etc/fstab file to ensure the mount persists after reboots.
  • Windows: Map the network share to a dedicated drive letter (e.g., Z:\) via Windows Explorer, ensuring the Reconnect at sign-in option is checked.
  • macOS: Connect to the server via SMB/NFS in Finder (Cmd + K) and add the volume to your Login Items to maintain persistent access.

Step 2: Set Directory Permissions

Ensure that the user account running Kdenlive has full read and write permissions on the target NAS folder. Network permission errors can cause auto-saves to silently fail or freeze the timeline during rendering/saving intervals.

Step 3: Configure Kdenlive Default Storage Paths

  1. Open Kdenlive.
  2. Navigate to Settings > Configure Kdenlive (or Kdenlive > Preferences on macOS).
  3. In the sidebar, select the Environment tab.
  4. Locate the Default Folders section.
  5. Set the Custom project folder or Backup directory to the mounted NAS path.
  6. Click Apply and then OK.

Step 4: Configure Project-Specific Auto-Save Settings

If you prefer to define auto-save locations on a per-project basis:

  1. Open your project and go to Project > Project Settings.
  2. Under the General tab, check the option for Custom project folder.
  3. Browse and select your mounted NAS directory.
  4. Switch to the Files or Project Data tab to verify that temporary files and recovery snapshots are directed to the network path.

Step 5: Adjust the Auto-Save Interval

  1. Return to Settings > Configure Kdenlive.
  2. Select Project Defaults (or Environment depending on your Kdenlive version).
  3. Enable Auto Save if it is not already checked.
  4. Set the timer interval (typically between 5 to 10 minutes). A slightly longer interval is recommended when working over standard 1GbE networks to prevent interface lag during heavy project writes.

Step 6: Test the Setup

  1. Create a new test project and place a clip on the timeline.
  2. Save the project to generate the initial file structure.
  3. Make an edit and either wait for the designated auto-save interval or force a recovery point.
  4. Open the file manager on your NAS and verify that the .kdenlive backup files and recovery snapshots appear in the designated network directory.
