How to Create Motion Graphics in Kdenlive Using Glaxnimate

This guide provides a straightforward method for creating custom vector motion graphic titles directly inside Kdenlive using its integrated Glaxnimate plugin. By leveraging this workflow, you can design vector elements, animate shapes and text using keyframes, and have your graphics update seamlessly on the video editing timeline with transparent backgrounds.

1. Set Up the Glaxnimate Integration

Before creating animations, ensure Kdenlive points to your Glaxnimate installation:

  1. Open Kdenlive and navigate to Settings > Configure Kdenlive.
  2. Go to the Environment tab and locate the Default Apps section.
  3. Check the path for Glaxnimate. If it is empty, browse and select the Glaxnimate executable installed on your system, then click Apply.

2. Create a New Animation Clip

  1. In the Kdenlive Project Bin, click the Add Clip dropdown menu.
  2. Select Create Animation... (or right-click in an empty space of the Project Bin and choose Create Animation).
  3. A file browser dialog will appear. Choose a destination folder, enter a name for your animation file (saved with the .rawr extension), and click Save.
  4. Set the frame rate and frame count to match your project settings, then click OK. Glaxnimate will launch automatically with a transparent canvas.

3. Design the Title Elements

Inside the Glaxnimate interface:

  1. Select the Text Tool (T) to type your title, or use shape tools (such as rectangles and ellipses) to create background banners and accents.
  2. Use the Properties panel on the right to adjust font family, font size, alignment, fill color, stroke width, and stroke color.
  3. Organize multiple layers using the Layers panel to control which elements appear in front of or behind others.

4. Animate Using Keyframes

  1. Move the playhead on the timeline to frame 0.
  2. Enable the Record button (the stopwatch/record icon) at the bottom to automatically generate keyframes when values change.
  3. Expand your layer properties (such as Transform > Position, Scale, or Opacity).
  4. Set your initial property values (for example, Opacity at 0% or Position off-screen).
  5. Move the playhead forward on the timeline (e.g., to frame 30) and adjust the properties to their final on-screen values (such as Opacity to 100% or Position to the center).
  6. Adjust interpolation by selecting keyframes and choosing Ease In, Ease Out, or editing the Bezier handles in the curve editor for smoother motion.

5. Sync and Edit in Kdenlive

  1. Save your work in Glaxnimate by pressing Ctrl + S (Cmd + S on macOS) and close the application.
  2. The .rawr animation clip will now appear in your Kdenlive Project Bin.
  3. Drag the clip onto a video track positioned above your background video footage. The transparent areas of the animation will automatically overlay your video.
  4. If you need to make changes, right-click the animation clip in the Project Bin and select Edit Clip. Glaxnimate will open, and any saved changes will instantly update in the Kdenlive timeline.
