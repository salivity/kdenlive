Auto-Conform Proxy Frame Rates in Kdenlive

This guide explains how to automatically conform mismatched video frame rates upon import in Kdenlive using custom proxy transcode profiles. By adjusting FFmpeg encoding parameters within Kdenlive’s proxy settings, you can ensure that all imported media matches your project frame rate automatically, eliminating playback stuttering, frame drops, and audio sync issues during the editing process.

1. Access Proxy Clip Settings

  1. Open Kdenlive.
  2. Navigate to Settings in the top menu and select Configure Kdenlive... (or press Ctrl + Shift + ,).
  3. In the left sidebar of the configuration window, select Proxy Clips.

2. Create a Custom Proxy Profile for Frame Rate Conforming

Kdenlive uses FFmpeg profiles to generate proxy clips. To conform frame rates automatically, you must add an FFmpeg frame rate flag to the proxy encoding profile.

  1. Under the Proxy Profiles section, click the Manage Proxy Profiles button (the wrench/gear icon next to the profile dropdown).
  2. Click the Add Profile button (plus icon) or duplicate an existing profile (such as x264 or MJPEG).
  3. Set a recognizable name for your new profile, such as Conform to Project FPS (x264).
  4. In the Parameters field, modify the FFmpeg string by adding the -r flag to force the frame rate:
    • To force the proxy to inherit the project's exact target frame rate automatically, add: 
      -r %fps
    • An example of a full profile parameter string: 
      -vaapi_device /dev/dri/renderD128 -vcodec libx264 -s 1280x720 -r %fps -acodec aac -b:a 128k -preset ultrafast
      (Adjust the video codec and scaling resolution to match your editing hardware preferences).
  5. Click Save and close the profile manager.
  6. Set your newly created profile as the Default Profile in the Proxy Clips settings.

3. Enable Automatic Proxy Generation on Import

To ensure Kdenlive processes all incoming footage without requiring manual intervention:

  1. In the Proxy Clips settings window, check the box for Enable Proxy Clips.
  2. Check Generate for videos larger than and set the pixel threshold to 0 (or 320) so that every imported clip triggers proxy creation regardless of resolution.
  3. Check Auto-generate for newly added clips.
  4. Click Apply, then OK to save the global settings.

4. Ensure Project Profile Alignment

  1. Set your target project frame rate before importing media by going to Project > Project Settings.
  2. Select your desired standard profile (e.g., 1080p 24fps, 1080p 60fps).
  3. When you drag and drop footage with mismatched frame rates into the Project Bin, Kdenlive will immediately transcode the source file into a proxy that conforms directly to the specified project frame rate.
