How to Automate Kdenlive Batch Rendering

Automating batch rendering in Kdenlive allows you to queue multiple project timelines and process them sequentially without manual intervention. This guide outlines the exact steps required to generate individual rendering scripts from the Kdenlive timeline, combine them into an automated master execution script using Melt and Kdenlive's rendering engine, and trigger automated exports on Linux or Windows systems.

Step 1: Generate Individual Render Scripts from Kdenlive

Instead of rendering directly within the interface, use Kdenlive's built-in script generator to produce standalone rendering instructions for each project or timeline segment.

  1. Open your project in Kdenlive and finalize your timeline cuts and markers.
  2. Click the Render button (or press Ctrl + Return) to open the rendering dialog.
  3. Select your desired output format, resolution, frame rate, and output file destination.
  4. Click the dropdown arrow next to the Render to File button at the bottom.
  5. Select Generate Script.
  6. Save the generated script (.sh on Linux, .bat on Windows) and its accompanying .mlt playlist file into a dedicated queue folder (e.g., /render_queue/).
  7. Repeat this process for all project timelines you want to batch render.

Step 2: Create the Master Batch Script

Once your queue folder contains the generated scripts, create a master execution script to run them sequentially.

For Linux / macOS (Bash)

Create a file named run_batch.sh in your queue directory:

#!/bin/bash
QUEUE_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

echo "Starting Kdenlive Batch Render Queue..."

for script in "$QUEUE_DIR"/*.sh; do
    # Avoid executing the master runner script itself
    if [ "$script" != "$QUEUE_DIR/run_batch.sh" ]; then
        echo "Processing: $script"
        chmod +x "$script"
        "$script"
        echo "Finished: $script"
    fi
done

echo "All rendering jobs completed."

Make the master script executable:

chmod +x run_batch.sh

For Windows (Batch)

Create a file named run_batch.bat in your queue directory:

@echo off
setlocal enabledelayedexpansion

echo Starting Kdenlive Batch Render Queue...

for %%f in (*.bat) do (
    if /I not "%%f"=="run_batch.bat" (
        echo Processing: %%f
        call "%%f"
        echo Finished: %%f
    )
)

echo All rendering jobs completed.
pause

Step 3: Configure Environment Paths (If Required)

Kdenlive scripts rely on the melt binary or the kdenlive_render utility. Ensure that these binaries are in your system's PATH variable:

  • Linux: Melt is typically located at /usr/bin/melt. Verify installation by running melt --version in your terminal.
  • Windows: Ensure the path to the Kdenlive bin directory (e.g., C:\Program Files\kdenlive\bin) is added to the system Path environment variable.

Step 4: Execute and Automate the Queue

Run the master script manually or schedule it for automated off-peak rendering:

  • Manual Execution: Run ./run_batch.sh in the terminal or double-click run_batch.bat.
  • Scheduled Rendering (Linux): Add a cron job via crontab -e to trigger the queue overnight: 
    0 2 * * * /path/to/render_queue/run_batch.sh >> /path/to/render_queue/render.log 2>&1
  • Scheduled Rendering (Windows): Open Task Scheduler, create a basic task pointing to run_batch.bat, and set your desired time trigger.
