How to Compile Kdenlive from Source on Ubuntu

Compiling Kdenlive from source on Ubuntu allows you to access the latest features, improvements, and bug fixes before they are packaged into official releases. This guide provides a straightforward, step-by-step process to prepare your system, install the required development libraries, compile dependencies like the MLT multimedia framework, build Kdenlive via CMake, and run your newly compiled video editor.

Step 1: Update Your System

Ensure your package index is up to date and all current packages are upgraded:

sudo apt update && sudo apt upgrade -y

Step 2: Install Essential Build Tools and Dependencies

Kdenlive requires standard compilation tools, CMake, KDE Frameworks, Qt development packages, and multimedia libraries. Run the following command to install the primary build tools and library headers:

sudo apt install -y \
    build-essential \
    cmake \
    git \
    extra-cmake-modules \
    pkg-config \
    ffmpeg \
    libvpx-dev \
    librtmp-dev \
    libtheora-dev \
    libvorbis-dev \
    libxml2-dev \
    libsamplerate0-dev \
    libsox-dev \
    ladspa-sdk \
    libjack-dev \
    libasound2-dev \
    libsdl2-dev \
    qtbase5-dev \
    qtdeclarative5-dev \
    qtmultimedia5-dev \
    qtquickcontrols2-5-dev \
    libqt5svg5-dev \
    libqt5networkauth5-dev \
    libkf5archive-dev \
    libkf5bookmarks-dev \
    libkf5coreaddons-dev \
    libkf5config-dev \
    libkf5configwidgets-dev \
    libkf5dbusaddons-dev \
    libkf5guiaddons-dev \
    libkf5i18n-dev \
    libkf5iconthemes-dev \
    libkf5itemviews-dev \
    libkf5kio-dev \
    libkf5newstuff-dev \
    libkf5notifications-dev \
    libkf5notifyconfig-dev \
    libkf5plotting-dev \
    libkf5solid-dev \
    libkf5textwidgets-dev \
    libkf5widgetsaddons-dev \
    libkf5xmlgui-dev \
    libkf5declarative-dev \
    libkf5purpose-dev \
    libkf5crash-dev \
    libkf5filemetadata-dev

Alternatively, you can pull in existing distribution build dependencies:

sudo apt build-dep kdenlive -y

Step 3: Compile and Install MLT (Recommended)

Kdenlive relies directly on the MLT framework engine. While Ubuntu provides libmlt-dev, compiling MLT ensures API compatibility with the latest Kdenlive master branch:

cd ~
git clone https://github.com/mltframework/mlt.git
cd mlt
mkdir build && cd build
cmake .. -DCMAKE_INSTALL_PREFIX=/usr/local -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
sudo make install
sudo ldconfig

Step 4: Clone the Kdenlive Source Code

Clone the official KDE repository for Kdenlive:

cd ~
git clone https://invent.kde.org/multimedia/kdenlive.git
cd kdenlive

Step 5: Configure and Build Kdenlive

Create a separate build directory, configure the build settings using CMake, and compile using all available CPU cores:

mkdir build && cd build
cmake .. \
    -DCMAKE_INSTALL_PREFIX=/usr/local \
    -DCMAKE_BUILD_TYPE=Release \
    -DKDE_INSTALL_USE_QT_SYS_PATHS=ON

make -j$(nproc)

Step 6: Install and Launch Kdenlive

Install the compiled binaries and data files to your system:

sudo make install
sudo ldconfig

Update your desktop database so the application icon appears in your application menu:

sudo update-mime-database /usr/local/share/mime
sudo update-desktop-database /usr/local/share/applications

To run the freshly compiled version of Kdenlive, execute:

kdenlive
