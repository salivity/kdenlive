How to Create a Directional Zoom in Kdenlive

A directional zoom transition creates a dynamic whip-like effect between two video clips by combining scaling with directional movement. In Kdenlive, this effect is achieved by applying the Transform effect to the transition zone of both clips, keyframing their position and size parameters, adjusting interpolation for smooth velocity, and adding motion blur to enhance realism.

Step 1: Arrange the Clips on the Timeline

  1. Place your first clip (outgoing) and second clip (incoming) side-by-side on the same video track, or on two separate overlapping tracks (Video 1 and Video 2).
  2. Determine the duration of the transition (typically 10 to 20 frames is ideal for a fast, punchy zoom).
  3. Using the Razor Tool (X), cut the last 10–15 frames of the outgoing clip and the first 10–15 frames of the incoming clip to isolate the transition section.

Step 2: Animate the Outgoing Clip

  1. Select the cut section at the end of the first clip.
  2. Go to the Effects panel, search for Transform, and apply it to the clip.
  3. In the effect properties, create two keyframes: one at the very first frame of the cut section and one at the very last frame.
  4. Set the parameters:
    • Start Keyframe: Keep Size at 100% and Position (X, Y) at default center coordinates (0, 0).
    • End Keyframe: Increase the Size (e.g., 200% to 300%) to zoom in, and adjust the X or Y Position in the direction you want the camera to move (e.g., shift X to the left to zoom and pan left).

Step 3: Animate the Incoming Clip

  1. Select the cut section at the start of the second clip.
  2. Add the Transform effect to this clip.
  3. Create two keyframes: one at the very first frame and one at the final frame of the transition section.
  4. Set the parameters to match the incoming motion:
    • Start Keyframe: Set Size to match the outgoing clip's final zoom level (e.g., 200% to 300%) and offset the X or Y Position to the opposite side of the outgoing clip’s exit point so the motion continues seamlessly.
    • End Keyframe: Reset the Size back to 100% and the Position (X, Y) to default center coordinates (0, 0).

Step 4: Adjust Keyframe Interpolation

  1. Right-click on the keyframes within the Transform effect settings for both clips.
  2. Set the interpolation mode:
    • For the outgoing clip, change the end keyframe interpolation to Smooth or Exponential (Ease In) to accelerate into the zoom.
    • For the incoming clip, set the start keyframe interpolation to Smooth (Ease Out) so the movement decelerates naturally back to the normal view.

Step 5: Add Directional Motion Blur

  1. Search for Directional Blur or Motion Blur in the Effects tab.
  2. Apply the blur effect to both transition sections.
  3. Match the blur angle to the axis of your zoom movement (e.g., 0° or 180° for horizontal movement, 90° for vertical movement).
  4. Keyframe the blur intensity so it peaks at the cut point where the two clips meet, then fades back to zero.
