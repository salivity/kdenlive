How to Run Scripts After Kdenlive Render Queue

Automating post-render tasks in Kdenlive streamlines video production workflows by allowing custom external scripts to execute automatically once a render job or the entire queue finishes. This guide outlines the straightforward steps required to prepare an external script, configure Kdenlive's post-rendering options, and trigger automated tasks such as desktop notifications, automated uploads, or secondary transcoding pipelines.

Step 1: Create and Prepare the External Script

  1. Write the Script: Create a shell script (Linux/macOS) or batch/PowerShell script (Windows) containing the tasks you want to execute (e.g., sending a notification, moving files, or encoding).
  2. Make it Executable (Linux/macOS): Open a terminal and grant execution permissions to the script: 
    chmod +x /path/to/your_script.sh
  3. Test the Script Independently: Run the script manually in your terminal or command prompt to verify that it completes without errors.

Step 2: Open the Render Window in Kdenlive

  1. Open your project in Kdenlive.
  2. Open the Render dialog by clicking the Render button in the main toolbar or using the shortcut Ctrl + Return (or Cmd + Return on macOS).

Step 3: Configure Post-Render Script Execution

  1. In the Render dialog, locate the More Options section (expand it if it is collapsed).
  2. Look for the Post-processing or Execute script options:
    • Select Run script or check the box designated for custom post-render commands.
  3. Browse and select the path to the executable script you prepared in Step 1.
  4. If your script accepts arguments (such as the output file path or export name), include the supported placeholder variables in the parameters field.

Step 4: Add Jobs to the Render Queue

  1. Configure your standard export settings (format, resolution, and output destination).
  2. Instead of clicking Render to File immediately, click Generate Script or Add to Queue depending on whether you are managing jobs through Kdenlive's background queue manager.
  3. If using the Render Queue window, verify that the post-render script action is attached to the specific queue item or set as a global trigger upon queue completion.

Step 5: Start the Queue and Verify Execution

  1. Click Start Job or Start Queue in the Render Queue tab.
  2. Monitor the rendering progress.
  3. Once the render status reaches 100%, Kdenlive will invoke the specified external script.
  4. Verify execution by checking the output destination, process logs, or whatever action the script was programmed to perform.
