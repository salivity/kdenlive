Custom Frame Rates for Stop-Motion in Kdenlive

Setting up custom timeline frame rates in Kdenlive is essential for stop-motion animation, allowing animators to work at traditional animation rates like 12 or 15 frames per second (fps) without unwanted frame interpolation or uneven playback. This guide provides the step-by-step procedure for creating a custom project profile, adjusting timeline properties, and configuring image import settings to optimize Kdenlive for stop-motion projects.

Step 1: Create a Custom Project Profile

  1. Open Kdenlive and navigate to the top menu bar.
  2. Go to Project and select Project Settings.
  3. In the Project Settings window, click the Manage Project Profiles button (the icon shaped like a folder with a gear or wrench next to the profile dropdown).
  4. In the Project Profile Manager, click the Add new profile button (represented by a + icon).
  5. Name your profile appropriately (e.g., "Stop Motion 1080p 12fps").
  6. Set the Frame rate to your desired animation speed (for example, change the numerator to 12 and the denominator to 1 for 12 fps, or 15 and 1 for 15 fps).
  7. Configure the desired Frame size (such as 1920x1080) and set the Pixel aspect ratio to 1/1 (square pixels).
  8. Click Save to store your new custom preset.

Step 2: Apply the Profile to Your Project

  1. Return to the Project Settings window.
  2. In the profile list, select the custom profile you just created.
  3. Check the box labeled Generate proxy clips for videos larger than if you want to optimize playback performance for high-resolution stills.
  4. Click OK to apply the custom profile to the timeline.

Step 3: Configure Default Image Durations

To ensure imported still photos match your target frame duration on the timeline:

  1. Go to Settings > Configure Kdenlive.
  2. Select Timeline from the left navigation panel.
  3. Under the Default Durations section, locate the Image clip setting.
  4. Set the duration to 00:00:00:01 (1 frame) if you intend each image to represent a single frame, or 00:00:00:02 (2 frames) if animating "on twos."
  5. Click Apply and then OK.

Step 4: Import and Assemble the Animation

  1. In the Project Bin, right-click and select Add Clip or Folder to import individual frames, or select Add Image Sequence.
  2. If using Add Image Sequence, enable the feature, browse to the first image of your numbered sequence, and confirm that the frame rate matches your custom project profile.
  3. Drag the imported sequence or individual image clips onto your timeline to begin editing.
