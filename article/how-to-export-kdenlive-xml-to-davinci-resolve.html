How to Export Kdenlive XML to DaVinci Resolve

Moving a project from Kdenlive to DaVinci Resolve allows you to leverage DaVinci Resolve's industry-standard color grading and audio post-production capabilities. This guide provides a straightforward, step-by-step process for exporting a Final Cut Pro XML timeline from Kdenlive and successfully importing it into DaVinci Resolve while maintaining track sync and clip positioning.

Step 1: Prepare the Kdenlive Timeline

Before exporting, simplify your timeline to avoid translation errors between the two different video editing engines:

  • Flatten complex effects: Specialized transitions, titles, and procedural effects in Kdenlive do not translate directly to DaVinci Resolve. Bake them in or remove them before export.
  • Consolidate tracks: Keep cuts, crossfades, and standard audio/video placements clean and organized on clearly defined tracks.
  • Match project framerates: Note your exact frame rate (e.g., 23.976, 24, 29.97, 60 fps) in Kdenlive project settings, as the target DaVinci Resolve timeline must match it precisely.

Step 2: Export the Final Cut Pro XML from Kdenlive

Kdenlive features native export tools to generate XML files compatible with standard NLE formats:

  1. Open your project in Kdenlive.
  2. Navigate to the top menu and select Project > Extract Timeline > Export to Final Cut Pro XML (or File > Export > Final Cut Pro XML, depending on your Kdenlive version).
  3. In the export dialog window, choose a destination folder and file name for the .xml file.
  4. Click Save to generate the XML file.

Step 3: Import the XML into DaVinci Resolve

  1. Open DaVinci Resolve and create a new project or open an existing one.
  2. In the top menu, go to File > Import > Timeline... (or press Ctrl + Shift + I on Windows/Linux, Cmd + Shift + I on macOS).
  3. Navigate to and select the .xml file exported from Kdenlive, then click Open.
  4. The Load XML options dialog will appear:
    • Ensure the Timeline Resolution and Timeline Frame Rate match your original Kdenlive project settings.
    • Enable Automatically import source clips into media pool so Resolve links the original media files automatically.
  5. Click OK.

Step 4: Relink Unresolved Media (If Necessary)

If DaVinci Resolve fails to automatically detect the original source files:

  1. Right-click the missing media clips (marked red with "Media Offline") in the Media Pool.
  2. Select Relink Selected Clips... or Change Source Folder....
  3. Browse to the directory on your drive where the raw footage is stored and click Open. Resolve will scan the folder and re-establish the file paths.
