Display Project Timestamps in Kdenlive

This guide explains how to use Kdenlive's Dynamic Text effect to display the project's modification timestamp directly on your video. Using dynamic overlays allows editors to track version histories, render dates, and file edits automatically without manually typing out time codes or dates on title clips.

Step 1: Add a Clip to the Timeline

  1. Open your project in Kdenlive.
  2. Select the clip on the timeline where you want the timestamp to appear, or create a dedicated overlay track by going to Project > Add Color Clip (set to transparent) and placing it on an upper video track.

Step 2: Apply the Dynamic Text Effect

  1. Open the Effects tab (typically located in the bottom-left or side panel).
  2. Use the search bar to search for Dynamic Text.
  3. Drag and drop the Dynamic Text effect onto your target clip or timeline track.

Step 3: Configure the Timestamp Tag

  1. Select the clip to open the Effect/Composition Stack panel.
  2. In the Dynamic Text settings, locate the text input field.
  3. Click the preset/keyword dropdown menu or directly insert the dynamic tag for the project modification date.
  4. Select the file modification timestamp tag (e.g., #filedate# or the specific date/time format tag provided in the effect options). This tells Kdenlive to read the metadata from the project file directly.

Step 4: Customize Appearance and Positioning

  1. Font & Size: Adjust the font family, font size, and text color for readability.
  2. Background: Add a semi-transparent background box if the text blends into the video footage.
  3. Positioning: Adjust the Horizontal Alignment (Left, Center, Right) and Vertical Alignment (Top, Center, Bottom) or manually set the X and Y coordinates to place the timestamp where desired.

Step 5: Verify the Output

  1. Move the playhead across the timeline to ensure the timestamp renders clearly in the Project Monitor.
  2. When the project is saved or modified, the Dynamic Text effect will update the displayed timestamp according to the latest file metadata.
